Detailed Description

Base class for finite element function spaces.

FiniteElementSpace provides an abstract representation of a function space that is constructed from a finite element. This class serves as the foundation for specialized function spaces such as affine spaces, mesh spaces, and scaled variants.

The class encapsulates the finite element that generates the space and provides common properties and interfaces that all concrete finite element spaces must implement. Each space defines how functions are represented, evaluated, and manipulated within that space.
