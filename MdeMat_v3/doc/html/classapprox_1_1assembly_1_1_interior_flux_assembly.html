Detailed Description

Assembly for interior flux terms in DG methods.

InteriorFluxAssembly handles the assembly of flux terms between neighboring elements in the interior of the computational domain. These flux terms are essential for providing inter-element coupling in discontinuous Galerkin (DG) methods, where the solution is allowed to be discontinuous across element boundaries.

The class implements both inner and outer flux contributions:

  • Inner fluxes: contributions from the current element's boundary
  • Outer fluxes: contributions from neighboring elements' boundaries

Each flux type (left-biased, right-biased) is supported, enabling the construction of upwind-like or downwind-like numerical schemes. The flux terms are assembled using triplet format for efficient sparse matrix construction.
