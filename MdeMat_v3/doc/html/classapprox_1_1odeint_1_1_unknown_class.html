Detailed Description

Backward Differentiation Formula integrator.

Abstract base class for ODE integrators.

Implements multi-step BDF methods (e.g., BDF2, BDF3) for solving ODEs of the form: d(M*u)/dt = L*u + S where M is a mass operator, L is a linear operator and S is a source term. Any of these terms can be empty. For mass operator, it means it reduces to an identity. For linear and source term, it means they vanish from the equation. BDF methods use multiple previous time steps to achieve higher-order accuracy and are A-stable, making them suitable for stiff problems.

% Full implicit problem
integrator = approx.odeint.Bdf2Integrator(1.0);
U_new = integrator.step(L, S, M);
integrator.update(U_new);
integrator.advance();
% Pure diffusion (only linear term)
U_new = integrator.step(L, [], []);
% Pure source (only forcing term)
U_new = integrator.step([], S, []);
% With mass matrix
U_new = integrator.step(L, S, M);

Provides a common interface and shared functionality for all ODE integration methods. This base class manages solution history, timeline operations, and linear system solving infrastructure. Concrete integrators must implement the abstract methods for specific integration schemes.

We focus on the following ODEs of the form: d(M*u)/dt = L*u + F(u) + S where M is a mass term, L is a linear term, F(u) is a nonlinear term, and S is a source term. Any of these terms can be empty. In particular, M = [] means the mass operator reduces to an identity operator; {L, F, S} = [] means they vanish from the equation.

The contribution of mass operator M is determined by the physical simulation framework.

  • In the Eulerian framework, M is space-only so that it can be represented by a unique static matrix.
  • In the Semi-Lagrangian framework, M is time-dependent. The LHS mass term is forced to be a unique static matrix as in Eulerian framework. However, the RHS mass term should be updated as time evolves. In particular, M is a matrix under periodic boundary conditions, while M is a pair formed by a matrix and a vector under Dirichlet boundary conditions.

◆ setCoefficients()

virtual function approx::odeint::UnknownClass::setCoefficients ( InputType obj)
virtual

Set BDF coefficients for variable step sizes.

This method must be implemented by concrete BDF integrator classes to compute the appropriate alpha and beta coefficients based on the current timeline configuration. The coefficients depend on the specific BDF order and may vary with step size changes.

The alpha coefficients multiply previous solution values in the backward difference approximation, while beta multiplies the current derivative evaluation.
