5 % OrthogonalPolynomialBasisFunction provides common functionality for
6 % orthogonal polynomial families such as Legendre, Chebyshev, and
7 % Jacobi polynomials. It automatically sets the index as degree + 1
8 % following standard mathematical convention and provides utilities
9 % for orthogonal polynomial construction.

12 % \f[
13 % \int_{a}^{b} P_m(x) P_n(x) w(x) dx = 0, \forall m \neq n.
14 % \f]
