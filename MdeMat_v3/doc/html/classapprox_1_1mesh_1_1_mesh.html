Detailed Description

Base class for computational meshes.

Mesh provides foundational functionality for computational meshes in numerical approximation methods. It defines common interfaces for coordinate transformations, mesh refinement, and geometric computations while supporting efficient caching of expensive operations.

The class manages coordinate transformations between reference and physical coordinate systems, computes Jacobian matrices and their determinants for integration quadrature, and provides mesh refinement capabilities for adaptive algorithms.

Transformation data is cached using bitwise flags to avoid redundant computations:

  • 0b00001: Outward normals computed
  • 0b00010: Face Jacobian determinants computed
  • 0b00100: Element inverse Jacobians computed
  • 0b01000: Element Jacobian determinants computed
  • 0b10000: Element Jacobians computed

InputType IE )

Compute element inverse Jacobian matrices.

invEJ = computeElementInverseJacobians(obj) computes inverse Jacobian matrices for coordinate transformation from physical to reference coordinates for all elements.

invEJ = computeElementInverseJacobians(obj, IE) computes inverse Jacobian matrices only for the specified elements.

Parameters
obj- The Mesh object
IE- Element linear indices (optional, vector)
Return values
invEJ- Inverse Jacobian matrices (nDims × nDims × nElements)
Note
The inverse Jacobian matrix appears in gradient
computations:

\[@note \nabla_x f = J^{-T} \nabla_ξ f @note \]

where \(\nabla_x\) and \(\nabla_\xi\) are gradients in
physical and reference coordinates respectively.

Return values

Note

\[@note \int_{\Omega} f(x) dx = \int_{\hat{\Omega}} f(F(\xi)) @note |det(J)| d\xi @note \]

Parameters
obj- The Mesh object
IE- Element linear indices (optional, vector)
Return values
EJ- Jacobian matrices (nDims × nDims × nElements)
Note
The Jacobian matrix \(J_{ij} = \frac{\partial @note x_i}{\partial\xi_j}\) where \(x\) are physical
coordinates and \(\xi\) are reference coordinates. For
coordinate transformations: \(dx = J d\xi\).

Compute face Jacobian determinants.

detFJ = computeFaceJacobianDeterminants(obj, IE, IFE) computes Jacobian determinants for coordinate transformation on element faces for integration over boundaries.

Parameters
obj- The Mesh object
IE- Element linear indices (vector or [])
IFE- Local face index (scalar, 1 to nFaces)
Return values
detFJ- Face Jacobian determinants (vector)
Note
Face Jacobian determinants are used in boundary
integration:

\[@note \int_{\partial\Omega} f(x) dS = @note \int_{\partial\hat{\Omega}} f(F(\xi)) |det(J_F)| d\xi @note \]

where \(\partial\Omega\) is the boundary and \(J_F\) is
the face Jacobian.
