1classdef HeunIntegrator < approx.odeint.ExrkIntegrator
2 % HEUNINTEGRATOR Heun's integrator.
3 %
4 % HeunIntegrator implements Heun's method, a second-order explicit
5 % Runge-Kutta scheme for solving ordinary differential equations of
6 % the form:
7 %
8 % \f[
9 % \frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + F(u) + S(t),
10 % \f]
11 %
12 % where \f$M\f$ is a mass operator, \f$L\f$ is a linear operator,
13 % \f$F(u)\f$ is a nonlinear operator, and \f$S(t)\f$ is a source
14 % term. This method provides second-order accuracy with good
15 % stability properties. It's also known as the improved Euler method
16 % or RK2.
17 %
18 % Heun's method evaluates the derivative at \f$t\f$ and at \f$t +
19 % (2/3)\Delta t\f$, then takes a weighted average. The weights [1/4,
20 % 3/4] give optimal second-order accuracy with this intermediate
21 % evaluation point.
22 %
23 % Examples:
24 % % Basic usage with all terms
25 % integrator = approx.odeint.HeunIntegrator(1.0);
26 % U_new = integrator.step(L, F, S, M);
27 % integrator.update(U_new);
28 % integrator.advance();
29 %
30 % % Pure diffusion (only linear term)
31 % U_new = integrator.step(L, [], [], []);
32 %
33 % % Pure nonlinear dynamics
34 % U_new = integrator.step([], F, [], []);
35 %
36 % % Linear system with forcing
37 % U_new = integrator.step(L, [], S, []);
38 %
39 % See also:
40 % approx.odeint.ExrkIntegrator, approx.odeint.Exrk4Integrator,
41 % approx.odeint.FeIntegrator
42
43 properties (Constant)
44 ORDER = 2 % Accuracy order of Heun's method
45 end
