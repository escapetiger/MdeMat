Detailed Description

Single timing record with state tracking.

Record represents a named timing measurement that maintains active or inactive state and accumulates elapsed time.

% Basic usage
rec = core.utilities.Record('Computation');
rec.startTime = tic;
pause(0.1); % Simulate computation
rec.duration = rec.duration + toc(rec.startTime);
rec.startTime = []; % Mark as inactive
% Check if active
if ~rec.isActive()
rec.startTime = tic; % Start timing again
end
