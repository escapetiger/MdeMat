Detailed Description

Configuration file parser for KEY=VALUE format.

OptionParser provides a robust interface for reading and processing configuration files that use KEY=VALUE syntax. Supports extracting options as MATLAB variables, dynamically adding directories to the MATLAB path, and handling various configuration settings.

% Basic configuration parsing
parser = core.io.OptionParser();
options = parser.parse('config/simulation.conf');
% Parse with cleanup
parser = core.io.OptionParser();
options = parser.parse('config/setup.conf');
parser.reset(); % Clean up paths
