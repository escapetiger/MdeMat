Detailed Description

Base class for assembly operations.

Assembly provides the foundation for assembling discrete operators from element-level contributions in finite element methods. The assembly process involves iterating over mesh elements, computing local data, and accumulating contributions into global sparse data using appropriate connectivity information from the mesh space.

Assemble matrix contribution.

G = assembleMatrix(obj, IE, IL, JE, JL, L) assembles local matrices L to a global block diagonal matrix G with specified elements (IE, JE) and local Dofs (IL, JL) for test space and trial space, respectively.

Parameters
obj- The MeshOperator object
IE- Element linear indices for test space (ne x 1 vector)
IL- Local DoF indices for test space (ni x 1 vector)
JE- Element linear indices for trial space (ne x 1 vector)
JL- Local DoF indices for trial space (nj x 1 vector)
L- Local matrices (nl x nl matrix or nl × nl × ne array)
Return values
G- Global matrix (ng x ng sparse)
