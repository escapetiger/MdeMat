Detailed Description

Scaled affine transformation of finite element space.

ScaledAffineSpace extends the affine space with individual scaling parameters for both the finite element coefficients and the directional component. Functions in this space have the form:

\[f(x) = \varepsilon_u \cdot u(x) + \varepsilon_g \cdot g \]

where \(s_u\) are scaling factors applied to the finite element coefficients, \(u(x)\) is the finite element function, \(s_g\) is the scaling factor for the directional component, and \(g\) is the directional shift.

This formulation provides additional flexibility in function approximation and optimization by allowing independent scaling of different components, which can improve conditioning and convergence properties.

% Create scaled affine space with coefficient and direction scaling
coeffScales = [1.5; 2.0; 0.8]; % scale each FE coefficient
directionScale = 0.5; % scale directional component
scales = [coeffScales; directionScale];
space = ScaledAffineSpace(finiteElement, scales);
% Evaluate with automatic scaling applied
points = [0, 0.5, 1.0; 0, 0, 0];
coeffs = [1; 1; 1]; % unit coefficients
direction = [1, 1, 1]; % unit direction
values = space.evaluate(points, coeffs, direction);
% Result: values = 1.5*fe1 + 2.0*fe2 + 0.8*fe3 + 0.5*[1,1,1]
