Constructs a block matrix from a 2D cell array of matrices.

S = block(As) infers the block dimensions and returns a block matrix from a cell array of matrices.

S = block(As, Ms, Ns) returns a block matrix from a cell array of matrices.

Parameters
As- 2D cell array of matrices
Ms- Row counts for each block row (optional)
Ns- Column counts for each block column (optional)
Return values
S- Block matrix (sparse if all blocks are sparse)
% Create a block matrix from sparse blocks
A1 = sparse(rand(2,3)); B1 = sparse(rand(2,4));
C1 = sparse(rand(3,3)); D1 = sparse(rand(3,4));
As = {A1, B1; C1, D1};
S1 = block(As);
% S1 will be a sparse matrix of size (2+3) x (3+4) = 5x7.

◆ khatrirao()

function core::linalg::khatrirao ( InputType U,
VariableInputType varargin )

Compute Khatri-Rao product of input matrices.

X = khatrirao(A, B) computes column-wise Kronecker product of matrices A and B. For matrices A (I-by-K) and B (J-by-K), result is (I*J)-by-K matrix where each column k is Kronecker product of k-th columns of A and B.

Parameters
U- Cell array of matrices or head input matrix
varargin- Tailed input matrices
Return values
X- Khatri-Rao product matrix
% Two-matrix Khatri-Rao product
A = [1 2; 3 4]; % 2-by-2 matrix
B = [5 6; 7 8]; % 2-by-2 matrix
X = khatrirao(A, B);
% Sparse matrix Khatri-Rao product
As = sparse([1 0; 3 4]);
Bs = sparse([5 0; 0 8]);
X = khatrirao(As, Bs);

◆ kronecker()

function core::linalg::kronecker ( VariableInputType varargin)

Kronecker product of multiple matrices.

K = kronecker(A1, A2, ...) computes Kronecker product of all input matrices, with operation carried out from right to left. Extends MATLAB's built-in kron to handle multiple As.

Parameters
varargin- Input matrices
Return values
K- Kronecker product
% Basic usage
A = [1 2; 3 4];
B = [5 6; 7 8];
K = kronecker(A, B); % K will be a 4x4 matrix
% Using cell array
K = kronecker({A, B, eye(2)}); % K will be an 8x8 matrix
