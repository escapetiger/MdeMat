Detailed Description

Separable function with derivative capabilities and optional sparse structure.

SeparableDifferentiableFunction combines the capabilities of SeparableFunction and DifferentiableFunction to represent functions that can be expressed as products of factor functions and support differentiation with optional sparsity patterns.

The class supports both dense (full tensor product) and sparse (reduced set of multi-indices) evaluation patterns for both function values and derivatives. This enables efficient computation for high-dimensional separable functions.

% Dense separable differentiable function
factors = {LegendreBasis(3), LegendreBasis(4)};
func = SeparableDifferentiableFunction(factors);
df = func.derivative([0.5; 0.3], [1, 0]); % Partial w.r.t. first variable
% Sparse separable differentiable function with L1 constraint
func = SeparableDifferentiableFunction(factors, 'l1');
df = func.derivative([0.5; 0.3], [0, 1]); % Partial w.r.t. second variable

Constructor for separable differentiable functions.

obj = SeparableDifferentiableFunction() creates an empty separable differentiable function.

obj = SeparableDifferentiableFunction(F) creates a separable differentiable function from factor functions using dense evaluation (full tensor product).

obj = SeparableDifferentiableFunction(F, patternType) creates a separable differentiable function with specified pattern type for sparse evaluation.

Parameters
F- (Optional) Cell array or object array of Function objects
patternType- (Optional) String indicating pattern: 'full' (default), 'l1', or 'lx'

Dense derivative evaluation using full tensor product.

dY = derivativeDense(obj, X, r) computes derivatives using the full tensor product structure. Each factor function is evaluated or differentiated as needed, and results are combined using Kronecker or Khatri-Rao products.
