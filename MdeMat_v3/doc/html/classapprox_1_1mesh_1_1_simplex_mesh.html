Detailed Description

Computational mesh using simplicial elements.

SimplexMesh provides a concrete implementation of PolytopalMesh for simplicial elements (line segments in 1D, triangles in 2D, tetrahedra in 3D). It leverages the core.geometry.Simplex class for geometric operations and implements efficient algorithms for mesh refinement, coordinate transformations, and Jacobian computations.

Simplicial meshes are fundamental in finite element methods due to their mathematical properties:

  • Linear coordinate transformations with constant Jacobians per element
  • Natural barycentric coordinate systems for interpolation
  • Efficient mesh generation and refinement algorithms
  • Well-established quadrature rules and basis functions

Element types by dimension:

  • 1D: Line segments (2 vertices, 2 faces as endpoints)
  • 2D: Triangles (3 vertices, 3 edges as faces)
  • 3D: Tetrahedra (4 vertices, 4 triangular faces)
  • nD: n-simplices (n+1 vertices, n+1 (n-1)-simplex faces)

The class uses affine coordinate transformations between reference and physical coordinates, where the reference simplex has vertices at the origin and unit coordinate vectors: {0, e₁, e₂, ..., eₙ}.

% Create 2D triangular mesh
vertices2D = [0, 0; 1, 0; 0.5, 1; 1, 1];
elements2D = [1, 2, 3; 2, 4, 3];
domain2D = core.geometry.Rectangle([0, 1, 0, 1]);
triMesh = SimplexMesh(domain2D, vertices2D, elements2D);
% Create 3D tetrahedral mesh
vertices3D = [0, 0, 0; 1, 0, 0; 0, 1, 0; 0, 0, 1];
elements3D = [1, 2, 3, 4];
domain3D = core.geometry.Tetrahedron();
tetMesh = SimplexMesh(domain3D, vertices3D, elements3D);
% Map reference coordinates to physical coordinates
xRef = [0.2; 0.3]; % Reference coordinates in triangle
xPhys = triMesh.collocate(xRef, 1); % Map to element 1
% Perform uniform mesh refinement
refinedMesh = triMesh.refine(2); % 2 levels: 4^2 = 16× more triangles
% Compute geometric quantities
h = triMesh.computeMeasure(); % Minimum edge length
detJ = triMesh.computeElementJacobianDeterminants([1, 2]);
graph = triMesh.graphify(); % Extract connectivity graph
% Access mesh topology
nVerts = triMesh.nVertices; % Number of mesh vertices
nElems = triMesh.nElements; % Number of elements
V = triMesh.findElementVertices([1, 3]); % Vertices for elements 1,3

Map reference coordinates to physical coordinates.

Y = collocate(obj, X, L) transforms reference Cartesian coordinates to physical Cartesian coordinates using affine transformations defined by simplex element vertices.

Parameters
obj- The SimplexMesh object
X- Reference coordinates (nDims × nPoints)
L- Element linear indices (nElements × 1)
Return values
Y- Physical coordinates (nDims × nPoints × nElements)
Note
The transformation uses the affine mapping F(ξ) = V₀ + J×ξ
where V₀ is the first vertex, J is the Jacobian matrix
formed by edge vectors, and ξ are reference coordinates.
For a triangle with vertices [V₀, V₁, V₂], the Jacobian is
J = [V₁-V₀, V₂-V₀] and the mapping is F(ξ) = V₀ + J×ξ.

◆ refine()

function approx::mesh::SimplexMesh::refine ( InputType obj,
InputType nLevels )
virtual

Perform uniform subdivision of simplicial mesh.

newObj = refine(obj, nLevels) creates a refined mesh by uniformly subdividing each simplex element. The number of refinement levels determines the subdivision density.

Parameters
obj- The SimplexMesh object
nLevels- Number of refinement levels (non-negative integer)
Return values
newObj- Refined SimplexMesh object
Note
Refinement follows standard simplex subdivision:
- Level 0: Original mesh (no refinement)
- Level 1: Each element splits into 2^d sub-elements
- Level k: Each element splits into 2^(k×d) sub-elements
For triangles: 1 → 4 → 16 → 64 triangles per original
For tetrahedra: 1 → 8 → 64 → 512 tetrahedra per original
The refined mesh maintains the same boundary geometry
and element orientation as the original mesh.
