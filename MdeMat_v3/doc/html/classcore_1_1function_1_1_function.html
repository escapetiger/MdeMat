Detailed Description

Base class for all functions from Euclidean space to Euclidean space.

Function represents a mathematical mapping from R^n to R^m, which can be evaluated at specified points. This class defines the interface for all function types in the system.

The implementation uses a two-step evaluation process:

  1. The public evaluate method handles input/output reshaping
  2. The protected evaluateImpl method handles the actual computation

Constructor for the abstract Function class.

obj = Function() creates a Function with default dimensions (both nDims and nCodims are 0).

obj = Function(nDims) creates a Function with specified input dimension and default output dimension (0).
