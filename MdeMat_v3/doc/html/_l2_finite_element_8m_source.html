1classdef L2FiniteElement < fem.element.C0FiniteElement
2 % L2FINITEELEMENT Discontinuous finite element.
3 %
4 % L2FiniteElement implements a discontinuous (L2) finite element that
5 % extends C0 elements with flux contributions at element boundaries.
6 % Functions in this space may be discontinuous across element
7 % boundaries, making them suitable for discontinuous Galerkin (DG)
8 % methods and problems with discontinuous solutions.
9 %
10 % The L2 space allows for complete flexibility in function values
11 % across element interfaces, requiring numerical fluxes to couple
12 % neighboring elements. This approach is particularly effective for
13 % hyperbolic problems, convection-dominated flows, and problems with
14 % solution discontinuities.
15 %
16 % Flux integration is performed separately on each element boundary
17 % face, with dedicated integrators for accurate computation of
18 % interface terms in the weak formulation.
19 %
20 % Examples:
21 % % Create L2 finite element with volume and flux integration
22 % geometry = core.geometry.Orthotope.unit(2);
23 % basis = approx.basis.LagrangeBasis(2);
24 % projector = approx.project.NodalProjector(basis);
25 % volumeIntegrator = approx.integrate.GaussLegendre(3);
26 % fluxIntegrators = arrayfun(@(i) approx.integrate.FaceIntegrator(i), 1:4);
27 % element = L2FiniteElement(geometry, projector, volumeIntegrator, fluxIntegrators);
28 %
29 % % Set up data for DG method assembly
30 % element.setVolumeData(1); % Volume terms with derivatives
31 % element.setFluxData(0); % Flux terms with function values
32 %
33 % % Access flux data for boundary face i
34 % faceValues = element.fluxData(i).values;
35 % faceWeights = element.fluxData(i).weights;
36 %
37 % % Use static factory method for standard orthotope elements
38 % element = L2FiniteElement.Orthotope(2, 3, 2, 1);
39 %
40 % See also:
41 % fem.element.C0FiniteElement, fem.element.FiniteElement,
42 % fem.data.FunctionData

99 %
