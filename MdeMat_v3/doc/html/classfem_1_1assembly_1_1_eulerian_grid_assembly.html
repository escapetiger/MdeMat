Detailed Description

Eulerian grid-based assembly.

EulerianGridAssembly provides assembly methods for finite element operators on structured grid meshes using an Eulerian approach. This class handles volume and flux contributions with support for different boundary condition types including periodic and Dirichlet conditions.

The assembly supports various flux formulations (left-biased, right-biased, and central) and handles both interior and boundary contributions for each type.

% Create Eulerian grid assembly
assembly = EulerianGridAssembly(fe, mesh, op, 0); % Periodic BC
% Assemble different flux types
T_left = assembly.assembleLeftFluxTerms(1, coeffs);
T_central = assembly.assembleCentralFluxTerms(1, coeffs);
