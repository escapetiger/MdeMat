2 % C0FINITEELEMENT Continuous finite element.
3 %
4 % C0FiniteElement implements a continuous (C0) finite element with
5 % volume integration capabilities. Functions in this space are
6 % continuous across element boundaries but may have discontinuous
7 % derivatives. This corresponds to the standard Galerkin finite
8 % element method for elliptic and parabolic problems.
9 %
10 % The C0 continuity requirement ensures that the global finite element
11 % function is continuous across inter-element boundaries, which is
12 % essential for conforming finite element approximations of problems
13 % requiring H^1 regularity.
14 %
15 % Volume integration is performed using numerical quadrature over the
16 % element domain, with function data pre-computed at integration points
17 % for efficient assembly of system matrices and vectors.
18 %
19 % Examples:
20 % % Create C0 finite element with quadrature
21 % geometry = core.geometry.Orthotope.unit(2);
22 % basis = approx.basis.LagrangeBasis(2);
23 % projector = approx.project.NodalProjector(basis);
24 % integrator = approx.integrate.GaussLegendre(3);
25 % element = C0FiniteElement(geometry, projector, integrator);
26 %
27 % % Set up function data for mass matrix assembly
28 % element.setVolumeData(0); % Function values only
29 %
30 % % Set up function data for stiffness matrix assembly
31 % element.setVolumeData(1); % Include first derivatives
32 %
33 % % Access pre-computed data
34 % values = element.volumeData.values;
35 % weights = element.volumeData.weights;
36 %
