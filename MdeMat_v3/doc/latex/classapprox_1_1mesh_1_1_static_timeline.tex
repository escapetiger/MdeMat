\doxysubsection{Detailed Description}
Predefined time node timeline. 

\doxylink{classapprox_1_1mesh_1_1_static_timeline}{Static\+Timeline} represents a temporal discretization with predefined time points. It advances through these points sequentially and provides information about the current state and properties of the timeline, including uniformity checks and time step queries.
