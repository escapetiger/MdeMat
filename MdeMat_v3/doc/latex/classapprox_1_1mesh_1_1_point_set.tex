\doxysubsection{Detailed Description}
Point distributions within geometric domains. 

\doxylink{classapprox_1_1mesh_1_1_point_set}{Point\+Set} generates and manages point distributions within various geometric domains using appropriate integration rules. It supports orthotope (rectangular) and hypersphere geometries with multiple point generation strategies including deterministic quadrature and Monte Carlo methods.
