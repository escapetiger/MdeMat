\doxysubsection{Detailed Description}
H1 Galerkin element. 

\doxylink{classapprox_1_1element_1_1_h1_element}{H1\+Element} implements a H1 element function. This class extends the base \doxylink{classapprox_1_1element_1_1_element}{Element} class by adding volume integration capabilities through precomputed basis values and first-\/order derivatives at integration points.
