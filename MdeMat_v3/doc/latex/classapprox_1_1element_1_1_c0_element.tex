\doxysubsection{Detailed Description}
Continuous Galerkin element. 

\doxylink{classapprox_1_1element_1_1_c0_element}{C0\+Element} implements a continuous element function. This class extends the base \doxylink{classapprox_1_1element_1_1_element}{Element} class by adding volume integration capabilities through precomputed basis values at integration points.
