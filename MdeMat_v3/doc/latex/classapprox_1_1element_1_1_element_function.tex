\doxysubsection{Detailed Description}
Element-\/level discrete function data. 

\doxylink{classapprox_1_1element_1_1_element_function}{Element\+Function} stores function values and derivatives evaluated at integration nodes, along with the associated quadrature weights. This class provides the fundamental data structure for numerical integration and finite element computations.

The class manages function evaluations at quadrature points and supports efficient computation of integrals involving functions and their derivatives. It serves as a bridge between continuous function representations and discrete numerical computations.

Function derivatives are computed using multi-\/index notation to handle arbitrary spatial dimensions and derivative orders efficiently.

Set function derivatives at specified points. 

obj = set\+Derivatives(obj, f, X, k) computes derivatives of the function {\itshape f} up to order {\itshape k} at the specified points {\itshape X} using multi-\/index notation. The derivatives are stored in the derivatives cell array.
