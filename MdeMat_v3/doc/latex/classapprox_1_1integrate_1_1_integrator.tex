\doxysubsection{Detailed Description}
Base class for all integrators. 

\doxylink{classapprox_1_1integrate_1_1_integrator}{Integrator} provides a common interface for numerical integration across different domains and methods. It manages integration rules, nodes, weights, and provides the fundamental integration functionality that can be specialized by concrete subclasses.
