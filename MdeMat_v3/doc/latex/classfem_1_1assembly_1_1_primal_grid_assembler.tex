\doxysubsection{Detailed Description}
Grid-\/based assembler for primal variables. 

\doxylink{classfem_1_1assembly_1_1_primal_grid_assembler}{Primal\+Grid\+Assembler} implements Dirichlet boundary treatment for primal variables in mixed finite element systems. This class provides specific boundary flux implementations optimized for the primal variable formulation in mixed methods.

The assembler handles the primary variable in mixed formulations, typically representing the main unknown quantity such as pressure in flow problems or electric potential in electromagnetic problems.
