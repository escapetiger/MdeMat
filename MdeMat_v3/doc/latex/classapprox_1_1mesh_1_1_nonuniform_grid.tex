\doxysubsection{Detailed Description}
Structured grid with variable element spacing. 

\doxylink{classapprox_1_1mesh_1_1_nonuniform_grid}{Nonuniform\+Grid} represents a structured computational grid where elements can have different sizes within each dimension while maintaining the regular tensor-\/product topology. This flexibility enables adaptive mesh refinement in specific regions while preserving the computational advantages of structured grids.

The grid is defined by coordinate vectors along each dimension, allowing arbitrary spacing distributions such as geometric progressions, hyperbolic tangent clustering, or user-\/defined refinement patterns. Despite varying element sizes, the tensor-\/product structure enables efficient storage O(∑nᵢ) and algorithmic operations compared to unstructured meshes.

Key advantages over uniform grids\+:
\begin{DoxyItemize}
\item Adaptive resolution\+: Fine elements where needed, coarse elsewhere
\item Boundary layer capture\+: Geometric clustering near walls/interfaces
\item Smooth transitions\+: Gradual spacing changes avoid numerical artifacts
\item Domain conformity\+: Better approximation of curved boundaries
\end{DoxyItemize}

Key advantages over unstructured meshes\+:
\begin{DoxyItemize}
\item Tensor-\/product structure\+: Efficient matrix operations and solvers
\item Separable algorithms\+: Fast Fourier transforms and direct methods
\item Memory efficiency\+: O(d×n) storage vs O(n\texorpdfstring{$^\wedge$}{\string^}d) for explicit connectivity
\item Neighbor queries\+: O(1) algorithmic connectivity vs stored tables
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Node coordinates must be strictly increasing within each dimension 

to ensure proper element ordering and positive Jacobian 

determinants. The constructor automatically computes element 

centers and spacings from the provided node coordinates. 

Refinement preserves the relative spacing ratios within each 

original element while subdividing uniformly. This maintains the 

adaptive character of the original grid at finer scales. 

Despite variable spacing, face normals remain axis-\/aligned and the 

coordinate transformation retains its separable structure, enabling 

efficient tensor-\/product algorithms.
\end{DoxyNote}
