\doxysubsection{Detailed Description}
Error computation for function-\/based solutions. 

\doxylink{classprofilers_1_1metrics_1_1_function_metric}{Function\+Metric} implements error computation between discrete function values evaluated at specified integration nodes with associated quadrature weights. This class is designed for computing various error norms (L1, L2, Lx) between numerical and reference solutions represented as function values.

The metric uses numerical integration to compute weighted error norms, making it suitable for finite element error analysis where solutions are evaluated at quadrature points with appropriate integration weights.
