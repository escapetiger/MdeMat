3-\/D Surface Mesh Generator using Distance Functions. \mbox{[}P,T\mbox{]}=DISTMESHSURFACE(\+FD,\+FH,\+H0,\+BBOX,\+FPARAMS) 

\begin{DoxyNote}{Note}
Doesn\textquotesingle{}t work too well for nonuniform size functions... need a 

better initial grid or density control. Also no support for 

fixed points, again because of the initial grid. 

P\+: Node positions (Nx2) 

T\+: Triangle indices (NTx3) 

FD\+: Distance function \doxylink{ddiff_8m_a1aabac6d068eef6a7bad3fdf50a05cc8}{d(x,y)} 

FH\+: Scaled edge length function h(x,y) 

H0\+: Initial edge length 

BBOX\+: Bounding box \mbox{[}xmin,ymin; xmax,ymax\mbox{]} 

FPARAMS\+: Additional parameters passed to FD and FH 

Example\+: (Uniform Mesh on Unit Sphere) 

fd=@(p) dsphere(p,0,0,0,1); 

\mbox{[}p,t\mbox{]}=distmeshsurface(fd,@huniform,0.\+2,1.\+1\texorpdfstring{$\ast$}{*}\mbox{[}-\/1,-\/1,-\/1;1,1,1\mbox{]}); 

Example\+: (Graded Mesh on Unit Sphere) 

fd=@(p) dsphere(p,0,0,0,1); 

fh=@(p) 0.\+05+0.\+5\texorpdfstring{$\ast$}{*}dsphere(p,0,0,1,0); 

\mbox{[}p,t\mbox{]}=distmeshsurface(fd,fh,0.\+15,1.\+1\texorpdfstring{$\ast$}{*}\mbox{[}-\/1,-\/1,-\/1;1,1,1\mbox{]}); 

Example\+: (Uniform Mesh on Torus) 

fd=@(p) (sum(p.\texorpdfstring{$^\wedge$}{\string^}2,2)+.8\texorpdfstring{$^\wedge$}{\string^}2-\/.2\texorpdfstring{$^\wedge$}{\string^}2).\texorpdfstring{$^\wedge$}{\string^}2-\/4\texorpdfstring{$\ast$}{*}.8\texorpdfstring{$^\wedge$}{\string^}2\texorpdfstring{$\ast$}{*}(p(\+:,1).\texorpdfstring{$^\wedge$}{\string^}2+p(\+:,2).\texorpdfstring{$^\wedge$}{\string^}2); 

\mbox{[}p,t\mbox{]}=distmeshsurface(fd,@huniform,0.\+1,\mbox{[}-\/1.\+1,-\/1.\+1,-\/.\+25;1.\+1,1.\+1,.25\mbox{]}); 

Example\+: (Uniform Mesh on Ellipsoid) 

fd=@(p) p(\+:,1).\texorpdfstring{$^\wedge$}{\string^}2/4+p(\+:,2).\texorpdfstring{$^\wedge$}{\string^}2/1+p(\+:,3).\texorpdfstring{$^\wedge$}{\string^}2/1.5\texorpdfstring{$^\wedge$}{\string^}2-\/1;
