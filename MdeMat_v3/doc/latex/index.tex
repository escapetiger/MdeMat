The {\bfseries{doxygen}} software (\href{http://www.doxygen.org}{\texttt{http\+://www.\+doxygen.\+org}}) allows you to extract code comments from your code to automatically generate documentation.

Doxygen builds automatically a documentation based on C++ components (classes, functions, structs, variables,...) using syntaxic analysis. Doxygen extends this documentation by extracting special comments.\hypertarget{index_matlabComments}{}\doxysection{\texorpdfstring{Extract code comments from Matlab files (.m files)}{Extract code comments from Matlab files (.m files)}}\label{index_matlabComments}
Matlab code is not supported nativly by Doxygen \+: a perl filter allowing the conversion from .m to C++ has been developped, the {\ttfamily m2cpp.\+pl} script.

This filter extracts only \+:
\begin{DoxyItemize}
\item lines beginning with {\bfseries{\%\texorpdfstring{$>$}{>}}} \+: these lines are converted into C++ comments, ie beginning by ///
\item lines beginning with the {\ttfamily function} keyword \+: these lines are converted into C++ functions
\item lines beginning with the {\ttfamily classdef} keyword \+: these lines are converted into C++ classes
\item lines beginning with the {\ttfamily properties} keyword \+: these lines are converted into C++ properties
\item lines beginning with the {\ttfamily enumeration} keyword \+: these lines are converted into C++ enum
\item lines beginning with the {\ttfamily events} keyword \+: these lines are converted into C++ enum Events \begin{DoxyNote}{Note}
for enumeration definition \+: this script only supports the following declaration \+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{enumeration}
\DoxyCodeLine{\ \ first\_enum}
\DoxyCodeLine{\ \ second\_enum}
\DoxyCodeLine{end}

\end{DoxyCode}
 This one is not yet supported \+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{enumeration}
\DoxyCodeLine{\ \ first\_enum,\ second\_enum}
\DoxyCodeLine{end}

\end{DoxyCode}
 The file \doxylink{class_documentation_example_8m}{class\+Documentation\+Example.\+m} provides an example of enumeration definition with comments extracted by Doxygen.
\end{DoxyNote}

\end{DoxyItemize}See \doxysectlink{installation}{Installation details}{0} if you want more details about how to make this script work.

\begin{DoxyAttention}{Attention}
Each line belonging to the doxygen documentation must begin with {\bfseries{\%\texorpdfstring{$>$}{>}}} .
\end{DoxyAttention}
