\doxysubsection{Detailed Description}
Computational mesh using simplicial elements. 

\doxylink{classapprox_1_1mesh_1_1_simplex_mesh}{Simplex\+Mesh} provides a concrete implementation of \doxylink{classapprox_1_1mesh_1_1_polytopal_mesh}{Polytopal\+Mesh} for simplicial elements (line segments in 1D, triangles in 2D, tetrahedra in 3D). It leverages the \doxylink{classcore_1_1geometry_1_1_simplex}{core.\+geometry.\+Simplex} class for geometric operations and implements efficient algorithms for mesh refinement, coordinate transformations, and Jacobian computations.

Simplicial meshes are fundamental in finite element methods due to their mathematical properties\+:
\begin{DoxyItemize}
\item Linear coordinate transformations with constant Jacobians per element
\item Natural barycentric coordinate systems for interpolation
\item Efficient mesh generation and refinement algorithms
\item Well-\/established quadrature rules and basis functions
\end{DoxyItemize}

Element types by dimension\+:
\begin{DoxyItemize}
\item 1D\+: Line segments (2 vertices, 2 faces as endpoints)
\item 2D\+: Triangles (3 vertices, 3 edges as faces)
\item 3D\+: Tetrahedra (4 vertices, 4 triangular faces)
\item nD\+: n-\/simplices (n+1 vertices, n+1 (n-\/1)-\/simplex faces)
\end{DoxyItemize}

The class uses affine coordinate transformations between reference and physical coordinates, where the reference simplex has vertices at the origin and unit coordinate vectors\+: \{0, e₁, e₂, ..., eₙ\}.

\begin{DoxyNote}{Note}
Reference coordinates use the standard simplex with vertices at 

\{0, e₁, e₂, ..., eₙ\} where eᵢ are unit coordinate vectors. This 

differs from some references that use centered or symmetric simplices. 

\doxylink{classapprox_1_1mesh_1_1_mesh}{Mesh} refinement follows standard subdivision rules\+: 

-\/ 1D\+: Each edge splits into 2 segments 

-\/ 2D\+: Each triangle splits into 4 triangles 

-\/ 3D\+: Each tetrahedron splits into 8 tetrahedra 

-\/ General\+: Each k-\/level refinement produces 2\texorpdfstring{$^\wedge$}{\string^}(k×d) sub-\/elements
\end{DoxyNote}
