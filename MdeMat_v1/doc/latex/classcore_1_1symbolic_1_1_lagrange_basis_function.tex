\doxysubsection{Detailed Description}
Lagrange interpolation basis functions. 

\doxylink{classcore_1_1symbolic_1_1_lagrange_basis_function}{Lagrange\+Basis\+Function} generates Lagrange interpolation basis functions associated with a specified set of nodes. Each basis function satisfies the Kronecker delta property at the interpolation nodes and can be in standard or monic form.

Generates the Lagrange basis function. 

expr = generate(obj) creates the symbolic expression for the Lagrange interpolation basis function using the product formula. The resulting polynomial equals 1 at the specified node and 0 at all other nodes.
