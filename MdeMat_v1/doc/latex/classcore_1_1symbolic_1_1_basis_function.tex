\doxysubsection{Detailed Description}
Base class for all symbolic basis functions. 

\doxylink{classcore_1_1symbolic_1_1_basis_function}{Basis\+Function} provides common functionality for basis function families such as Legendre, Chebyshev, Fourier, and interpolation polynomials. It handles index and multidimensional bounding box information for individual basis function construction.
