\doxysubsection{Detailed Description}
Grid-\/based assembler for auxiliary variables. 

\doxylink{classfem_1_1assembly_1_1_auxiliary_grid_assembler}{Auxiliary\+Grid\+Assembler} implements Dirichlet boundary treatment for auxiliary variables in mixed finite element systems. This class handles coupling terms between primal and auxiliary variables with both interior and extraction contributions.

The assembler specializes in handling jump terms and boundary conditions specific to auxiliary variable formulations in mixed methods and discontinuous Galerkin schemes.
