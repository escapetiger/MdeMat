\doxysubsection{Detailed Description}
Base class for all differentiable functions. 

\doxylink{classcore_1_1function_1_1_differentiable_function}{Differentiable\+Function} extends the \doxylink{classcore_1_1function_1_1_function}{Function} class to add support for computing derivatives.

The implementation uses a two-\/step approach for derivatives\+:
\begin{DoxyEnumerate}
\item The public derivative method handles input/output reshaping
\item The protected derivative\+Impl method handles the actual computation
\end{DoxyEnumerate}
