\doxysubsection{Detailed Description}
Chebyshev polynomial basis functions. 

\doxylink{classcore_1_1symbolic_1_1_chebyshev_basis_function}{Chebyshev\+Basis\+Function} represents Chebyshev polynomials of the first kind on a specified interval. The polynomials can be in standard or monic form and are scaled to the given interval. These polynomials are orthogonal on \mbox{[}-\/1, 1\mbox{]} with respect to the weight function $w(x)=\frac{1}{\sqrt{1-x^2}}$. They also satifies the following three-\/term recurrence relation\+:     \begin{eqnarray*}&&T_0(t) = 1, \\
&&T_1(t) = t, \\
&&T_n(t) = 2tT_{n-1}(t) - T_{n-2}(t), \forall n \ge 2.
\end{eqnarray*}
