Detailed Description

Base class for all orthogonal polynomial basis functions.

OrthogonalPolynomialBasisFunction provides common functionality for orthogonal polynomial families such as Legendre, Chebyshev, and Jacobi polynomials. It automatically sets the index as degree + 1 following standard mathematical convention and provides utilities for orthogonal polynomial construction.

Orthogonal polynomials satisfy orthogonality conditions:

\[\int_{a}^{b} P_m(x) P_n(x) w(x) dx = 0, \forall m \neq n. \]

where \(w(x)\) is the weight function.
