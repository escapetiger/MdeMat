Detailed Description

Assembler for constant coefficient operators.

ConstantAssembler assembles diagonal matrices with constant coefficients for each element. This is particularly useful for mass matrices and other operators where each element contributes a uniform coefficient to all its local degrees of freedom.

The assembler creates block-diagonal structures where each element's contribution is a constant value multiplied by the identity matrix of size equal to the number of local degrees of freedom.

% Create constant assembler
assembler = ConstantAssembler(fe, mesh, op);
% Assemble diagonal matrix with element-wise coefficients
coeffs = [1.0, 2.0, 1.5]; % One coefficient per element
matrix = assembler.assemble(coeffs);
% Mass matrix assembly
density = ones(mesh.nTotalElements, 1);
massMatrix = assembler.assemble(density);

function fem::assembly::ConstantAssembler::assemble ( InputType obj,
InputType c )

Assemble diagonal matrix with constant coefficients.

A = assemble(obj, c) creates a diagonal sparse matrix where each element contributes a constant coefficient repeated for all its local degrees of freedom. The resulting matrix is block-diagonal with each block being a scaled identity.

Parameters
obj- The ConstantAssembler object
c- Vector of coefficients, one per element (length nTotalElements)
Return values
A- Assembled diagonal sparse matrix of size nGlobalDofs×nGlobalDofs
