Detailed Description

Base class for all geometries.

Geometry defines common properties and interfaces of a geometry.

Determines if points are inside the geometry.

TF = isInside(obj, X) tests whether specified points are contained within the interior of the geometric domain, excluding its boundary. Concrete subclasses must implement this method to define the containment test for their specific geometry type.

◆ magnitude()

function core::geometry::Geometry::magnitude ( InputType obj)

Returns the measure (size) of the geometry.

m = magnitude(obj) returns the measure of the geometric domain, which depends on the dimension: length in 1D, area in 2D, volume in 3D, and hypervolume in higher dimensions. Concrete subclasses must implement this method to define how the geometric measure is calculated.

Parameters
obj- The Geometry object
Return values
m- The measure (size) of the geometric domain
