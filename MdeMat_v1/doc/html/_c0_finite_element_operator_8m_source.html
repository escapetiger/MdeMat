1classdef C0FiniteElementOperator < fem.element.FiniteElementOperator
2 % C0FINITEELEMENTOPERATOR Operator for continuous finite elements.
3 %
4 % C0FiniteElementOperator provides differential operators such as
5 % gradient for C0 finite elements. It manages bilinear form data
6 % for volume integrals and constructs discrete operator matrices
7 % used in conforming finite element methods.
8 %
9 % The class handles the assembly of discrete differential operators
10 % by pre-computing bilinear forms involving function derivatives
11 % at quadrature points. This enables efficient construction of
12 % system matrices for elliptic and parabolic problems.
13 %
14 % For C0 elements, operators only involve volume integrals since
15 % function continuity across element boundaries eliminates the
16 % need for explicit flux terms in the weak formulation.
17 %
18 % Examples:
19 % % Create C0 element and its operator
20 % element = fem.element.C0FiniteElement(geometry, projector, integrator);
21 % element.setVolumeData(1); % Include first derivatives
22 % operator = C0FiniteElementOperator(element);
23 %
24 % % Set up operator data and access gradient
25 % operator.setVolumeData();
26 % gradOp = operator.gradient;
27 %
28 % % Use gradient components for stiffness matrix assembly
29 % gradX = gradOp.volumeData(1).matrix; % ∂/∂x component
30 % gradY = gradOp.volumeData(2).matrix; % ∂/∂y component
31 %
32 % See also:
33 % fem.element.FiniteElementOperator, fem.element.L2FiniteElementOperator,
34 % fem.element.C0FiniteElement
