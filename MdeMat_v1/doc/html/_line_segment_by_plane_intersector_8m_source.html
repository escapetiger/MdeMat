4 % LineSegmentByPlaneIntersector computes intersection points between
5 % line segments and planes in n-dimensional space (\f$n \ge 2\f$).
6 % Line segments are defined by their endpoints, and planes are
7 % defined by normal vectors and offset constants.
8 %
9 % The line segment is parameterized as:
10 % \f[
11 % L(t) = X1 + t*(X2 - X1), t \in [0,1]
12 % \f]
13 % The plane is defined by the equation:
14 % \f[
15 % a^T * x + b = 0,
16 % \f]
17 % where \f$a\f$ is the normal vector to the plane and \f$b\f$ is
18 % the offset constant.
19 %
20 % Examples:
21 % % Create a 3D line-plane intersector
22 % intersector = LineSegmentByPlaneIntersector(3);
23 %
24 % % Define a line segment
25 % X1 = [0; 0; 0]; % First endpoint
26 % X2 = [1; 1; 1]; % Second endpoint
27 %
28 % % Define a plane: x + y + z - 1 = 0
29 % a = [1; 1; 1]; % Normal vector
30 % b = -1; % Offset constant
31 %
32 % % Compute intersection
33 % [intersectionPoint, isValid] = intersector.intersect(X1, X2, a, b);
34 %
35 % Notes:
36 % The method handles parallel and coincident cases appropriately.
37 % If a line segment lies entirely on a plane, all points are
38 % considered intersection points.
39 %
