1classdef L2SemiLagrangianFiniteElementOperator < fem.element.C0SemiLagrangianFiniteElementOperator
2 % L2SEMILAGRANGIANFINITEELEMENTOPERATOR Semi-Lagrangian operator for
3 % discontinuous finite elements.
4 %
5 % L2SemiLagrangianFiniteElementOperator extends the C0 semi-Lagrangian
6 % operator with flux piece contributions for L2 finite elements.
7 % It manages both volume piece and flux piece bilinear form data
8 % required for semi-Lagrangian discontinuous Galerkin methods.
9 %
10 % The operator handles the complex geometric intersections that arise
11 % when discontinuous elements track fluid parcels backward along
12 % characteristic curves. Both element interiors and boundaries
13 % contribute to the transport operator through specialized piece-wise
14 % integration procedures.
15 %
16 % This combination of semi-Lagrangian time stepping with discontinuous
17 % Galerkin spatial discretization is particularly powerful for
18 % convection-dominated flows with discontinuous solutions, providing
19 % both stability and accuracy without excessive numerical diffusion.
20 %
21 % Examples:
22 % % Create semi-Lagrangian operator for L2 element
23 % element = fem.element.L2FiniteElement(geometry, projector, volInt, fluxInt);
24 % clipper = SomeClipperImplementation();
25 % operator = L2SemiLagrangianFiniteElementOperator(element, clipper);
26 %
27 % % Set up piece data for both volume and flux
28 % operator.setVolumePieceData();
29 % operator.setFluxPieceData();
30 % gradOp = operator.gradient;
31 %
32 % % Access volume and flux piece contributions
33 % volPieces = gradOp.volumePieceData;
34 % fluxPieces = gradOp.fluxPieceData;

71 %
72 % setFluxPieceData(obj) creates bilinear form matrices for

74 % boundaries with upstream footprints. These matrices enable
75 % accurate computation of flux terms in semi-Lagrangian
76 % discontinuous Galerkin methods.
77 %
78 % Inputs:
79 % obj - The L2SemiLagrangianFiniteElementOperator object
80 %
81 % Outputs:
82 % NULL

84 De = obj.clipper.fluxEulerianData;
85 Du = obj.clipper.fluxUpstreamData;
86 nf = length(De);

89 %< Initialize flux piece data for each boundary
90 obj.fluxPieceData = cell(1, nf);
