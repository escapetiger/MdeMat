Detailed Description

Function space generated from finite element.

Provides an abstract representation of a function space that is constructed from a finite element. Serves as the base class for specialized function spaces such as affine and mesh spaces.

% Create concrete finite element spaces
affineSpace = AffineSpace(finiteElement);
meshSpace = MeshSpace(finiteElement, mesh);
