Detailed Description

Backward Differentiation Formula integrator base class.

BdfIntegrator implements multi-step Backward Differentiation Formula (BDF) methods for solving ordinary differential equations of the form:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + S, \]

where \(M\) is a mass operator, \(L\) is a linear operator, and \(S\) is a source term. BDF methods use multiple previous time steps to achieve higher- order accuracy and are A-stable, making them suitable for stiff problems.

BDF methods are implicit and require solving linear systems at each time step. They are particularly effective for stiff ODEs where explicit methods would require prohibitively small time steps.

% Cannot instantiate abstract class directly
% Use concrete subclasses instead:
integrator = approx.odeint.Bdf2Integrator(1.0);
% Full implicit problem with all terms
U_new = integrator.step(L, S, M);
integrator.update(U_new);
integrator.advance();
% Pure diffusion (only linear term)
U_new = integrator.step(L, [], []);
% Pure forcing (only source term)
U_new = integrator.step([], S, []);
