Detailed Description

Unit tests for L1MultiIndexer class.

TestL1MultiIndexer provides test coverage for L1MultiIndexer functionality including index generation, caching, and conversion between multi-indices and linear indices.

% Run all tests
results = runtests(core.linalg.tests.TestL1MultiIndexer);
