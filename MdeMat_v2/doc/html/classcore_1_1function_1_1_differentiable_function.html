Detailed Description

Base class for all differentiable functions.

DifferentiableFunction extends the Function class to add support for computing derivatives.

The implementation uses a two-step approach for derivatives:

  1. The public derivative method handles input/output reshaping
  2. The protected derivativeImpl method handles the actual computation

Compute the derivative of specified order at given points.

dY = derivative(obj, X, r) computes the derivative of order specified by the vector r at the points X. The derivative order vector r specifies the partial derivative order for each input dimension.

Compute the Jacobian matrix at specified points.

J = jacobian(obj, X) computes the Jacobian matrix of the function at the specified points. For a function from \(R^n\) to \(R^m\), the Jacobian is an \(m\times n\) matrix of first partial derivatives.

Parameters

X- Coordinates (nDims x ...)
Return values
J- Jacobian tensor (nCodims x nDims x ...)
