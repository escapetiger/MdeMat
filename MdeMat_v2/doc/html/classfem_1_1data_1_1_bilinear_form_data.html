Detailed Description

A collection of data for a bilinear form.

BilinearFormData represents a bilinear form through its matrix representation, computed from function data and derivatives. Each bilinear form corresponds to a weighted inner product between basis functions and their derivatives of the form:

\[a(u, v) = \int_{\Omega} \frac{\partial^i u}{\partial x^i} w(x) \frac{\partial^j v}{\partial x^j} \, dx \]

where \(u\) and \(v\) are basis functions, \(i\) and \(j\) are derivative orders, and \(w(x)\) are integration weights. The discrete representation is computed using quadrature rules.

This class is fundamental in finite element methods for assembling system matrices from weak formulations of differential equations.

% Create empty bilinear form
form = BilinearFormData();
% Create mass matrix (0,0 derivatives)
massForm = BilinearFormData(functionData1, functionData2, 0, 0);
M = massForm.matrix;
% Create stiffness matrix (1,1 derivatives)
stiffForm = BilinearFormData(functionData1, functionData2, 1, 1);
K = stiffForm.matrix;
% Mixed derivative form
mixedForm = BilinearFormData(functionData1, functionData2, 0, 1);

Set the matrix representation of the bilinear form.

obj = setMatrix(obj, D1, D2, i, j) computes the matrix representation as the weighted inner product between function values or derivatives from two function data objects. The computation follows the discrete bilinear form:

\[A_{mn} = \sum_{k} U_k^{(i)}(x_m) w_k V_k^{(j)}(x_n) \]

where \(U^{(i)}\) and \(V^{(j)}\) are the i-th and j-th derivatives, and \(w_k\) are integration weights.

Parameters
obj- The BilinearFormData object
D1- First function data object (FunctionData)
D2- Second function data object (FunctionData)
i- Derivative order for first function (0 for values)
j- Derivative order for second function (0 for values)
Return values
obj- The BilinearFormData object
