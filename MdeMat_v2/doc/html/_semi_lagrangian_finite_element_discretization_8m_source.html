2 % SEMILAGRANGIANFINITEELEMENTDISCRETIZATION Semi-Lagrangian finite
3 % element discretization.
4 %
5 % SemiLagrangianFiniteElementDiscretization extends the standard
6 % finite element discretization with semi-Lagrangian capabilities for
7 % solving advection-dominated problems. It adds element clipping and
8 % semi-Lagrangian operators to handle characteristic tracing and flux
9 % computations across element boundaries.
10 %
11 % The semi-Lagrangian method traces characteristics backward in time
12 % and requires specialized operators to handle the interaction
13 % between the departure points and the finite element mesh structure.
14 %
15 % Examples:
16 % % Create semi-Lagrangian FE discretization
17 % disc = SemiLagrangianFiniteElementDiscretization();
18 % disc.setL2OrthotopeElement('nDims', 2, 'order', 2);
19 % disc.setElementOperator();
20 % disc.setElementClipper();
21 % disc.setSemiLagrangianElementOperator();
22 %
23 % % Set up mesh and advance solution
24 % disc.setUniformGrid([20, 20], [0, 1; 0, 1]);
25 % disc.setMeshSpace();
26 % disc.setDerivativeOrder(1);
27 %
28 % % Access semi-Lagrangian operator for time stepping
29 % slOp = disc.slOperator;
30 % clipper = disc.clipper;
31 %
32 % % Mesh refinement preserves all components
33 % fineMesh = disc.refineMesh(2);
34 %
35 % Notes:
36 % Element and clipper must be set before semi-Lagrangian operator.
37 % The clipper handles geometric intersections for characteristic
38 % foot computations.
39 %
40 % See also:
41 % approx.discretization.FiniteElementDiscretization,
