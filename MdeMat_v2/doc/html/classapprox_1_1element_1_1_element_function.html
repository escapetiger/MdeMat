Detailed Description

Element-level discrete function data.

ElementFunction stores function values and derivatives evaluated at integration nodes, along with the associated quadrature weights. This class provides the fundamental data structure for numerical integration and finite element computations.

The class manages function evaluations at quadrature points and supports efficient computation of integrals involving functions and their derivatives. It serves as a bridge between continuous function representations and discrete numerical computations.

Function derivatives are computed using multi-index notation to handle arbitrary spatial dimensions and derivative orders efficiently.

% Create function data with Gauss quadrature
integrator = approx.integrate.GaussLegendre(5);
funcData = ElementFunction(integrator);
% Set integration points and evaluate function
funcData.setPoints(-1, 1);
f = @(x) sin(pi*x);
funcData.setValues(f, funcData.nodes);
% Compute derivatives
df = DifferentiableFunction(f);
funcData.setDerivatives(df, funcData.nodes, 2);
% Access computed data
values = funcData.values;
firstDeriv = funcData.derivatives{1};
weights = funcData.weights;

InputType f,
InputType X,
InputType k )

Set function derivatives at specified points.

obj = setDerivatives(obj, f, X, k) computes derivatives of the function f up to order k at the specified points X using multi-index notation. The derivatives are stored in the derivatives cell array.

The multi-index approach enables efficient computation of derivatives in arbitrary spatial dimensions, where each derivative is characterized by a multi-index specifying the order of differentiation in each coordinate direction.

obj- The ElementFunction object
f- DifferentiableFunction object with derivative method
