2 % C0ELEMENT Element-level interior-continuous function.
3 %
4 % C0Element implements an element-level function that is continuous
5 % across element interior and supports volume integration. This class
6 % extends the base Element class by adding volume integration
7 % capabilities through pre-computed function data at quadrature
8 % points.
9 %
10 % The class manages function evaluations and derivatives at volume
11 % integration points, enabling efficient assembly of finite element
12 % matrices and vectors. It is designed for conforming finite element
13 % methods where continuity across element boundaries is enforced.
14 %
15 % Examples:
16 % % Create C0 element with quadrature
17 % geometry = core.geometry.Orthotope.unit(2);
18 % basis = approx.basis.LagrangeBasis(2);
19 % projector = approx.project.NodalProjector(basis);
20 % integrator = approx.integrate.GaussLegendre(3);
21 % element = C0Element(geometry, projector, integrator);
22 %
