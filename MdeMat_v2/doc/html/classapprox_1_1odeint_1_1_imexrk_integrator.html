Detailed Description

Implicit-Explicit Runge-Kutta integrator.

ImexrkIntegrator implements IMEX Runge-Kutta methods for solving ordinary differential equations of the form:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + F(u) + S(t), \]

where \(M\) is a mass operator, \(L\) is a linear operator (treated implicitly), \(F(u)\) is a nonlinear operator (treated explicitly), and \(S(t)\) is a source term (treated explicitly). Any of these terms can be empty (indicating they vanish from the equation). This approach allows efficient handling of problems with both stiff linear parts and nonlinear parts that benefit from explicit treatment.

IMEX methods combine the stability of implicit methods for stiff linear terms with the efficiency of explicit methods for nonlinear terms, making them ideal for many PDE applications.

% Basic IMEX problem
integrator = approx.odeint.Ars222Integrator(1.0);
U_new = integrator.step(L, F, S, M);
integrator.update(U_new);
integrator.advance();
% Pure implicit diffusion
U_new = integrator.step(L, [], [], []);
% Mixed implicit-explicit (L implicit, F explicit)
U_new = integrator.step(L, F, [], []);
% Implicit linear with explicit forcing
U_new = integrator.step(L, [], S, []);

Set the left-hand side matrix for stage i.

EXPLICIT PART

Advance one time step using the IMEX RK method.

U = step(obj, L, F, S, M) performs a complete time step by solving implicit stages for the linear term and explicit evaluations for the nonlinear term, then combining according to the Butcher tableau weights. Empty terms are handled gracefully by contributing zero.
