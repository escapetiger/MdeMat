2 % LEBEDEVRULE Lebedev quadrature rule for spherical integration.
3 %
4 % LebedevRule provides highly symmetric integration points on the
5 % surface of a sphere in 3D space. This method is particularly
6 % efficient for integrating functions with spherical symmetry and
7 % offers superior accuracy compared to standard product rules.
8 %
9 % Examples:
10 % % Create a Lebedev rule for 3D sphere
11 % rule = LebedevRule(3);
12 %
13 % % Generate 110 integration points on unit sphere
14 % [X, w] = rule.generate(110);
15 %
16 % % Custom sphere with center and radius
17 % [X, w] = rule.generate(194, false, [1, 0, 0], 2);
18 %
19 % Notes:
20 % Only specific numbers of integration points are available, as
21 % defined in the availableParams property. The method generates
22 % points with exact spherical symmetry.
23 %
