Detailed Description

Grid-based assembly for mixed finite element systems.

MixedGridAssembly extends the Eulerian grid assembly with support for different flux types (left-biased, right-biased, central) used in mixed finite element methods and discontinuous Galerkin schemes.

This class provides the foundation for assembling operators in mixed formulations where different variables may require different flux treatments. It supports various numerical flux choices commonly used in discontinuous methods.

% Create mixed assembly with central flux and Dirichlet BC
assembly = MixedGridAssembly(fe, mesh, op, 1, 3);
% Assemble divergence operator with dimension-specific coefficients
coeffs = [1.0, 0.5]; % coefficients for each dimension
divMatrix = assembly.divergence(coeffs);
% Assemble partial derivative in specific dimension
partialMatrix = assembly.partial(1, 2.0);

obj = MixedGridAssembly(fe, mesh, op, bcType, fluxType) creates an assembly for mixed finite element systems with specified flux type for discontinuous Galerkin methods.

Parameters
