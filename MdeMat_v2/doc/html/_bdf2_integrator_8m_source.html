1classdef Bdf2Integrator < approx.odeint.BdfIntegrator
2 % BDF2INTEGRATOR Second-order BDF integrator.
3 %
4 % Bdf2Integrator implements two-step Backward Differentiation
5 % Formula (BDF) methods for solving ordinary differential equations
6 % of the form:
7 %
8 % \f[
9 % \frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + S,
10 % \f]
11 %
12 % where \f$M\f$ is a mass operator, \f$L\f$ is a linear operator, and
13 % \f$S\f$ is a source term.
14 %
15 % Bdf2Integrator uses the Backward Euler method for the first step.
16 % It acheives second-order accuracy and A-stability.
17 %
18 % Examples:
19 % integrator = approx.odeint.Bdf2Integrator(1.0);
20 % U_new = integrator.step(L, N);
21 % integrator.update(U_new);
22 %
23 % See also:
24 % approx.odeint.BdfIntegrator, approx.odeint.Bdf3Integrator
