1classdef HypersphereIntegrator < approx.integrate.Integrator
2 % HYPERSPHEREINTEGRATOR Numerical integration over hypersphere domains.
3 %
4 % HypersphereIntegrator provides specialized integration capabilities
5 % for functions defined on hyperspheres of arbitrary dimension. It
6 % supports multiple integration methods including Gauss-Trapezoidal,
7 % Lebedev (for 3D), and Monte Carlo approaches.
8 %
9 % Examples:
10 % % Create integrator with Gauss-Trapezoidal rule for 3D sphere
11 % integrator = HypersphereIntegrator(3, 'gauss_trapezoidal');
12 %
13 % % Create integrator with Lebedev rule for 3D sphere
14 % integrator = HypersphereIntegrator(3, 'lebedev');
15 %
16 % % Create integrator with Monte Carlo rule
17 % integrator = HypersphereIntegrator(4, 'monte_carlo', 12345);
18 %
19 % Notes:
20 % Lebedev rules are only available for 3D spheres and provide highly
21 % symmetric integration points. Monte Carlo methods are suitable for
22 % high-dimensional problems and discontinuous integrands.
23 %
24 % See also:
25 % approx.integrate.Integrator,
26 % approx.integrate.SphericalGaussTrapezoidalRule,
27 % approx.integrate.LebedevRule,
28 % approx.integrate.SphericalMonteCarloRule
