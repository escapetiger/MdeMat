2 % STATE Solution state for advection problems.
3 %
4 % The State class encapsulates the complete solution state for
5 % advection problems, managing both spatial discretization
6 % information and degrees of freedom data. It provides a unified
7 % container for all components needed to represent and evolve
8 % the numerical solution.
9 %
10 % The class uses handle semantics to enable efficient state
11 % management during time integration without unnecessary copying
12 % of large data structures.
13 %
14 % Examples:
15 % % Create state with spatial discretization
16 % state = State(spatialDiscretization);
17 %
18 % % Access discretization and solution data
19 % mesh = state.xDisc.mesh;
20 % solution = state.dofs.U;
21 %
22 % % Update solution data
23 % state.dofs.U = newSolutionVector;
24 %
25 % Notes:
26 % The handle-based design allows for efficient passing of state
27 % objects between methods without copying large arrays.
28 %
29 % See Also:
30 % physics.Scheme, physics.advection.SldgScheme,
