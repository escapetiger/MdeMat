1classdef ElementClipper < handle
2 % ELEMENTCLIPPER Base class for all element clippers.
3 %
4 % ElementClipper provides the foundation for geometric clipping
5 % operations in semi-Lagrangian finite element methods. Clippers
6 % handle the complex geometric intersections that arise when tracking
7 % fluid parcels backward along characteristic curves, computing the
8 % overlap between Eulerian elements and upstream footprints.
9 %
10 % The clipping process is essential for accurate semi-Lagrangian
11 % transport calculations, as it determines the integration domains
12 % for coupling Eulerian and Lagrangian data. This involves computing
13 % intersections between the current element and the region occupied
14 % by fluid parcels at the previous time step.
15 %
16 % Clippers organize the resulting geometric pieces and set up
17 % appropriate quadrature rules for accurate integration over
18 % these potentially complex domains. The geometric decomposition
19 % enables efficient and accurate computation of transport operators
20 % while handling the complex geometries that arise from characteristic
21 % tracking in convection-dominated flows.
22 %
23 % See also:
24 % approx.element.C0ElementClipper, approx.element.L2ElementClipper,
25 % approx.element.SemiLagrangianElementOperator
