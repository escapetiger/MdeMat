function core::validate::hasFields ( InputType s,
InputType f )

Check if a struct s has all specified fields f.

tf = hasFields(s, f) returns true if struct s contains all fields specified in f.

Parameters
s- Structure to check
f- Field name (string/char) or cell array of field names
Return values
tf- True if all fields exist, false otherwise
% Single field check
s = struct('name', 'John', 'age', 30);
tf = hasFields(s, 'name'); % Returns true
% Multiple fields check
tf = hasFields(s, {'name', 'age'}); % Returns true
% Empty field list
tf = hasFields(s, {}); % Returns true

function core::validate::isAllClass ( InputType x,
InputType cls )

Check if all elements of x belong to cls.

tf = isAllClass(x, cls) returns true if all elements in x belong to one of the classes specified in cls.

Parameters
x- Element(s) (object array or cell array)
cls- Class name(s) (string or cell array of strings)
Return values
tf- True only if all elements belong to the specified class(es)
% Check if all elements are numeric
tf = isAllClass([1, 2, 3], 'double');
% Check multiple allowed classes
mixedData = {1, 2.5, int32(3)};
tf = isAllClass(mixedData, {'double', 'int32'});
% Empty array returns true
tf = isAllClass([], 'any_class');

function core::validate::isAllSameClass ( VariableInputType varargin)

Check if all inputs belong to the same class.

tf = isAllSameClass(X1, X2, ...) returns true if all inputs belong to the same class. For a single input argument, always returns true.

Parameters
varargin- Input arguments lists
Return values
tf- True if all input arguments have the same class
% Check if all inputs are the same numeric type
result = isAllSameClass(1.0, 2.0, 3.0); % returns true
% Check mixed types
result = isAllSameClass(1.0, int32(2), 3.0); % returns false
% Check objects of the same class
obj1 = containers.Map();
obj2 = containers.Map();
result = isAllSameClass(obj1, obj2); % returns true
% Single input always returns true
result = isAllSameClass(42); % returns true
