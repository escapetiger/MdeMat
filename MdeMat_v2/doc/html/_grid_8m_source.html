2 % GRID Abstract base class for multidimensional structured grids.
3 %
4 % Grid provides a foundation for representing multidimensional
5 % structured grids using memory-efficient tensor-based storage.
6 % This abstract class defines common properties and methods for
7 % querying grid characteristics, connectivity, and performing
8 % grid-based operations.
9 %
10 % Examples:
11 % % Cannot instantiate abstract class directly
12 % % Use concrete subclasses instead:
13 % uniformGrid = approx.mesh.UniformGrid([10, 10], [0, 0, 1, 1]);
14 % nonuniformGrid = approx.mesh.NonuniformGrid({0:0.1:1, [0, 0.2, 0.5, 1]});
15 %
16 % Notes:
17 % This is an abstract class that cannot be instantiated directly.
18 % Concrete subclasses must implement the collocate and refine methods,
19 % as well as the protected abstract methods for grid-specific operations.

180 % SETBOUNDARY Initialize boundary element indices.
181 %
182 % obj = setBoundary(obj) creates factor index arrays for
183 % boundary elements on each face of the grid domain.
184 %
185 % Inputs:
186 % obj - The Grid object
187 %
188 % Outputs:
189 % obj - The Grid object
190
191 obj.boundary = cell(1, 2*obj.nDims);
192 for i = 1:obj.nDims
193 b = arrayfun(@(r) 1:r, obj.resolution, 'Un', 0);
194 b{i} = 1;
195 obj.boundary{2*i-1} = b;
196 b{i} = obj.resolution(i);
197 obj.boundary{2*i} = b;
