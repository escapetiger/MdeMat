Detailed Description

Grid-based assembly for structured meshes.

GridAssembly provides assembly methods for finite element operators on structured grid meshes. This class extends the base Assembly to handle grid-specific operations and boundary condition treatments.

The assembly supports different boundary condition types and provides specialized methods for handling Dirichlet boundary conditions on structured grids.

% Create grid assembly with periodic boundaries
assembly = GridAssembly(fe, gridMesh, op, 0);
% Create grid assembly with Dirichlet boundaries
assembly = GridAssembly(fe, gridMesh, op, 1);
