Detailed Description

Base class for all symbolic compilers.

Compiler provides a unified interface for generating, compiling, and storing basis matrices from various symbolic function types. It manages a centralized repository of pre-computed basis matrices for efficient reuse across the core package.

The compiler creates function handle matrices for basis functions and their derivatives, stores them with metadata for later retrieval, and provides utilities for managing the compiled function repository.
