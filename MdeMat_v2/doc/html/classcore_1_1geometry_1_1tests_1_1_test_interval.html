Detailed Description

Unit tests for the Interval class.

This test class validates the functionality of the Interval class, which represents one-dimensional intervals on the real line using the bbox format [lower, upper]. Tests include construction with various parameters, validation of boundary inclusion properties, testing points for inside/boundary conditions, and verifying string representation.
