4 % Hyperball represents a generalized geometric domain that extends
5 % the concept of filled circles and solid spheres to arbitrary
6 % dimensions. It represents the region enclosed by an
7 % \f$(n-1)\f$-dimensional sphere in n-dimensional Euclidean space.
8 % Dimensional representations:
9 % - 1-ball: A line segment

66 function m = magnitude(obj)
67 % MAGNITUDE Returns the volume of the hyperball.
68 %
69 % m = magnitude(obj) computes the n-dimensional volume of the
70 % hyperball using the general formula for hyperballs. Special
71 % cases are optimized for common dimensions (1D, 2D, 3D) for
72 % computational efficiency and accuracy.
73 %
74 % Inputs:
75 % obj - The Hyperball object
76 %
77 % Outputs:
78 % m - Volume of the hyperball
79
80 d = obj.nDims;
81 r = obj.radius;
82 switch d
83 case 1
84 m = 2 * r;
85 case 2
86 m = pi * r^2;
87 case 3
88 m = 4 / 3 * pi * r^3;
89 otherwise
90 m = pi^(d / 2) / gamma(d/2+1) * r^d;
91 end
92 end
