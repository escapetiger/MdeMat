Abstract class for functions with compiled metadata.

from the core.symbolic module.

CompiledFunction automatically loads precompiled function handles and metadata from the +core/metadata/basis directory. This provides a bridge between symbolic function definitions and efficient numerical evaluation.

The class supports automatic metadata discovery, caching, and efficient function evaluation using precompiled function handles.

core.function.Function
core.function.DifferentiableFunction

functions with metadata support.

This class combines the capabilities of CompiledFunction and DifferentiableFunction to provide automatic metadata loading and efficient derivative evaluation using precompiled function handles.

The class automatically discovers and loads compiled metadata from the +core/metadata/basis directory, providing both function evaluation and derivative computation capabilities.

core.function.DifferentiableFunction

differentiation.

A DifferentiableFunction extends the Function class to add support for computing derivatives. This represents the mathematical concept of a differentiable function from R^n to R^m.

The implementation uses a two-step approach for derivatives:

  1. The public derivative method handles input/output reshaping
  2. The protected derivativeImpl method handles the actual computation

core.function.Function

space to Euclidean space.

A Function represents a mathematical mapping from R^n to R^m, which can be evaluated at specified points. This class defines the interface for all function types in the system.

The implementation uses a two-step evaluation process:

  1. The public evaluate method handles input/output reshaping
  2. The protected evaluateImpl method handles the actual computation
