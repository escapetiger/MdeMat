Detailed Description

Base class for all Galerkin-type projectors.

GalerkinProjector provides the foundation for Galerkin approximation methods where functions are projected onto finite-dimensional spaces using mass operators to solve linear systems. The class implements the core Galerkin methodology for function approximation.

The Galerkin method seeks an approximation \(u_h \in V_h\) of a function \(u\) such that

\[\langle u_h, v_h\rangle = \langle f, v_h\rangle, \forall v_h ∈ V_h, \]

where \(V_h\) is the finite-dimensional function space spanned by the basis.

This class defines the interface for concrete implementations such as modal and nodal projectors, which differ in how they construct the mass operator and embed data into the latent space.

function approx::project::GalerkinProjector::project ( InputType obj,
InputType F )

Project data onto the function space.

U = project(obj, F) projects data from the latent space onto the function space by solving the Galerkin system M*U = F, where M is the mass operator. Handles well-posed and overdetermined systems automatically.
