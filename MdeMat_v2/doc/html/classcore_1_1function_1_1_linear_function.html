Detailed Description

Function representing affine transformations.

LinearFunction represents affine transformations of the form:

\[f(x) = A*x + b \]

where \(A\) is an \(m\times n\) matrix and \(b\) is an \(m\times 1\) vector. When \(b\) is not provided or is zero, this reduces to a pure linear transformation.

% Pure linear transformation f(x) = A*x
A = [1 2; 3 4];
f = LinearFunction(A); % R^2 -> R^2
% Affine transformation f(x) = A*x + b
b = [1; -1];
f = LinearFunction(A, b); % R^2 -> R^2
% Evaluate
X = rand(2, 100);
Y = f.evaluate(X);

Implementation of linear function derivative.

dY = derivativeImpl(obj, X, r) computes derivatives of the linear function. For first-order derivatives, this returns the appropriate columns/rows of matrix A. Higher-order derivatives are zero since linear functions have constant first derivatives.
