2 % ESDIRK3INTEGRATOR Third-order ESDIRK integrator.
3 %
4 % Esdirk3Integrator implements a third-order ESDIRK method with three
5 % stages for solving ordinary differential equations of the form:
6 %
7 % \f[
8 % \frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + S,
9 % \f]
10 %
11 % where \f$M\f$ is a mass operator, \f$L\f$ is a linear operator, and
12 % \f$S\f$ is a source term. This method features an explicit first
13 % stage (\f$c_1 = 0\f$) followed by two implicit stages, providing
14 % computational efficiency while maintaining good stability properties.
15 %
16 % The parameter \f$\gamma = (3 + \sqrt{3})/6 \approx 0.7886751346\f$
17 % ensures third-order accuracy and A-stability. The explicit first
18 % stage reduces computational cost compared to fully implicit methods.
19 %
20 % Examples:
21 % % Basic usage
22 % integrator = approx.odeint.Esdirk3Integrator(1.0);
23 % U_new = integrator.step(L, S, M);
24 % integrator.update(U_new);
25 % integrator.advance();
26 %
27 % % Pure diffusion (only linear term)
28 % U_new = integrator.step(L, [], []);
29 %
30 % % Pure forcing (only source term)
31 % U_new = integrator.step([], S, []);
32 %
33 % % With mass matrix
34 % U_new = integrator.step(L, S, M);
35 %
36 % See also:
37 % approx.odeint.DirkIntegrator, approx.odeint.Sdirk2Integrator,
38 % approx.odeint.Sdirk3Integrator
39
