Detailed Description

Real-valued spherical harmonic basis functions.

SphericalHarmonicBasisFunction represents real-valued spherical harmonic basis functions on the canonical domain \(\mu\in[-1,1]\) and \(\theta\in[0,2\pi]\). The functions are constructed using associated Legendre polynomials and trigonometric functions.

The spherical harmonic function with degree \(l\) and order \(m\) are:

  • \((l^2+1)\)-th function (zonal harmonics, \(m=0\)): \(P_l^0(\mu)\)
  • \((l^2+2m-1)\)-th function (tesseral harmonics, \(m>0\)): \(\cos(m\theta)P_l^m(\mu)\)
  • \((l^2 + 2m)\)-th function (tesseral harmonics, \(m>0\)): \(\sin(m\theta)P_l^m(\mu)\)
% Zonal harmonic (constant)
basis1 = core.symbolic.SphericalHarmonicBasisFunction(1); % P_0^0(mu) = 1
% First degree harmonics
basis2 = core.symbolic.SphericalHarmonicBasisFunction(2); % P_1^0(mu) = mu
basis3 = core.symbolic.SphericalHarmonicBasisFunction(3); % cos(theta)*P_1^1(mu)
basis4 = core.symbolic.SphericalHarmonicBasisFunction(4); % sin(theta)*P_1^1(mu)
