2 % L2SEMILAGRANGIANELEMENTOPERATOR Semi-Lagrangian operator for discontinuous finite elements.
3 %
4 % L2SemiLagrangianElementOperator extends the C0 semi-Lagrangian
5 % operator with flux piece contributions for L2 finite elements.
6 % It manages both volume piece and flux piece bilinear form data
7 % required for semi-Lagrangian discontinuous Galerkin methods.
8 %
9 % The operator handles the complex geometric intersections that arise
10 % when discontinuous elements track fluid parcels backward along
11 % characteristic curves. Both element interiors and boundaries
12 % contribute to the transport operator through specialized piece-wise
13 % integration procedures.
14 %
15 % This combination of semi-Lagrangian time stepping with discontinuous
16 % Galerkin spatial discretization is particularly powerful for
17 % convection-dominated flows with discontinuous solutions, providing
18 % both stability and accuracy without excessive numerical diffusion.
19 % The method can handle large time steps while maintaining sharp
20 % resolution of solution features.
21 %
22 % Examples:
23 % % Create semi-Lagrangian operator for L2 element
24 % element = approx.element.L2Element(geometry, projector, volInt, fluxInt);
25 % clipper = SomeClipperImplementation();
26 % operator = L2SemiLagrangianElementOperator(element, clipper);
27 %
28 % % Set up piece data for both volume and flux
29 % operator.setVolumePieceData();
30 % operator.setFluxPieceData();
31 % gradOp = operator.gradient;
32 %
33 % % Access volume and flux piece contributions
34 % volPieces = gradOp.volumePieceData;
35 % fluxPieces = gradOp.fluxPieceData;
36 %
37 % % Process piece-wise structure
38 % nVolPieces = size(volPieces, 2);
39 % nFluxPieces = cellfun(@(x) size(x, 2), fluxPieces);

78 function obj = setFluxPieceData(obj)
79 % SETFLUXPIECEDATA Set up bilinear form data for flux piece integrals.
80 %
81 % obj = setFluxPieceData(obj) creates bilinear form matrices
82 % for each flux piece resulting from the intersection of
83 % element boundaries with upstream footprints. These matrices
84 % enable accurate computation of flux terms in
85 % semi-Lagrangian discontinuous Galerkin methods.
86 %
87 % The flux piece structure accounts for the fact that element
88 % boundaries may intersect with multiple upstream boundary
89 % pieces, each requiring separate treatment for inflow and
90 % outflow contributions in the DG formulation.
91 %
92 % Inputs:
93 % obj - The L2SemiLagrangianElementOperator object
94 %
95 % Outputs:
96 % obj - The L2SemiLagrangianElementOperator object
97
98 De = obj.clipper.fluxEulerianData;
99 Du = obj.clipper.fluxUpstreamData;
100 nf = length(De);
101 np = obj.clipper.nFluxPieces;
102
103 %< Initialize flux piece data for each boundary
104 obj.fluxPieceData = cell(1, nf);
105 for i = 1:nf
106 f = @(k, l) approx.element.ElementBilinearForm(De{i}(k, l), Du{i}(k, l), 0, 0);
107 K = repmat((1:2).', 1, np(i));
108 L = repmat(1:np(i), 2, 1);
109 obj.fluxPieceData{i} = arrayfun(f, K, L);
110 end
111 end
