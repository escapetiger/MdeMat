Detailed Description

Three-dimensional vector class for geometric operations.

This class represents a three-dimensional vector with basic arithmetic operations, geometric transformations, and utility methods. It inherits from handle to provide reference semantics for efficient manipulation of vector objects.

v1 = Vector3D(1, 2, 3);
v2 = Vector3D([4, 5, 6]);
result = v1.add(v2);
magnitude = v1.norm();
