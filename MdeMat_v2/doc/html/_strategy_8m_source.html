2 % STRATEGY Abstract base class for data rendering strategies.

4 % Strategy defines the interface and common functionality for all
5 % rendering strategies used in data visualization. This class
6 % provides mode-based rendering control, variable-to-axis mapping
7 % capabilities, and utility methods for coordinated multi-panel
8 % visualizations.

101 % RENDERSEQUENTIAL Render variables in sequential order.

103 for j = 1:length(varNames)
