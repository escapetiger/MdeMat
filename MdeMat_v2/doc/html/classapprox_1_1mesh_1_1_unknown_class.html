Detailed Description

Abstract base class for multi-dimensional grids.

Abstract base class for time discretization.

This abstract class defines common properties for representing multi-dimensional structured grids using memory-efficient tensor-based storage. It provides methods to query grid properties and connectivity.

Timeline represents a sequence of time points and provides basic functionality for time stepping in numerical simulations.
