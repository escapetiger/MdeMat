Detailed Description

Fourth-order SDIRK integrator.

Sdirk4Integrator implements a fourth-order SDIRK method with five stages for solving ordinary differential equations of the form:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + S, \]

where \(M\) is a mass operator, \(L\) is a linear operator, and \(S\) is a source term. This method provides high-order accuracy with good stability properties for stiff problems. The diagonal elements of the Butcher tableau are identical.

The method uses \(\gamma = 1/4\), which provides A-stability and good damping properties. The method requires five implicit solves per time step but achieves fourth-order accuracy, making it suitable for problems requiring high precision.

% Basic usage
integrator = approx.odeint.Sdirk4Integrator(1.0);
U_new = integrator.step(L, S, M);
integrator.update(U_new);
integrator.advance();
% Pure diffusion (only linear term)
U_new = integrator.step(L, [], []);
% Pure forcing (only source term)
U_new = integrator.step([], S, []);
% With mass matrix
U_new = integrator.step(L, S, M);
