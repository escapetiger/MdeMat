Detailed Description

Numerical integration on orthotope faces.

OrthotopeFaceIntegrator provides specialized integration capabilities for functions defined on the faces (boundaries) of multidimensional orthotopes (hyperrectangles). Each face is identified by an index and corresponds to fixing one coordinate at either its minimum or maximum value.

% Create integrator for face 1 of a 3D orthotope
integrator = OrthotopeFaceIntegrator(3, 'gauss_legendre', 1);
% Using existing rule object
rule = approx.integrate.SeparableRule.gaussLobatto(2);
integrator = OrthotopeFaceIntegrator(rule, 3);
