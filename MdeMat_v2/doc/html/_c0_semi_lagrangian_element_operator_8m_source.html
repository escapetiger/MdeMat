2 % C0SEMILAGRANGIANELEMENTOPERATOR Semi-Lagrangian operator for
3 % continuous finite elements.
4 %
5 % C0SemiLagrangianElementOperator implements semi-Lagrangian
6 % operators for C0 finite elements. It manages piece-wise bilinear
7 % form data for volume integrals that arise from the intersection
8 % of Eulerian elements with upstream footprints in semi-Lagrangian
9 % transport schemes.
10 %
11 % The operator handles the complex geometry resulting from tracking
12 % fluid parcels backward along characteristic curves. Each Eulerian
13 % element may intersect with multiple upstream elements, creating
14 % a piecewise structure that requires specialized integration
15 % and assembly procedures.
16 %
17 % This approach is particularly effective for advection-dominated
18 % problems where traditional Eulerian methods suffer from numerical
19 % diffusion or require prohibitively small time steps for stability.
20 % The semi-Lagrangian approach allows for larger time steps while
21 % maintaining accuracy and stability.
22 %
23 % Examples:
24 % % Create semi-Lagrangian operator for C0 element
25 % element = approx.element.C0Element(geometry, projector, integrator);
26 % clipper = SomeClipperImplementation();
27 % operator = C0SemiLagrangianElementOperator(element, clipper);
28 %
29 % % Set up piece data and access operators

88 function obj = setVolumePieceData(obj)
89 % SETVOLUMEPIECEDATA Set up bilinear form data for volume piece
90 % integrals.
91 %
92 % obj = setVolumePieceData(obj) creates bilinear form
93 % matrices for each volume piece resulting from the
94 % intersection of Eulerian and upstream elements. These
95 % matrices enable accurate integration over the complex
96 % geometries arising in semi-Lagrangian methods.
97 %
98 % The piece-wise structure accounts for the fact that each
99 % Eulerian element may overlap with multiple upstream
100 % elements, requiring separate integration over each
101 % intersection region.
102 %
103 % Inputs:
104 % obj - The C0SemiLagrangianElementOperator object
105 %
106 % Outputs:
107 % obj - The C0SemiLagrangianElementOperator object
108
109 De = obj.clipper.volumeEulerianData;
110 Du = obj.clipper.volumeUpstreamData;
111 np = obj.clipper.nVolumePieces;
112 nr = De.nDerivatives;
113 f = @(i, j) approx.element.ElementBilinearForm(De(j), Du(j), i, 0);
114 I = repmat((0:nr).', 1, np);
115 J = repmat(1:np, nr+1, 1);
116 obj.volumePieceData = arrayfun(f, I, J);
117 end
118 end
