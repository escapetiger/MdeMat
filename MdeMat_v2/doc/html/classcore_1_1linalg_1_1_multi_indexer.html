Detailed Description

Indexers handling multi-dimensional indexing.

MultiIndexer generates multi-indices for tensor operations and provides methods to convert between multi-indices and linear indices.

% Create 3D multi-indexer and generate indices
indexer = core.linalg.MultiIndexer([2,3,4]);
M = indexer.generate();
L = indexer.multiToLinear(M);

Convert multi-indices to linear indices.

L = multiToLinear(obj, M) converts multi-indices M to linear indices based on tensor dimensions.

L = multiToLinear(obj, M, bc) uses boundary condition bc.

Parameters

bc- Boundary condition (optional, default: 1)
*0: periodic boundary (wrap-around)
*1: strict boundary (default, out-of-range set to 0)
