Detailed Description

Base class for finite element assembly operations.

Assembly provides the foundation for assembling discrete operators from element-level contributions in finite element methods. It encapsulates the common interface and data structures needed to transform local element operators into global system matrices.

The assembly process involves iterating over mesh elements, extracting local operators from element data, and accumulating contributions into global sparse matrices using appropriate connectivity information from the mesh space.
