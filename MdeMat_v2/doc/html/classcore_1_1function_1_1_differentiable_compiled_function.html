Detailed Description

Base class for compiled differentiable functions.

DifferentiableCompiledFunction combines the capabilities of CompiledFunction and DifferentiableFunction to provide automatic metadata loading and efficient derivative evaluation using precompiled function handles.

The class automatically discovers and loads compiled metadata from the configuration directory, providing both function evaluation and derivative computation capabilities with optimal performance.

% Create and use differentiable compiled function
func = MyDifferentiableCompiledFunction();
func = func.autoLoad();
% Evaluate function and its derivative
x = linspace(0, 1, 100);
y = func.evaluate(x);
dy = func.derivative(x, 1); % First derivative
