Detailed Description

Compiled orthogonal polynomial basis functions.

OrthogonalBasisFunction represents a set of orthogonal polynomial basis functions (such as Legendre or Chebyshev polynomials) with automatic metadata loading from the core.symbolic compilation system.

The class automatically discovers appropriate metadata files based on the specified basis type, interval type, and number of basis functions, providing efficient evaluation of both function values and derivatives through precompiled function handles.

Supported orthogonal polynomial families:

  • Legendre polynomials: orthogonal on \([-1,1]\) with weight \(w(x) = 1\)
  • Chebyshev polynomials: orthogonal on \([-1,1]\) with weight \(w(x) = \frac{1}{\sqrt{1-x^2}}\)
  • Monic Legendre: Legendre polynomials with leading coefficient = 1
% Standard Legendre basis on unit interval
basis = OrthogonalBasisFunction(5, 'legendre', 'unit');
basis = basis.autoLoad();
y = basis.evaluate([0.25]);
dy = basis.derivative([0.25], [1]);
% Monic Legendre polynomials on canonical interval
basis = OrthogonalBasisFunction(4, 'monic_legendre', 'canonical');
basis = basis.autoLoad();
% Chebyshev polynomials with manual loading
basis = OrthogonalBasisFunction(6, 'chebyshev', 'unit');
basis = basis.load('chebyshev_unit_6');
