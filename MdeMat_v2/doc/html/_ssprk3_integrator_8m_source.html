2 % SSPRK3INTEGRATOR Third-order SSPRK integrator.
3 %
4 % Ssprk3Integrator implements the SSPRK3 method, a third-order
5 % explicit scheme for solving ordinary differential equations of the
6 % form:
7 %
8 % \f[
9 % \frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + F(u) + S(t),
10 % \f]
11 %
12 % where \f$M\f$ is a mass operator, \f$L\f$ is a linear operator,
13 % \f$F(u)\f$ is a nonlinear operator, and \f$S(t)\f$ is a source term.
14 % This method is designed to preserve strong stability properties,
15 % making it particularly suitable for hyperbolic conservation laws
16 % and problems where monotonicity preservation is important.
17 %
18 % SSPRK3 maintains the total variation diminishing (TVD) property
19 % under appropriate CFL conditions. The method uses three stages
20 % with specific coefficients designed to preserve stability properties
21 % of the spatial discretization.
22 %
23 % Examples:
24 % % Basic usage with all terms
25 % integrator = approx.odeint.Ssprk3Integrator(1.0);
26 % U_new = integrator.step(L, F, S, M);
27 % integrator.update(U_new);
28 % integrator.advance();
29 %
30 % % Pure advection (only nonlinear term)
31 % U_new = integrator.step([], F, [], []);
32 %
33 % % Hyperbolic conservation law
34 % U_new = integrator.step([], F, S, []);
35 %
36 % % Linear advection with forcing
37 % U_new = integrator.step(L, [], S, []);
38 %
39 % Notes:
40 % SSPRK3 is particularly effective for problems involving discontinuous
41 % solutions or steep gradients where maintaining monotonicity and
42 % avoiding spurious oscillations is critical.
43 %
44 % See also:
45 % approx.odeint.ExrkIntegrator, approx.odeint.Exrk4Integrator,
46 % approx.odeint.HeunIntegrator
47
