2 % FINITEELEMENTOPERATOR Base class for finite element operators.
3 %
4 % FiniteElementOperator provides a foundation for operators that act
5 % on finite element spaces, such as gradient, divergence, curl, and
6 % other differential operators. This abstract base class maintains
7 % a reference to the underlying finite element and provides common
8 % functionality for all derived operator classes.
9 %
10 % Finite element operators encapsulate the discrete forms of
11 % differential operators, enabling efficient computation of terms
12 % in weak formulations of partial differential equations. They
13 % bridge the gap between continuous differential operators and
14 % their discrete matrix representations.
