Detailed Description

Grid-based assembler for diffusion operators.

DiffusionGridAssembler provides assembly methods for diffusion-type operators on structured grid meshes. This class combines auxiliary and primal variable assemblers to construct complete diffusion operators with various jump treatments and boundary conditions.

The assembler supports both implicit and explicit jump treatments for handling discontinuities at element interfaces, which is essential for discontinuous Galerkin and mixed finite element methods.

% Create diffusion assembler with implicit jumps
assembler = DiffusionGridAssembler(fe, mesh, op, 1, 2, 1, 1);
% Assemble isotropic diffusion operator
diffusionMatrix = assembler.hessian(eye(2));
% Assemble anisotropic diffusion with boundary conditions
anisotropyTensor = [2.0, 0.1; 0.1, 0.5];
bcVector = assembler.hessianBc(anisotropyTensor, @bcFunc, @jumpFunc);

Constructor for DiffusionGridAssembler.

obj = DiffusionGridAssembler(fe, mesh, op, bcType, auxFlux, prmFlux, jumpType) creates an assembler for diffusion operators using mixed formulations with auxiliary and primal variables.

Parameters
fe- Finite element object
mesh- Grid mesh object (must be approx.mesh.Grid)
op- Finite element operator object
bcType- Boundary condition type (0=periodic, 1=Dirichlet)
auxFlux- Flux type for auxiliary variables (1=left, 2=right, 3=central)
prmFlux- Flux type for primal variables (1=left, 2=right, 3=central)
jumpType- Jump treatment (1=implicit, 2=explicit)

function fem::assembly::DiffusionGridAssembler::hessian ( InputType obj,
InputType c )

Assemble diffusion Hessian operator.

A = hessian(obj, c) assembles the complete diffusion operator matrix using the specified diffusion tensor. The method combines auxiliary and primal variable contributions with appropriate jump terms based on the jump type.

Parameters
obj- The DiffusionGridAssembler object
c- Diffusion tensor (nDims×nDims matrix)
Return values
A- Assembled diffusion operator sparse matrix
% Isotropic diffusion
isotropicMatrix = assembler.hessian(eye(2));
% Anisotropic diffusion
tensor = [2.0, 0.5; 0.5, 1.0];
anisotropicMatrix = assembler.hessian(tensor);
