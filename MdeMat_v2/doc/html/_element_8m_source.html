2 % ELEMENT Base class for element representations.
3 %
4 % Element encapsulates geometry information and function space used
5 % in Galerkin methods. The main idea of Galerkin methods is to
6 % approximate an infinite-dimensional function space by a
7 % finite-dimensional function space, called the "ansatz space".
8 %
9 % In the spectral method (SPM), the ansatz space consists of
10 % high-order polynomials on an element. In the finite element method
11 % (FEM), the ansatz space comprises piecewise low-order polynomials
12 % over a mesh of elements. Element serves as a building block for
13 % both SPM and FEM to define the ansatz space.
14 %
15 % This abstract base class provides the fundamental interface for
16 % element-based computations, including function evaluation and
17 % access to geometric properties.
18 %
19 % Examples:
20 % % Cannot instantiate abstract class directly
21 % % Use concrete subclasses instead:
22 % geometry = core.geometry.Orthotope.unit(2);
23 % basis = approx.basis.LagrangeBasis(2);
24 % projector = approx.project.NodalProjector(basis);
25 % integrator = approx.integrate.GaussLegendre(3);
26 % element = approx.element.C0Element(geometry, projector, integrator);
27 %
28 % % Access element properties
29 % nDims = element.nDims;
30 % nDofs = element.nDofs;
31 % normals = element.outerNormals;
32 %
33 % % Evaluate functions
34 % Y = element.evaluate(X, C);
35 %
36 % See also:
37 % core.geometry.Geometry, approx.project.Projector,
38 % approx.element.C0Element, approx.element.L2Element
39

88 % EVALUATE Evaluate a function over the element.
89 %
90 % Y = evaluate(obj, Z) evaluates the basis functions at
91 % points specified in Z = [X; C], where X contains evaluation
92 % points and C contains coefficients.
93 %
94 % Y = evaluate(obj, X, C) evaluates the finite element
95 % function defined by coefficients C at the evaluation
96 % points X.
97 %
98 % Inputs:
99 % obj - The Element object
100 % varargin - Variable input arguments:
101 %< Z - Combined matrix [X; C] (for single argument case)
102 %< X - Evaluation points (nDims x nPts matrix)
103 %< C - Coefficient vectors (nDofs x nVars matrix)
104 %
105 % Outputs:
106 % Y - Function values at evaluation points:
107 %< * If nargin = 2: (1 x nPts) vector
108 %< * If nargin = 3: (nVars x nPts) matrix
