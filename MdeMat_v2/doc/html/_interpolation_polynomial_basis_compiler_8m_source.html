2 % INTERPOLATIONPOLYNOMIALBASISCOMPILER Compiler for interpolation polynomial basis functions.
3 %
4 % InterpolationPolynomialBasisCompiler specializes in compiling basis
5 % matrices for interpolation polynomial families such as Lagrange and
6 % Hermite polynomials. It creates and manages arrays of interpolation
7 % polynomial basis functions based on specified node sets.
8 %
9 % Supported interpolation types:
10 % - Lagrange: n basis functions for n nodes (function value interpolation)
11 % - Hermite: 2n basis functions for n nodes (function + derivative interpolation)
12 %
13 % Examples:
14 % % Create compiler and set Lagrange functions
15 % compiler = core.symbolic.InterpolationPolynomialBasisCompiler();
16 % compiler.setFunctions([0, 1, 2], 'lagrange');
17 %
18 % % Compile and load basis matrix
19 % compiler.compile('lagrange_basis', 'Lagrange', 2);
20 % metadata = compiler.load('lagrange_basis');
21 %
22 % % Hermite interpolation
23 % compiler.setFunctions([-1, 0, 1], 'hermite');
24 % compiler.compile('hermite_basis', 'Hermite', 1);
