\doxysubsection{Detailed Description}
Compiled orthogonal polynomial basis functions. 

\doxylink{classapprox_1_1basis_1_1_orthogonal_basis_function}{Orthogonal\+Basis\+Function} represents a set of orthogonal polynomial basis functions (such as Legendre or Chebyshev polynomials) with automatic metadata loading from the \doxylink{namespacecore_1_1symbolic}{core.\+symbolic} compilation system.

The class automatically discovers appropriate metadata files based on the specified basis type, interval type, and number of basis functions, providing efficient evaluation of both function values and derivatives through precompiled function handles.

Supported orthogonal polynomial families\+:
\begin{DoxyItemize}
\item Legendre polynomials\+: orthogonal on $[-1,1]$ with weight $w(x) = 1$
\item Chebyshev polynomials\+: orthogonal on $[-1,1]$ with weight $w(x) = \frac{1}{\sqrt{1-x^2}}$
\item Monic Legendre\+: Legendre polynomials with leading coefficient = 1
\end{DoxyItemize}
