\doxysubsection{Detailed Description}
Structure for multidimensional grid data. 

\doxylink{classcore_1_1data_1_1_grid_struct}{Grid\+Struct} stores grid coordinates and associated data variables defined over the grid. Ensures all variables are consistent with grid dimensions.
