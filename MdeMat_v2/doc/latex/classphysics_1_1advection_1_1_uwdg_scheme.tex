\doxysubsection{Detailed Description}
Upwind Discontinuous Galerkin scheme. 

\doxylink{classphysics_1_1advection_1_1_uwdg_scheme}{Uwdg\+Scheme} implements an Upwind Discontinuous Galerkin (UWDG) method for solving advection equations. The method uses upwind numerical fluxes to handle the hyperbolic nature of advection problems, providing stability and sharp resolution of solution features.

The UWDG method discretizes the spatial domain using discontinuous Galerkin finite elements and handles inter-\/element communication through upwind fluxes, making it particularly suitable for transport-\/dominated problems with sharp gradients or discontinuities.
