\doxysubsection{Detailed Description}
Forward Euler integrator. 

\doxylink{classapprox_1_1odeint_1_1_fe_integrator}{Fe\+Integrator} implements the Forward Euler method, a first-\/order explicit time integration scheme for solving ordinary differential equations of the form\+:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + F(u) + S(t),
\]

where $M$ is a mass operator, $L$ is a linear operator, $F(u)$ is a nonlinear operator, and $S(t)$ is a source term. Any of these terms can be empty. For mass term, it means it reduces to an identity. For linear, nonlinear and source term, it means they vanish from the equation. This is the simplest explicit method, using only one evaluation per time step.

Forward Euler has a stability region of $|1 + z| \leq 1$, which restricts the time step for stability. For eigenvalue $\lambda$, the stability condition is  $|1 + \lambda \Delta t|
\leq 1$.

\begin{DoxyNote}{Note}
Forward Euler is conditionally stable and may require very small 

time steps for stiff problems. Use implicit methods for better 

stability properties with stiff systems.
