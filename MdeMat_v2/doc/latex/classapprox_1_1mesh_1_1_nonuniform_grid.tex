\doxysubsection{Detailed Description}
Nonuniform multidimensional structured grid. 

\doxylink{classapprox_1_1mesh_1_1_nonuniform_grid}{Nonuniform\+Grid} represents a structured grid with non-\/uniform spacing defined by coordinate vectors along each dimension. This class implements memory-\/efficient tensor-\/based storage while allowing arbitrary element sizes and distributions.
