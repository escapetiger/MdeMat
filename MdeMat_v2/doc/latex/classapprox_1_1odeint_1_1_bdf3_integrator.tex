\doxysubsection{Detailed Description}
Third-\/order BDF integrator. 

\doxylink{classapprox_1_1odeint_1_1_bdf2_integrator}{Bdf2\+Integrator} implements two-\/step Backward Differentiation Formula (BDF) methods for solving ordinary differential equations of the form\+:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + S,
\]

where $M$ is a mass operator, $L$ is a linear operator, and $S$ is a source term.

\doxylink{classapprox_1_1odeint_1_1_bdf3_integrator}{Bdf3\+Integrator} uses the Backward Euler method for the first step and BDF2 method for the second step. It acheives third-\/order accuracy and A-\/stability.


\begin{DoxyCode}{0}
\DoxyCodeLine{integrator\ =\ approx.odeint.Bdf3Integrator(1.0);}
\DoxyCodeLine{U\_new\ =\ integrator.step(L,\ N);}
\DoxyCodeLine{integrator.update(U\_new);}

\end{DoxyCode}


\begin{DoxyNote}{Note}
For the first time step, reduces to Backward Euler (first-\/order). 

For the second time step, reduces to BDF2 (second-\/order). 

Full third-\/order accuracy is achieved from the third step onward.
\end{DoxyNote}
