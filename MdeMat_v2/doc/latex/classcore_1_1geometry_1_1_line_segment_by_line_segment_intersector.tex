\doxysubsection{Detailed Description}
Computes intersections between line segments. 

\doxylink{classcore_1_1geometry_1_1_line_segment_by_line_segment_intersector}{Line\+Segment\+By\+Line\+Segment\+Intersector} computes intersection points between pairs of line segments in n-\/dimensional space (n \texorpdfstring{$>$}{>}= 2). The line segments are defined by their endpoints, and intersections are computed using a least-\/squares approach.

The line segments are parameterized as\+: L1(s) = X1 + s\texorpdfstring{$\ast$}{*}(X2 -\/ X1) L2(t) = X3 + t\texorpdfstring{$\ast$}{*}(X4 -\/ X3)

An intersection is considered valid only when\+:
\begin{DoxyEnumerate}
\item Two non-\/collinear line segments intersect at exactly one point
\item Two collinear line segments intersect at exactly one point (e.\+g., at an endpoint)
\end{DoxyEnumerate}

If line segments would have more than one intersection point (e.\+g., they overlap), an error is thrown.
