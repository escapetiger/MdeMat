\doxysubsection{Detailed Description}
Uniform multidimensional structured grid. 

\doxylink{classapprox_1_1mesh_1_1_uniform_grid}{Uniform\+Grid} represents a structured grid with uniform spacing defined by the number of elements per dimension and domain bounds. This class implements memory-\/efficient tensor-\/based storage with constant element sizes throughout the domain.

\begin{DoxyNote}{Note}
Uniform grids have constant element spacing within each dimension. 

The bounding box format is \mbox{[}a1, b1, a2, b2, ..., ad, bd\mbox{]} where 

\mbox{[}ai, bi\mbox{]} defines the interval for dimension i.
