\doxysubsection{Detailed Description}
Base class for compiled differentiable functions. 

\doxylink{classcore_1_1function_1_1_differentiable_compiled_function}{Differentiable\+Compiled\+Function} combines the capabilities of \doxylink{classcore_1_1function_1_1_compiled_function}{Compiled\+Function} and \doxylink{classcore_1_1function_1_1_differentiable_function}{Differentiable\+Function} to provide automatic metadata loading and efficient derivative evaluation using precompiled function handles.

The class automatically discovers and loads compiled metadata from the configuration directory, providing both function evaluation and derivative computation capabilities with optimal performance.
