\doxysubsection{Detailed Description}
Base class for all interpolation polynomial basis functions. 

\doxylink{classcore_1_1symbolic_1_1_interpolation_polynomial_basis_function}{Interpolation\+Polynomial\+Basis\+Function} provides common functionality for interpolation-\/based polynomial basis functions such as Lagrange and Hermite polynomials. It handles node management and automatically calculates the polynomial degree based on the number of nodes.
