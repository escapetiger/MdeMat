\doxysubsection{Detailed Description}
Base class for all symbolic functions. 

\doxylink{classcore_1_1symbolic_1_1_symbolic_function}{Symbolic\+Function} provides a foundation for creating and manipulating symbolic mathematical expressions with a consistent interface. This class serves as a base for implementing specialized symbolic function types while maintaining uniform evaluation and conversion capabilities.
