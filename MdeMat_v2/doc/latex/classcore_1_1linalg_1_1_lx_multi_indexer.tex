\doxysubsection{Detailed Description}
Generate L-\/infinity constrained multi-\/indices. 

\doxylink{classcore_1_1linalg_1_1_lx_multi_indexer}{Lx\+Multi\+Indexer} generates one-\/based multi-\/indices such that maximum value in each index is within specified bounds. Useful for tensor approximation with L-\/infinity norm constraints.
