\doxysubsection{Detailed Description}
\doxylink{classcore_1_1function_1_1_function}{Function} representing Hadamard product of two functions. 

\doxylink{classcore_1_1function_1_1_product_function}{Product\+Function} represents the element-\/wise (Hadamard) product of two functions with broadcasting support\+: (f \texorpdfstring{$\ast$}{*} g)(x) = \doxylink{classcore_1_1function_1_1_product_function_a066c8ddb60f0fdaa3542cf4722195662}{f(x)} .\texorpdfstring{$\ast$}{*} \doxylink{classcore_1_1function_1_1_product_function_a16a4778f161397a9e4c739ec1f56e6fb}{g(x)}

The class supports broadcasting following MATLAB\textquotesingle{}s element-\/wise operation rules. Input dimensions must be identical, while output dimensions follow broadcasting compatibility rules. The class implements the product rule for derivatives\+: (f \texorpdfstring{$\ast$}{*} g)\textquotesingle{} = f\textquotesingle{} \texorpdfstring{$\ast$}{*} g + f \texorpdfstring{$\ast$}{*} g\textquotesingle{}
