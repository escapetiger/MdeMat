\doxysubsection{Detailed Description}
Grid-\/based assembler for structured meshes. 

\doxylink{classfem_1_1assembly_1_1_grid_assembler}{Grid\+Assembler} provides assembly methods for finite element operators on structured grid meshes. This class extends the base \doxylink{classfem_1_1assembly_1_1_assembler}{Assembler} to handle grid-\/specific operations and boundary condition treatments.

The assembler supports different boundary condition types and provides specialized methods for handling Dirichlet boundary conditions on structured grids.
