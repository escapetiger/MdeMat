\doxysubsection{Detailed Description}
\doxylink{classcore_1_1symbolic_1_1_compiler}{Compiler} for interpolation polynomial basis functions. 

\doxylink{classcore_1_1symbolic_1_1_interpolation_polynomial_basis_compiler}{Interpolation\+Polynomial\+Basis\+Compiler} specializes in compiling basis matrices for interpolation polynomial families such as Lagrange and Hermite polynomials. It creates and manages arrays of interpolation polynomial basis functions based on specified node sets.

Supported interpolation types\+:
\begin{DoxyItemize}
\item Lagrange\+: n basis functions for n nodes (function value interpolation)
\item Hermite\+: 2n basis functions for n nodes (function + derivative interpolation)
\end{DoxyItemize}
