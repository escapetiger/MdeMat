\doxysubsection{Detailed Description}
Heun\textquotesingle{}s integrator. 

\doxylink{classapprox_1_1odeint_1_1_heun_integrator}{Heun\+Integrator} implements Heun\textquotesingle{}s method, a second-\/order explicit Runge-\/\+Kutta scheme for solving ordinary differential equations of the form\+:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + F(u) + S(t),
\]

where $M$ is a mass operator, $L$ is a linear operator, $F(u)$ is a nonlinear operator, and $S(t)$ is a source term. This method provides second-\/order accuracy with good stability properties. It\textquotesingle{}s also known as the improved Euler method or RK2.

Heun\textquotesingle{}s method evaluates the derivative at $t$ and at  $t +
(2/3)\Delta t$, then takes a weighted average. The weights \mbox{[}1/4, 3/4\mbox{]} give optimal second-\/order accuracy with this intermediate evaluation point.
