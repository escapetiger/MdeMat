\doxysubsection{Detailed Description}
Grid-\/based assembler for mixed finite element systems. 

\doxylink{classfem_1_1assembly_1_1_mixed_grid_assembler}{Mixed\+Grid\+Assembler} extends the Eulerian grid assembler with support for different flux types (left-\/biased, right-\/biased, central) used in mixed finite element methods and discontinuous Galerkin schemes.

This class provides the foundation for assembling operators in mixed formulations where different variables may require different flux treatments. It supports various numerical flux choices commonly used in discontinuous methods.
