\doxysubsection{Detailed Description}
Separable function composed of basis function factors with optional sparse structure. 

\doxylink{classapprox_1_1basis_1_1_separable_basis_function}{Separable\+Basis\+Function} represents a separable function where each factor is either an \doxylink{classapprox_1_1basis_1_1_interpolation_basis_function}{Interpolation\+Basis\+Function} or an \doxylink{classapprox_1_1basis_1_1_orthogonal_basis_function}{Orthogonal\+Basis\+Function}. This provides a unified framework for creating tensor product basis functions with optional sparsity patterns for high-\/dimensional approximation.

The class supports both dense (full tensor product) and sparse (reduced set of multi-\/indices) evaluation patterns for both function values and derivatives, with automatic metadata loading from the compiled basis functions.

Key features\+:
\begin{DoxyItemize}
\item Mixed basis types\+: combine orthogonal and interpolation polynomials
\item Sparse evaluation\+: $L^1$ or $L^\infty$ constrained index sets
\item Automatic metadata management for all factor functions
\item Efficient derivative computation through precompiled handles
\end{DoxyItemize}
