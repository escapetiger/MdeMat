\doxysubsection{Detailed Description}
Integration rule over the hypersphere. 

\doxylink{classapprox_1_1integrate_1_1_hypersphere_rule}{Hypersphere\+Rule} creates multidimensional integration rules on the hypersphere. This approach is efficient for integrating functions that can be separated into products of univariate functions or for rectangular integration domains.
