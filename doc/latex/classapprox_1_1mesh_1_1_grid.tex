\doxysubsection{Detailed Description}
Abstract base class for multidimensional structured grids. 

\doxylink{classapprox_1_1mesh_1_1_grid}{Grid} provides a foundation for representing multidimensional structured grids using memory-\/efficient tensor-\/based storage. This abstract class defines common properties and methods for querying grid characteristics, connectivity, and performing grid-\/based operations.


\begin{DoxyCode}{0}
\DoxyCodeLine{\%\ Cannot\ instantiate\ abstract\ \textcolor{keyword}{class\ }directly}
\DoxyCodeLine{\%\ Use\ concrete\ subclasses\ instead:}
\DoxyCodeLine{uniformGrid\ =\ approx.mesh.UniformGrid([10,\ 10],\ [0,\ 0,\ 1,\ 1]);}
\DoxyCodeLine{nonuniformGrid\ =\ approx.mesh.NonuniformGrid(\{0:0.1:1,\ [0,\ 0.2,\ 0.5,\ 1]\});}

\end{DoxyCode}


\begin{DoxyNote}{Note}
This is an abstract class that cannot be instantiated directly. 

Concrete subclasses must implement the collocate and refine methods, 

as well as the protected abstract methods for grid-\/specific operations.
\end{DoxyNote}
