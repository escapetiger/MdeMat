\doxysubsection{Detailed Description}
Base class for multidimensional structured grids. 

\doxylink{classapprox_1_1mesh_1_1_grid}{Grid} provides a foundational framework for representing structured computational grids using memory-\/efficient tensor-\/based storage. Unlike unstructured meshes that store explicit connectivity, structured grids leverage their regular topology to achieve O(d×n) memory usage instead of O(n\texorpdfstring{$^\wedge$}{\string^}d) for d-\/dimensional grids with n elements per dimension.

The class implements a tensor-\/product structure where\+:
\begin{DoxyItemize}
\item \doxylink{classapprox_1_1mesh_1_1_grid}{Grid} vertices form a Cartesian product of 1D coordinate arrays
\item Element connectivity follows regular patterns in each dimension
\item Neighbor relationships are computed algorithmically rather than stored
\item Boundary faces are identified by coordinate extrema
\end{DoxyItemize}

Reference coordinate system uses the hypercube \mbox{[}-\/1/2, 1/2\mbox{]}\texorpdfstring{$^\wedge$}{\string^}d, providing a canonical domain for finite element basis functions and quadrature rules. Coordinate transformations between reference and physical spaces are handled by concrete subclasses (\doxylink{classapprox_1_1mesh_1_1_uniform_grid}{Uniform\+Grid}, \doxylink{classapprox_1_1mesh_1_1_nonuniform_grid}{Nonuniform\+Grid}).

The Multi\+Indexer facilitates efficient conversion between\+:
\begin{DoxyItemize}
\item Linear indices\+: Single integers identifying grid elements \mbox{[}1, N\mbox{]}
\item Multi-\/indices\+: d-\/tuples specifying position in each dimension
\item Factor indices\+: Separate indexing within each dimensional factor
\end{DoxyItemize}

Interior elements are those with indices \mbox{[}2, n\+\_\+i-\/1\mbox{]} in
