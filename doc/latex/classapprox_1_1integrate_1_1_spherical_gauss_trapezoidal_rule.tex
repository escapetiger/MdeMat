\doxysubsection{Detailed Description}
Gauss-\/\+Trapezoidal integration over hypersphere. 

\doxylink{classapprox_1_1integrate_1_1_spherical_gauss_trapezoidal_rule}{Spherical\+Gauss\+Trapezoidal\+Rule} implements numerical integration over hyperspheres using a product of Gauss-\/\+Lobatto rules for zenith angles and a periodic trapezoidal rule for the azimuthal angle. This method provides efficient integration for functions on spherical domains.

Hyperspherical coordinates map Cartesian coordinates $(y_1,...,y_d)$ as\+:     \[y_1 = r*\cos(x_1)
y_i = r*\sin(x_1)*...*\sin(x_{i-1})*\cos(x_i), i = 2,...,d-1
y_d = r*\sin(x_1)*...*\sin(x_{d-1})
\] where\+:    \[x_i \in [0, \pi] for i = 1,...,d-2 (zenith angles)
x_{d-1} \in [0, 2\pi] (azimuthal angle)
\]
