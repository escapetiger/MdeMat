\doxysubsection{Detailed Description}
Compiled orthogonal polynomial basis functions. 

\doxylink{classcore_1_1function_1_1_compiled_orthogonal_basis}{Compiled\+Orthogonal\+Basis} represents a set of orthogonal polynomial basis functions (such as Legendre or Chebyshev polynomials) with automatic metadata loading from the \doxylink{namespacecore_1_1symbolic}{core.\+symbolic} compilation system.

The class automatically discovers appropriate metadata files based on the specified basis type, providing efficient evaluation of both function values and derivatives through precompiled function handles.
