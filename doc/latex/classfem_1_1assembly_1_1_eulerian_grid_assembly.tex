\doxysubsection{Detailed Description}
Eulerian grid-\/based assembly. 

\doxylink{classfem_1_1assembly_1_1_eulerian_grid_assembly}{Eulerian\+Grid\+Assembly} provides assembly methods for finite element operators on structured grid meshes using an Eulerian approach. This class handles volume and flux contributions with support for different boundary condition types including periodic and Dirichlet conditions.

The assembly supports various flux formulations (left-\/biased, right-\/biased, and central) and handles both interior and boundary contributions for each type.
