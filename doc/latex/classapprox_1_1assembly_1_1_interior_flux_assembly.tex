\doxysubsection{Detailed Description}
\doxylink{classapprox_1_1assembly_1_1_assembly}{Assembly} for interior flux terms in DG methods. 

\doxylink{classapprox_1_1assembly_1_1_interior_flux_assembly}{Interior\+Flux\+Assembly} handles the assembly of flux terms between neighboring elements in the interior of the computational domain. These flux terms are essential for providing inter-\/element coupling in discontinuous Galerkin (DG) methods, where the solution is allowed to be discontinuous across element boundaries.

The class implements both inner and outer flux contributions\+:
\begin{DoxyItemize}
\item Inner fluxes\+: contributions from the current element\textquotesingle{}s boundary
\item Outer fluxes\+: contributions from neighboring elements\textquotesingle{} boundaries
\end{DoxyItemize}

Each flux type (left-\/biased, right-\/biased) is supported, enabling the construction of upwind-\/like or downwind-\/like numerical schemes. The flux terms are assembled using triplet format for efficient sparse matrix construction.
