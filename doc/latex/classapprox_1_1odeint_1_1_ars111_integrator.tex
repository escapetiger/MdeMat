\doxysubsection{Detailed Description}
First-\/order ARS(1,1,1) IMEX Runge-\/\+Kutta integrator. 

\doxylink{classapprox_1_1odeint_1_1_ars111_integrator}{Ars111\+Integrator} implements the ARS(1,1,1) method, a first-\/order IMEX scheme for solving ordinary differential equations of the form\+:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + F(u) + S(t),
\]

where $M$ is a mass operator, $L$ is a linear operator (treated implicitly), $F(u)$ is a nonlinear operator (treated explicitly), and $S(t)$ is a source term (treated explicitly). This is the simplest IMEX method, combining forward Euler for the explicit part and backward Euler for the implicit part.

The method is A-\/stable for the implicit part and provides first-\/order accuracy. It\textquotesingle{}s suitable for initial testing and problems where simplicity is preferred over high accuracy.
