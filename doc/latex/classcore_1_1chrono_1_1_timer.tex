\doxysubsection{Detailed Description}
High-\/precision timing framework for performance measurement. 

\doxylink{classcore_1_1chrono_1_1_timer}{Timer} manages a collection of named timing records with mutually exclusive operation (only one record can be active at any time). It provides comprehensive timing functionality including start/stop operations, duration accumulation, and formatted reporting.

The \doxylink{classcore_1_1chrono_1_1_timer}{Timer} class maintains an array of \doxylink{classcore_1_1chrono_1_1_record}{Record} objects, each tracking a specific operation or phase. When a record is started, all other records must be stopped to ensure accurate measurements. Timing data accumulates across multiple start/stop cycles for the same record, allowing measurement of iterative or multi-\/phase operations.
