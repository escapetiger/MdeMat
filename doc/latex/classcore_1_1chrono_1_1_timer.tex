\doxysubsection{Detailed Description}
Measure elapsed time for multiple operations. 

\doxylink{classcore_1_1chrono_1_1_timer}{Timer} provides a framework for measuring and reporting execution time across multiple operations. Manages a collection of \doxylink{classcore_1_1chrono_1_1_record}{Record} objects with mutually exclusive timing (only one record active at a time).
