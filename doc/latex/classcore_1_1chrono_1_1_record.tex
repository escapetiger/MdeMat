\doxysubsection{Detailed Description}
Individual timing measurement with state management. 

\doxylink{classcore_1_1chrono_1_1_record}{Record} represents a single named timing operation that tracks active/inactive state and accumulates elapsed time across multiple measurement sessions. Each record maintains a name identifier, cumulative duration, and timing token for active measurements.

The \doxylink{classcore_1_1chrono_1_1_record}{Record} class provides the fundamental timing primitive used by the \doxylink{classcore_1_1chrono_1_1_timer}{Timer} class. It maintains state information to distinguish between active timing (when a measurement is in progress) and inactive timing (when no measurement is running). Duration values accumulate across multiple start/stop cycles.
