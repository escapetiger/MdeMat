\doxysubsection{Detailed Description}
Computes intersections between line segments and planes. 

\doxylink{classcore_1_1geometry_1_1_line_segment_by_plane_intersector}{Line\+Segment\+By\+Plane\+Intersector} computes intersection points between line segments and planes in n-\/dimensional space (n \texorpdfstring{$>$}{>}= 2). Line segments are defined by their endpoints, and planes are defined by normal vectors and offset constants.

The line segment is parameterized as\+:

\[L(t) = X1 + t*(X2 - X1),  t \in [0,1]
\]

The plane is defined by the equation\+:

\[a^T * x + b = 0,
\]

where $a$ is the normal vector to the plane and $b$ is the offset constant. The method handles parallel and coincident cases appropriately. If a line segment lies entirely on a plane, all points are considered intersection points.
