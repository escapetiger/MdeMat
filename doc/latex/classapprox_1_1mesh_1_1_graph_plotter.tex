\doxysubsection{Detailed Description}
Visualization class for \doxylink{classapprox_1_1mesh_1_1_graph}{Graph} objects. 

\doxylink{classapprox_1_1mesh_1_1_graph_plotter}{Graph\+Plotter} provides comprehensive visualization functionality for \doxylink{classapprox_1_1mesh_1_1_graph}{approx.\+mesh.\+Graph} objects, enabling customizable plots of vertices and edges in 1D, 2D, and 3D spaces. The class supports various styling options for different visualization needs.
