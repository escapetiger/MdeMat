\doxysubsection{Detailed Description}
Adaptive time stepping timeline. 

\doxylink{classapprox_1_1mesh_1_1_dynamic_timeline}{Dynamic\+Timeline} represents a temporal discretization with dynamically computed time step sizes. This class is particularly useful for simulations where the time step needs to be adjusted based on spatial discretization constraints (e.\+g., CFL conditions) or solution behavior.

\DoxyCodeLine{\%\ Set\ time\ step\ based\ on\ CFL\ condition}
\DoxyCodeLine{timeline.setTimeStep(0.1,\ 0.5);\ \ \%\ \mbox{\hyperlink{classapprox_1_1mesh_1_1_dynamic_timeline_aef514be4c6a4390e254ac6bc96cee475}{h}}=0.1,\ CFL=0.5}
\DoxyCodeLine{\%\ Advance\ through\ time}
\DoxyCodeLine{\textcolor{keywordflow}{while}\ \string~timeline.isFinished()}
\DoxyCodeLine{timeline.advance();}

\begin{DoxyNote}{Note}
The time step is computed as dt = C \texorpdfstring{$\ast$}{*} h\texorpdfstring{$^\wedge$}{\string^}p where h is the spatial 

mesh parameter, C is a convergence constant (e.\+g., CFL number), 

and p is an exponent (default 1).
\end{DoxyNote}
