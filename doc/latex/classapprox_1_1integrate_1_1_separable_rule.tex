\doxysubsection{Detailed Description}
Separable multidimensional integration rule. 

\doxylink{classapprox_1_1integrate_1_1_separable_rule}{Separable\+Rule} creates multidimensional integration rules by taking tensor products of one-\/dimensional rules. This approach is efficient for integrating functions that can be separated into products of univariate functions or for rectangular integration domains.

Examples\+: \% Create a 2D separable rule from two Gauss-\/\+Legendre rules rule1D = \doxylink{classapprox_1_1integrate_1_1_gauss_legendre_rule}{approx.\+integrate.\+Gauss\+Legendre\+Rule()}; rule2D = \doxylink{classapprox_1_1integrate_1_1_separable_rule}{Separable\+Rule}(\{rule1D, rule1D\});

\% Generate integration points \mbox{[}X, w\mbox{]} = rule2\+D.\+generate(\{5\}, \{5\});

\% Use static methods for common rules gauss\+Rule3D = Separable\+Rule.\+gauss\+Legendre(3);

\begin{DoxyNote}{Note}
The separable rule constructs multidimensional quadrature by 

taking tensor products of univariate rules. This is most efficient 

for functions that exhibit separability or low-\/rank structure.
\end{DoxyNote}
