\doxysubsection{Detailed Description}
Abstract base class for temporal discretization. 

\doxylink{classapprox_1_1mesh_1_1_timeline}{Timeline} provides a foundation for representing sequences of time points and managing temporal progression in numerical simulations. This abstract class defines the common interface and basic functionality that must be implemented by concrete timeline classes.
