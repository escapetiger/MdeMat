\doxysubsection{Detailed Description}
Second-\/order Strang operator splitting. 

\doxylink{classapprox_1_1odeint_1_1_strang_integrator}{Strang\+Integrator} implements the second-\/order Strang operator splitting method for solving ordinary differential equations of the form\+:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = \sum_{i=1}^{n} (L_i u +
F_i(u) + S_i)
\]

by decomposing it into n separate sub-\/problems\+:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = L_i u + F_i(u) + S_i, \quad
i = 1, 2, \ldots, n
\]

The Strang method uses the symmetric splitting formula for n operators\+:

\[e^{(A_1+A_2+\cdots+A_n)\Delta t} \approx e^{A_1\Delta t/2}
e^{A_2\Delta t/2} \cdots e^{A_n\Delta t/2} e^{A_n\Delta t/2}
\cdots e^{A_2\Delta t/2} e^{A_1\Delta t/2}
\]

This achieves second-\/order accuracy with global error  $O(\Delta
t^2)$. The symmetric structure causes second-\/order commutator terms to cancel exactly, providing superior accuracy compared to first-\/order Lie-\/\+Trotter splitting.

The splitting sequence applies operators in forward order with half time steps, then in reverse order with half time steps.

\begin{DoxyNote}{Note}
For n operators, the method applies 2n-\/1 sub-\/steps per time step. 

The middle operator (when n is odd) gets applied once with full 

time step, while others get applied twice with half time steps.
