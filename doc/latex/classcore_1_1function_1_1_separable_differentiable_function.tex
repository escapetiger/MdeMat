\doxysubsection{Detailed Description}
Separable function with derivative capabilities and optional sparse structure. 

\doxylink{classcore_1_1function_1_1_separable_differentiable_function}{Separable\+Differentiable\+Function} combines the capabilities of \doxylink{classcore_1_1function_1_1_separable_function}{Separable\+Function} and \doxylink{classcore_1_1function_1_1_differentiable_function}{Differentiable\+Function} to represent functions that can be expressed as products of factor functions and support differentiation with optional sparsity patterns.

The class supports both dense (full tensor product) and sparse (reduced set of multi-\/indices) evaluation patterns for both function values and derivatives. This enables efficient computation for high-\/dimensional separable functions.
