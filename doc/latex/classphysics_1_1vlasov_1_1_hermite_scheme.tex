\doxysubsection{Detailed Description}
Hermite spectral method for Vlasov equations. 

\doxylink{classphysics_1_1vlasov_1_1_hermite_scheme}{Hermite\+Scheme} implements a Hermite spectral method for solving Vlasov-\/\+Poisson equations using discontinuous Galerkin spatial discretization and operator splitting temporal integration.
