\doxysubsection{Detailed Description}
Gauss-\/\+Hermite numerical integration rule. 

\doxylink{classapprox_1_1integrate_1_1_gauss_hermite_rule}{Gauss\+Hermite\+Rule} implements numerical integration using the Gauss-\/\+Hermite method for integrands weighted by the Gaussian function. This method is optimal for integrating functions over the entire real line with the weight function\+:

\[w(x) = \frac{e^{-x^2/2}}{\sqrt{2\pi}}
\]

For $n$ nodes, this method exactly integrates polynomials weighted by the Gaussian function up to degree $2n-1$. The nodes are the roots of the physicist\textquotesingle{}s Hermite polynomial $He_n(x)$ scaled for the weight $e^{-x^2/2}$.

This quadrature is particularly useful for probability integrals and Fourier transforms involving Gaussian functions.

Generate 1D Gauss-\/\+Hermite nodes and weights. 

\mbox{[}x, w\mbox{]} = generate1d(obj, np) generates {\itshape np} Gauss-\/\+Hermite nodes {\itshape x} and corresponding weights {\itshape w} for the weight function e\texorpdfstring{$^\wedge$}{\string^}\{-\/x\texorpdfstring{$^\wedge$}{\string^}2/2\}/sqrt(2\texorpdfstring{$\ast$}{*}pi) over the infinite domain.

\mbox{[}x, w\mbox{]} = generate1d(obj, np, lower=a, upper=b) generates nodes and weights, but ignores lower and upper bounds since Gauss-\/\+Hermite quadrature is defined over the infinite domain.
