\doxysubsection{Detailed Description}
Second-\/order BDF integrator. 

\doxylink{classapprox_1_1odeint_1_1_bdf2_integrator}{Bdf2\+Integrator} implements two-\/step Backward Differentiation Formula (BDF) methods for solving ordinary differential equations of the form\+:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + S,
\]

where $M$ is a mass operator, $L$ is a linear operator, and $S$ is a source term.

\doxylink{classapprox_1_1odeint_1_1_bdf2_integrator}{Bdf2\+Integrator} uses the Backward Euler method for the first step. It achieves second-\/order accuracy and A-\/stability.
