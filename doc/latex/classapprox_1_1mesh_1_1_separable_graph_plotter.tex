\doxysubsection{Detailed Description}
Visualization class for \doxylink{classapprox_1_1mesh_1_1_separable_graph}{Separable\+Graph} objects. 

\doxylink{classapprox_1_1mesh_1_1_separable_graph_plotter}{Separable\+Graph\+Plotter} provides memory-\/efficient visualization functionality for \doxylink{classapprox_1_1mesh_1_1_separable_graph}{approx.\+mesh.\+Separable\+Graph} objects without requiring conversion to full \doxylink{classapprox_1_1mesh_1_1_graph}{Graph} representations. The class supports direct tensor-\/product visualization, subsampling for large grids, and projection for high-\/dimensional cases.
