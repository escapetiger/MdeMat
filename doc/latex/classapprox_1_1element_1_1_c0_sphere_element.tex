\doxysubsection{Detailed Description}
C0 element defined on spherical domains. 

\doxylink{classapprox_1_1element_1_1_c0_sphere_element}{C0\+Sphere\+Element} extends \doxylink{classapprox_1_1element_1_1_c0_element}{C0\+Element} for spherical geometries with various basis function types and reduction schemes. The element supports 1D (interval), 2D (circle), and 3D (sphere) domains with orthogonal, cardinal, or radial basis function (RBF) types.
