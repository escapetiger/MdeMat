\doxysubsection{Detailed Description}
Data container for visualization datasets. 

\doxylink{classphysics_1_1visual_1_1_dataset}{Dataset} provides a simple container for visualization data with type information. This class encapsulates the data structure and type classification used throughout the visualization system.

The {\itshape Type} property determines how the data is rendered\+:
\begin{DoxyItemize}
\item Type 0 (FIXED)\+: Fixed or reference data
\item Type 1 (EXACT)\+: Exact analytical solution data
\item Type 2 (NUMERICAL)\+: Numerical solution data
\end{DoxyItemize}
