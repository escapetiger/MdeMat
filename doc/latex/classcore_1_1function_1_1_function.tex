\doxysubsection{Detailed Description}
Base class for all functions from Euclidean space to Euclidean space. 

\doxylink{classcore_1_1function_1_1_function}{Function} represents a mathematical mapping from $R^n$ to $R^m$, which can be evaluated at specified points. This class defines the interface for all function types in the system.
