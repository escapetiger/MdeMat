\doxysubsection{Detailed Description}
Base class for all functions from Euclidean space to Euclidean space. 

\doxylink{classcore_1_1function_1_1_function}{Function} represents a mathematical mapping from R\texorpdfstring{$^\wedge$}{\string^}n to R\texorpdfstring{$^\wedge$}{\string^}m, which can be evaluated at specified points. This class defines the interface for all function types in the system.

The implementation uses a two-\/step evaluation process\+:
\begin{DoxyEnumerate}
\item The public evaluate method handles input/output reshaping
\item The protected evaluate\+Impl method handles the actual computation 
\end{DoxyEnumerate}
