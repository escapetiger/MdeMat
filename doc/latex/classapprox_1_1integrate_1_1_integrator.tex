\doxysubsection{Detailed Description}
Unified numerical integrator with data storage. 

\doxylink{classapprox_1_1integrate_1_1_integrator}{Integrator} combines integration point generation, function evaluation storage, and integration computation in a single cohesive interface. It manages nodes, weights, function values, and partial derivatives for efficient numerical integration.
