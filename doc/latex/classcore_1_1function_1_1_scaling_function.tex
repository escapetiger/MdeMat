\doxysubsection{Detailed Description}
\doxylink{classcore_1_1function_1_1_function}{Function} representing scaled coordinate transformations. 

Scaling represents coordinate scaling transformations of the form\+:

\[f(x) = g(x/\lambda)
\]

where $g$ is a \doxylink{classcore_1_1function_1_1_function}{core.\+function.\+Function} and $\lambda$ is a positive scaling parameter. This transformation scales the input coordinates by $1/\lambda$ before evaluating the base function.

For derivatives, the chain rule gives\+:    \[\frac{\partial^k f}{\partial x^k}(x) = \frac{1}{\lambda^k}
\frac{\partial^k g}{\partial u^k}(x/\lambda)
\]
