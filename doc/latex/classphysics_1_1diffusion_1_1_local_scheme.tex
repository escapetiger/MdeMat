\doxysubsection{Detailed Description}
Local scheme for diffusion equations. 

\doxylink{classphysics_1_1diffusion_1_1_local_scheme}{Local\+Scheme} implements a local finite element method for solving diffusion equations using discontinuous Galerkin discretization. The scheme supports both periodic and Dirichlet boundary conditions with elliptic assembly operations.
