\doxysubsection{Detailed Description}
Base class for all compiled functions. 

\doxylink{classcore_1_1function_1_1_compiled_function}{Compiled\+Function} provides a bridge between symbolic function definitions and efficient numerical evaluation by automatically loading precompiled function handles and metadata from the configuration directory.

The class supports automatic metadata discovery, caching, and efficient function evaluation using precompiled function handles stored in MAT files.
