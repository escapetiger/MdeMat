\doxysubsection{Detailed Description}
Abstract base class for orthogonal polynomial basis functions. 

\doxylink{classcore_1_1symbolic_1_1_orthogonal_polynomial_basis}{Orthogonal\+Polynomial\+Basis} provides a unified framework for generating orthogonal polynomial basis functions using three-\/term recurrence relations. Concrete subclasses implement specific polynomial families such as Legendre, Chebyshev, and Hermite polynomials.

The three-\/term recurrence relation has the general form\+:

\[P_{n+1}(x) = (A_n \cdot x + B_n) \cdot P_n(x) + C_n \cdot
P_{n-1}(x)
\]
