\doxysubsection{Detailed Description}
\doxylink{classcore_1_1function_1_1_function}{Function} representing affine transformations. 

\doxylink{classcore_1_1function_1_1_linear_function}{Linear\+Function} represents affine transformations of the form\+:

\[f(x) = A*x + b
\]

where $A$ is an $m\times n$ matrix and $b$ is an $m\times 1$ vector. When $b$ is not provided or is zero, this reduces to a pure linear transformation.
