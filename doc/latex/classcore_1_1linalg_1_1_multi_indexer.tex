\doxysubsection{Detailed Description}
Indexers handling multi-\/dimensional indexing. 

\doxylink{classcore_1_1linalg_1_1_multi_indexer}{Multi\+Indexer} generates multi-\/indices for tensor operations and provides methods to convert between multi-\/indices and linear indices. Supports both column-\/major (\textquotesingle{}F\textquotesingle{}) and row-\/major (\textquotesingle{}C\textquotesingle{}) storage orders with various boundary conditions for index conversion.
