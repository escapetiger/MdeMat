\doxysubsection{Detailed Description}
Real-\/valued spherical harmonic basis functions. 

\doxylink{classcore_1_1symbolic_1_1_spherical_harmonic_basis_function}{Spherical\+Harmonic\+Basis\+Function} represents real-\/valued spherical harmonic basis functions on the canonical domain $\mu\in[-1,1]$ and $\theta\in[0,2\pi]$. The functions are constructed using associated Legendre polynomials and trigonometric functions.

The spherical harmonic function with degree $l$ and order $m$ are\+:
\begin{DoxyItemize}
\item $(l^2+1)$-\/th function (zonal harmonics, $m=0$)\+: $P_l^0(\mu)$
\item $(l^2+2m-1)$-\/th function (tesseral harmonics, $m>0$)\+: $\cos(m\theta)P_l^m(\mu)$
\item $(l^2 + 2m)$-\/th function (tesseral harmonics, $m>0$)\+: $\sin(m\theta)P_l^m(\mu)$
\end{DoxyItemize}
