\doxysubsection{Detailed Description}
\doxylink{classcore_1_1function_1_1_function}{Function} that returns constant values. 

\doxylink{classcore_1_1function_1_1_constant}{Constant} represents a mathematical mapping that returns the same constant value for all input points\+:

\[f(x) = c
\]

where $c$ is a constant vector in $R^m$.
