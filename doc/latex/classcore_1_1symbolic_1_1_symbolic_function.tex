\doxysubsection{Detailed Description}
Base class for all symbolic functions. 

\doxylink{classcore_1_1symbolic_1_1_symbolic_function}{Symbolic\+Function} represents a symbolic function with expressions and variables. It provides the foundation for all symbolic basis functions with compilation capabilities and dimension properties.
