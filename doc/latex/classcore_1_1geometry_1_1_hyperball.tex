\doxysubsection{Detailed Description}
\doxylink{classcore_1_1geometry_1_1_geometry}{Geometry} for n-\/ball domains. 

\doxylink{classcore_1_1geometry_1_1_hyperball}{Hyperball} represents a generalized geometric domain that extends the concept of filled circles and solid spheres to arbitrary dimensions. It represents the region enclosed by an $(n-1)$-\/dimensional sphere in n-\/dimensional Euclidean space. Dimensional representations\+:
\begin{DoxyItemize}
\item 1-\/ball\+: A line segment
\item 2-\/ball\+: A disk (filled circle)
\item 3-\/ball\+: A solid sphere
\item n-\/ball\+: A solid region in n-\/dimensional space
\end{DoxyItemize}
