P\+: Node positions (Nx2) T\+: Triangle indices (NTx3) FD\+: Distance function \doxylink{ddiff_8m_a1aabac6d068eef6a7bad3fdf50a05cc8}{d(x,y)} FH\+: Scaled edge length function h(x,y) H0\+: Initial edge length BBOX\+: Bounding box \mbox{[}xmin,ymin; xmax,ymax\mbox{]} PFIX\+: Fixed node positions (NFIXx2) FPARAMS\+: Additional parameters passed to FD and FH
