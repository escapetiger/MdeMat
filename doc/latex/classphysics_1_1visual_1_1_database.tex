\doxysubsection{Detailed Description}
Simplified data container for visualization datasets. 

\doxylink{classphysics_1_1visual_1_1_database}{Database} provides centralized storage and management of visualization data using \doxylink{classphysics_1_1visual_1_1_dataset}{Dataset} objects. The class focuses purely on data management and provides grouping functionality for visualization components.
