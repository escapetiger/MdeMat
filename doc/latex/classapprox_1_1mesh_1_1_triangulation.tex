\doxysubsection{Detailed Description}
Computational mesh using simplicial elements. 

\doxylink{classapprox_1_1mesh_1_1_triangulation}{Triangulation} provides a concrete implementation of \doxylink{classapprox_1_1mesh_1_1_polytopal_mesh}{Polytopal\+Mesh} for simplicial elements (line segments in 1D, triangles in 2D, tetrahedra in 3D).

Element types by dimension\+:
\begin{DoxyItemize}
\item 1D\+: Line segments (2 vertices, 2 faces as endpoints)
\item 2D\+: Triangles (3 vertices, 3 edges as faces)
\item 3D\+: Tetrahedra (4 vertices, 4 triangular faces)
\item nD\+: n-\/simplices (n+1 vertices, n+1 (n-\/1)-\/simplex faces)
\end{DoxyItemize}

The class uses affine coordinate transformations between reference and physical coordinates, where the reference simplex has vertices at the origin and unit coordinate vectors\+: \{0, e\+\_\+1, e\+\_\+2, ..., e\+\_\+n\}.

Reference coordinates use the standard simplex with vertices at \{0, e\+\_\+1, e\+\_\+2, ..., e\+\_\+n\} where e\+\_\+i are unit coordinate vectors. This differs from some references that use centered or symmetric simplices.

\doxylink{classapprox_1_1mesh_1_1_mesh}{Mesh} refinement follows standard subdivision rules\+:
\begin{DoxyItemize}
\item 1D\+: Each edge splits into 2 segments
\item 2D\+: Each triangle splits into 4 triangles
\item 3D\+: Each tetrahedron splits into 8 tetrahedra
\item General\+: Each k-\/level refinement produces 2\texorpdfstring{$^\wedge$}{\string^}(k×d) sub-\/elements
\end{DoxyItemize}
