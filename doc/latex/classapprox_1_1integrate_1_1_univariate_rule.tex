\doxysubsection{Detailed Description}
Base class for all univariate integration rules. 

\doxylink{classapprox_1_1integrate_1_1_univariate_rule}{Univariate\+Rule} provides a specialized interface for one-\/dimensional numerical integration methods. It extends the general \doxylink{classapprox_1_1integrate_1_1_integration_rule}{Integration\+Rule} class with specific validation and structure appropriate for univariate quadrature formulas.
