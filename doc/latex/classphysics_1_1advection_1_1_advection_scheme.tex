\doxysubsection{Detailed Description}
Base class for all schemes solving advection equations. 

\doxylink{classphysics_1_1advection_1_1_advection_scheme}{Advection\+Scheme} implements a numerical scheme for solving advection equations. This base class defines the basic validation and parse logic of configuration struct.
