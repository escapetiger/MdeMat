\doxysubsection{Detailed Description}
$L^2$ element over the orthotope. 

\doxylink{classapprox_1_1element_1_1_l2_orthotope_element}{L2\+Orthotope\+Element} implements an $L^2$ finite element over the orthotope domain. The element supports both modal and nodal basis functions with various polynomial orders and ordering patterns.
