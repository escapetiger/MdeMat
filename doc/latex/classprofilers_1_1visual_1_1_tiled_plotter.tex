\doxysubsection{Detailed Description}
Multi-\/panel figure manager for data visualization. 

\doxylink{classprofilers_1_1visual_1_1_tiled_plotter}{Tiled\+Plotter} provides infrastructure for creating and managing multi-\/panel figures using MATLAB\textquotesingle{}s tiledlayout functionality. This class simplifies the creation of complex visualization layouts with automatic tile placement and flexible axis specifications.

The plotter supports both manual axis specification and automatic layout computation, making it suitable for both simple multi-\/plot figures and complex dashboard-\/style visualizations with varying panel sizes.
