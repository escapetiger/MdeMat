\doxysubsection{Detailed Description}
Base class for all finite element spaces. 

\doxylink{classapprox_1_1space_1_1_finite_element_space}{Finite\+Element\+Space} implements the finite-\/dimensional function space used in the finite element method, It serves as the foundation for finite element computations on complex geometries.
