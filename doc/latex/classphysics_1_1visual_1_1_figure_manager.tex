\doxysubsection{Detailed Description}
Automatic figure positioning and lifecycle management. 

\doxylink{classphysics_1_1visual_1_1_figure_manager}{Figure\+Manager} handles creation, positioning, and cleanup of figure windows with automatic screen centering. Figures are positioned in the center of the screen with default MATLAB styling.

The manager creates figures with consistent positioning and handles their lifecycle, ensuring proper cleanup when visualization is complete.

Examples\+: \% Create manager and figures manager = \doxylink{classphysics_1_1visual_1_1_figure_manager_a373c28dbdf6a3162a7678f334fb13166}{Figure\+Manager()}; figures = manager.\+create\+Figures(2);

\% Later cleanup manager.\+close\+All();
