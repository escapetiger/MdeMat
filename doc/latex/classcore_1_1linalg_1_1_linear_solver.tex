\doxysubsection{Detailed Description}
Adaptive linear solver with AMG preconditioning. 

\doxylink{classcore_1_1linalg_1_1_linear_solver}{Linear\+Solver} automatically detects matrix properties like sparsity and condition number to choose between direct methods and iterative methods with optional AMG preconditioning for optimal performance.

The solver uses sparsity and condition number thresholds to determine the optimal solution strategy, with optional preconditioner caching for repeated solves with similar matrices.
