\doxysubsection{Detailed Description}
Lagrange interpolation basis functions. 

\doxylink{classcore_1_1symbolic_1_1_lagrange_basis}{Lagrange\+Basis} generates Lagrange interpolation basis functions for given interpolation nodes. Each basis function is a polynomial that equals 1 at one node and 0 at all other nodes.
