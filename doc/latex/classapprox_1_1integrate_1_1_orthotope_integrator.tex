\doxysubsection{Detailed Description}
Numerical integration over orthotope domains. 

\doxylink{classapprox_1_1integrate_1_1_orthotope_integrator}{Orthotope\+Integrator} provides specialized integration capabilities for functions defined on multidimensional orthotopes (hyperrectangles). It uses separable integration rules that construct multidimensional quadrature by tensor products of univariate rules.

Examples\+: \% Create integrator with Gauss-\/\+Legendre rule for 3D orthotope integrator = \doxylink{classapprox_1_1integrate_1_1_orthotope_integrator}{Orthotope\+Integrator}(3, \textquotesingle{}gauss\+\_\+legendre\textquotesingle{});

\% Create integrator with Gauss-\/\+Lobatto rule for 2D rectangle integrator = \doxylink{classapprox_1_1integrate_1_1_orthotope_integrator}{Orthotope\+Integrator}(2, \textquotesingle{}gauss\+\_\+lobatto\textquotesingle{});

\% Using existing rule object rule = approx.\+integrate.\+Separable\+Rule.\+gauss\+Legendre(4); integrator = Orthotope\+Integrator(rule);

\begin{DoxyNote}{Note}
Orthotopes are multidimensional generalizations of rectangles. 

The separable rules are most efficient for functions that can 

be expressed as products of univariate functions.
\end{DoxyNote}
