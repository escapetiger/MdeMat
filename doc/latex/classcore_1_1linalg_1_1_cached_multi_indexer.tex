\doxysubsection{Detailed Description}
Base class for all indexers with cached indices. 

\doxylink{classcore_1_1linalg_1_1_cached_multi_indexer}{Cached\+Multi\+Indexer} provides foundation for index generation strategies that benefit from caching generated indices. Subclasses implement specific index generation while inheriting caching functionality.
