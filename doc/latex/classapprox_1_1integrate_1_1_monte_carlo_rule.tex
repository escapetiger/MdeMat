\doxysubsection{Detailed Description}
Monte Carlo numerical integration rule. 

\doxylink{classapprox_1_1integrate_1_1_monte_carlo_rule}{Monte\+Carlo\+Rule} provides a foundation for Monte Carlo integration methods. This class manages random number generation with reproducible seeding and defines the interface for Monte Carlo quadrature implementations.
