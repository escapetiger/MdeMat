\doxysubsection{Detailed Description}
Base class for all linear approximators. 

\doxylink{classapprox_1_1linear_1_1_linear_approximator}{Linear\+Approximator} provides the foundation for linear approximation methods where functions are approximated as finite linear combinations of basis functions. The class supports projection and fitting using mass and design operators to solve linear systems. In addition, the class implements the evaluation logic of linear approximator.

Let $V_h$ be a linear approximation space of which the element $u_h$ is of form\+:

\[u_h = \sum_{i=1}^n c_i p_i.
\]

The projection seeks a linear approximation $u_h \in V_h$ of a function $u$ such that

\[\langle u_h, v_h \rangle = f(v_h), \quad \forall v_h \in V_h,
\]

The fitting seeks a linear approximation $u_h \in V_h$ of a function $u$ such that

\[\phi_j(u) = \phi_j(u_h), \quad \forall 1 \le j \le m,
\]

where $\phi_j$ are linear functionals.
