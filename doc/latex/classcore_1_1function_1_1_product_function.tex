\doxysubsection{Detailed Description}
\doxylink{classcore_1_1function_1_1_function}{Function} representing Hadamard product of two functions. 

\doxylink{classcore_1_1function_1_1_product_function}{Product\+Function} represents the element-\/wise (Hadamard) product of two functions with broadcasting support\+:

\mbox{[} (f \texorpdfstring{$\ast$}{*} g)(x) = f(x) .\texorpdfstring{$\ast$}{*} g(x) \mbox{]}

The class supports broadcasting following MATLAB\textquotesingle{}s element-\/wise operation rules. Input dimensions must be identical, while output dimensions follow broadcasting compatibility rules. The class implements the product rule for derivatives\+:

\mbox{[} (f \texorpdfstring{$\ast$}{*} g)\textquotesingle{} = f\textquotesingle{} \texorpdfstring{$\ast$}{*} g + f \texorpdfstring{$\ast$}{*} g\textquotesingle{} \mbox{]}
