P\+: Node positions (Nx\+NDIM) T\+: Triangle indices (NTx(NDIM+1)) FDIST\+: Distance function FH\+: Edge length function H\+: Smallest edge length BOX\+: Bounding box \mbox{[}xmin,xmax;ymin,ymax; ...\mbox{]} (NDIMx2) FIX\+: Fixed node positions (NFIXx\+NDIM) FDISTPARAMS\+: Additional parameters passed to FDIST
