\doxysubsection{Detailed Description}
Base class for all Galerkin-\/type projectors. 

\doxylink{classapprox_1_1project_1_1_galerkin_projector}{Galerkin\+Projector} provides the foundation for Galerkin approximation methods where functions are projected onto finite-\/dimensional spaces using mass operators to solve linear systems. The class implements the core Galerkin methodology for function approximation.

The Galerkin method seeks an approximation $u_h \in V_h$ of a function $u$ such that   \[\langle u_h, v_h\rangle = \langle f, v_h\rangle, \forall v_h ∈ V_h,
\] where $V_h$ is the finite-\/dimensional function space spanned by the basis.

This class defines the interface for concrete implementations such as modal and nodal projectors, which differ in how they construct the mass operator and embed data into the latent space.
