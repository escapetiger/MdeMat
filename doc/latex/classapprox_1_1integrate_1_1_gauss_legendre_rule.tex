\doxysubsection{Detailed Description}
Gauss-\/\+Legendre numerical integration rule. 

\doxylink{classapprox_1_1integrate_1_1_gauss_legendre_rule}{Gauss\+Legendre\+Rule} implements numerical integration using the Gauss-\/\+Legendre method, which provides optimal accuracy for polynomial integrands. For $n$ nodes, this method exactly integrates polynomials of degree up to $2n-1$.

The Gauss-\/\+Legendre quadrature formula achieves maximum polynomial exactness for a given number of nodes. The nodes are the roots of the Legendre polynomial of degree n, providing optimal quadrature points that do not include the interval endpoints.
