\doxysubsection{Detailed Description}
Discontinuous Galerkin Hermite spectral method for Vlasov equations. 

\doxylink{classphysics_1_1vlasov_1_1_dghs_scheme}{Dghs\+Scheme} implements a discontinuous Galerkin Hermite spectral method for solving Vlasov-\/\+Poisson equations using discontinuous Galerkin spatial discretization and operator splitting temporal integration.
