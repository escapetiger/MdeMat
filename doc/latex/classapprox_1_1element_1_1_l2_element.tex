\doxysubsection{Detailed Description}
L2 Galerkin element. 

\doxylink{classapprox_1_1element_1_1_l2_element}{L2\+Element} implements a L2 function. This class extends the base \doxylink{classapprox_1_1element_1_1_element}{Element} class by adding volume and flux integration capabilities through precomputed basis values and derivatives at integration points.

\doxylink{classapprox_1_1element_1_1_l2_element}{L2\+Element} assumes discontinuity occurs only at element boundaries.
