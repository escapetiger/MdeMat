function approx\+::odeint\+::expseq (\begin{DoxyParamCaption}\item[{Input\+Type}]{Z}{, }\item[{Input\+Type}]{n}{}\end{DoxyParamCaption})}



Generate exponential sequence phi\+\_\+k(\+Z). 

phi = expseq(\+Z, n) computes the first (n+1) terms of the exponential sequence defined by\+:

\[\phi_0(Z) = \exp(Z)
\]   \[\phi_{k+1}(Z) = \frac{\phi_k(Z) - \phi_k(0)}{Z}
\]   \[\phi_k(0) = \frac{1}{k!}
\]

The sequence is fundamental in exponential integrators and provides exact integration of polynomial source terms multiplied by exponential decay. These functions are also known as the matrix $\phi$-\/functions and appear in the exact solution of linear ODEs with polynomial forcing terms.
