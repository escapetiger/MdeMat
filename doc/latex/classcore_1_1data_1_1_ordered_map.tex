\doxysubsection{Detailed Description}
Key-\/value map that preserves insertion order. 

\doxylink{classcore_1_1data_1_1_ordered_map}{Ordered\+Map} provides containers.\+Map-\/like interface but preserves insertion order of elements. Supports basic operations (get, set, remove, is\+Key) and adds methods for order manipulation.
