\doxysubsection{Detailed Description}
Local discontinuous Galerkin scheme for diffusion equations. 

\doxylink{classphysics_1_1diffusion_1_1_ldg_scheme}{Ldg\+Scheme} implements a local discontinuous Galerkin method for solving diffusion equations using discontinuous Galerkin discretization. The scheme supports both periodic and Dirichlet boundary conditions with elliptic assembly operations.
