\doxysubsection{Detailed Description}
Explicit Runge-\/\+Kutta integrator. 

\doxylink{classapprox_1_1odeint_1_1_exrk_integrator}{Exrk\+Integrator} implements explicit Runge-\/\+Kutta methods for solving ordinary differential equations of the form\+:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + F(u) + S,
\]

where $M$ is a mass operator, $L$ is a linear operator, $F(u)$ is a nonlinear operator, and $S$ is a source term. Any of these terms can be empty (indicating they vanish from the equation). When M is empty, it defaults to identity. All non-\/empty terms are treated explicitly, making this suitable for non-\/stiff problems where stability constraints are manageable.

Explicit RK methods have excellent stability properties for non-\/stiff problems but may require small time steps for stability when applied to stiff systems.
