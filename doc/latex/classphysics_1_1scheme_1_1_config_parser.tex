\doxysubsection{Detailed Description}
Configuration file parser for KEY=VALUE format. 

\doxylink{classphysics_1_1scheme_1_1_config_parser}{Config\+Parser} provides a robust interface for reading and processing configuration files that use KEY=VALUE syntax. Supports extracting options as MATLAB variables, dynamically adding directories to the MATLAB path, and handling various configuration settings with default values and validation.

The parser supports three main configuration directives\+:


\begin{DoxyItemize}
\item OPTION=name=value\+: Defines configuration options with automatic type conversion
\item MATLABPATH=path\+: Adds directories to MATLAB\textquotesingle{}s search path
\item SUBDIRS=path\+: Recursively adds all subdirectories to MATLAB\textquotesingle{}s search path
\end{DoxyItemize}

Type conversion is performed automatically for numeric values, logical values (true/false), and MATLAB expressions. String values are preserved as-\/is. Default values and validators can be configured for each option using the add\+Config method.

Configuration files use KEY=VALUE format with \# for comments. Empty lines and comment lines are ignored during parsing. All parsed options are stored in the Config property, and added paths are tracked in obj.\+Config.\+paths for removal using the \doxylink{classphysics_1_1scheme_1_1_config_parser_a444c2b7e2a258ae3a19ba1ac395cfe0e}{reset()} method.
