\doxysubsection{Detailed Description}
Base class for all mesh-\/based function spaces. 

\doxylink{classapprox_1_1space_1_1_mesh_space}{Mesh\+Space} represents a function space defined over a geometric mesh. It serves as the foundation of classical numerical methods leveraging the local approximation techniques, such as finite element method, finite difference method and finite volume method.
