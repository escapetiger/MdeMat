\doxysubsection{Detailed Description}
Base class for all hyperspherical geometries. 

\doxylink{classcore_1_1geometry_1_1_hyperspherical_geometry}{Hyperspherical\+Geometry} provides common functionality for hyperspherical geometries such as hyperball (solid sphere) and hypersphere (surface). It implements coordinate transformations between Cartesian and hyperspherical coordinates, and provides helper methods for computing distances between points in the domain.
