\doxysubsection{Detailed Description}
$H^1$ Sobolev space element. 

\doxylink{classapprox_1_1element_1_1_h1_element}{H1\+Element} implements an $H^1$ element function suitable for problems requiring both function values and first derivatives. This class extends the base \doxylink{classapprox_1_1element_1_1_element}{Element} class by adding volume integration capabilities through precomputed basis function values and first-\/order derivatives at integration points.
