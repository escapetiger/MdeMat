\doxysubsection{Detailed Description}
Abstract base class for ODE integrators. 

\doxylink{classapprox_1_1odeint_1_1_ode_integrator}{Ode\+Integrator} provides a common interface and shared functionality for all ODE integration methods. This base class manages solution history, timeline operations, and linear system solving infrastructure. Concrete integrators must implement the abstract methods for specific integration schemes.

The class focuses on solving ordinary differential equations of the form\+:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + F(u) + S(t),
\]

where $M$ is a mass operator, $L$ is a linear operator, $F(u)$ is a nonlinear operator, and $S(t)$ is a source term. Any of these terms can be empty. In particular, M = \mbox{[}\mbox{]} means the mass operator reduces to an identity operator; \{L, F, S\} = \mbox{[}\mbox{]} means they vanish from the equation.

The contribution of mass operator M is determined by the physical simulation framework\+:
\begin{DoxyItemize}
\item In the Eulerian framework, M is space-\/only so that it can be represented by a unique static matrix.
\item In the Semi-\/\+Lagrangian framework, M is time-\/dependent. The Lhs mass term is forced to be a unique static matrix as in Eulerian framework. However, the Rhs mass term should be updated as time evolves. In particular, M is a matrix under periodic boundary conditions, while M is a pair formed by a matrix and a vector under Dirichlet boundary conditions.
\end{DoxyItemize}

Update the solution history with a new solution. 

obj = update(obj, U) shifts the existing solution history and adds the new solution at the most recent position. For multi-\/step methods, this maintains the required number of previous solutions. For single-\/step methods, simply stores the current solution.
