\doxysubsection{Detailed Description}
Base class for physics simulation schemes. 

The \doxylink{classphysics_1_1_scheme}{Scheme} class provides a common framework for physics simulation schemes, managing time integration loops, performance monitoring, visualization, and analysis workflows. It defines the essential structure for numerical solution procedures while allowing specific implementations through abstract method definitions.

Key features include\+:
\begin{DoxyItemize}
\item Standardized time integration workflow
\item Integrated performance timing and monitoring
\item Visualization and analysis pipeline management
\item Configurable verbose output and reporting
\item Extensible architecture for different physics models
\end{DoxyItemize}

\begin{DoxyNote}{Note}
This is an abstract base class that cannot be instantiated 

directly. Concrete subclasses must implement all abstract methods 

to define specific physics and numerical schemes. 
\end{DoxyNote}
