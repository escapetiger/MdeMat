\doxysubsection{Detailed Description}
Linear approximator based on modal information. 

\doxylink{classapprox_1_1linear_1_1_modal_approximator}{Modal\+Approximator} implements a linear approximation method that uses modal basis functions, such as Legendre, Chebyshev, or Fourier polynomials, etc. The underlying projection and fitting operators coincide in this case. The mass matrix  $M_{ij} = \langle p_i,
p_j\rangle$ is constructed using numerical integration with specified quadrature points and weights.

Set up the design operator using numerical integration. 

obj = set\+Design(obj, X, w) constructs the design matrix using integration points and weights. The (i,j) entry of the design matrix is $\langle p_i, p_j\rangle$ where the inner product is defined by the weighted integration\+:

\[\langle f,g\rangle = \sum_k w_k f(x_k) g(x_k)
