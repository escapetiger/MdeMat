\doxysubsection{Detailed Description}
Base class for computational meshes. 

\doxylink{classapprox_1_1mesh_1_1_mesh}{Mesh} provides foundational functionality for computational meshes in numerical approximation methods. It defines common interfaces for coordinate transformations, mesh refinement, and geometric computations while supporting efficient caching of expensive operations.

The class manages coordinate transformations between reference and physical coordinate systems, computes Jacobian matrices and their determinants for integration quadrature, and provides mesh refinement capabilities for adaptive algorithms.

Transformation data is cached using bitwise flags to avoid redundant computations\+:
\begin{DoxyItemize}
\item 0b00001\+: Outward normals computed
\item 0b00010\+: Face Jacobian determinants computed
\item 0b00100\+: Element inverse Jacobians computed
\item 0b01000\+: Element Jacobian determinants computed
\item 0b10000\+: Element Jacobians computed
\end{DoxyItemize}
