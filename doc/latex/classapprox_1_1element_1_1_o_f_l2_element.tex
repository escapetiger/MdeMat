\doxysubsection{Detailed Description}
Oscillation-\/free $L^2$ element. 

\doxylink{classapprox_1_1element_1_1_o_f_l2_element}{OFL2\+Element} extends the standard \doxylink{classapprox_1_1element_1_1_l2_element}{L2\+Element} by adding flux derivative evaluation capabilities for oscillation-\/free treatment in Galerkin methods. This element type is particularly useful for problems where standard Galerkin methods may produce spurious oscillations, such as advection-\/dominated transport problems.
