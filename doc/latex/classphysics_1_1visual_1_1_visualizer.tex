\doxysubsection{Detailed Description}
Base class for visualizers. 

\doxylink{classphysics_1_1visual_1_1_visualizer}{Visualizer} provides comprehensive plotting capabilities for physics simulations, including support for exact solution comparisons and temporal interpolation. It manages plot timelines, rendering strategies, and coordinate visualization workflows using \doxylink{classphysics_1_1visual_1_1_figure_manager}{Figure\+Manager} for automatic figure positioning and \doxylink{classphysics_1_1visual_1_1_database}{Database} for centralized data and geometry management.

The class uses a handle-\/based design to manage visualization state efficiently across multiple time steps and solution updates. Default styling is automatically applied based on dataset types.
