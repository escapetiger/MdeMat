\doxysubsection{Detailed Description}
Configuration file parser for KEY=VALUE format. 

\doxylink{classcore_1_1io_1_1_option_parser}{Option\+Parser} provides a robust interface for reading and processing configuration files that use KEY=VALUE syntax. Supports extracting options as MATLAB variables, dynamically adding directories to the MATLAB path, and handling various configuration settings.

The parser supports three main configuration directives\+:


\begin{DoxyItemize}
\item OPTION=name=value\+: Defines configuration options with automatic type conversion
\item MATLABPATH=path\+: Adds directories to MATLAB\textquotesingle{}s search path
\item SUBDIRS=path\+: Recursively adds all subdirectories to MATLAB\textquotesingle{}s search path
\end{DoxyItemize}

Type conversion is performed automatically for numeric values, logical values (true/false), and MATLAB expressions. String values are preserved as-\/is.

Configuration files use KEY=VALUE format with \# for comments. Empty lines and comment lines are ignored during parsing. All added paths are tracked and can be removed using the \doxylink{classcore_1_1io_1_1_option_parser_a61a40f6d5b8f7d32cff8bd83b82665e6}{reset()} method.
