\doxysubsection{Detailed Description}
First-\/order Lie-\/\+Trotter operator splitting. 

\doxylink{classapprox_1_1odeint_1_1_lie_trotter_integrator}{Lie\+Trotter\+Integrator} implements the first-\/order Lie-\/\+Trotter operator splitting method for solving ordinary differential equations of the form\+:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = \sum_{i=1}^{n} (L_i u +
F_i(u) + S_i)
\]

by decomposing it into n separate sub-\/problems\+:    \[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = L_i u + F_i(u) + S_i, \quad
i = 1, 2, \ldots, n
\]

The Lie-\/\+Trotter method uses the splitting formula\+:    \[e^{(A_1+A_2+\cdots+A_n)\Delta t} \approx e^{A_1\Delta t}
e^{A_2\Delta t} \cdots e^{A_n\Delta t}
\]

This achieves first-\/order accuracy with global error  $O(\Delta
t)$. Each factor integrator solves its respective sub-\/problem using the most appropriate method (explicit, implicit, or IMEX).

Advance one time step using augmented Lie-\/\+Trotter splitting. 

U = step\+A(obj, L, F, S, M, P, A, B, C) performs one time step by sequentially applying each factor integrator to its corresponding constrained sub-\/problem. The method decomposes the augmented differential-\/algebraic equation\+:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = \sum_{i=1}^{n} (L_i
u + F_i(u) + P_i v + S_i), \quad 0 = \sum_{i=1}^{n} (A_i
u + B_i v + C_i)
\]

into n separable constrained sub-\/problems that are solved in sequence. Each factor integrator handles its respective constraint parameters {\itshape P}, {\itshape A}, {\itshape B}, and {\itshape C} through its augmented stepA method, maintaining first-\/order accuracy for the coupled system.
