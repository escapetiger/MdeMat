\doxysubsection{Detailed Description}
Base class for all schemes solving poisson equations. 

\doxylink{classphysics_1_1poisson_1_1_poisson_scheme}{Poisson\+Scheme} implements a numerical scheme for solving poisson equations. This base class defines the basic validation and parse logic of configuration struct.
