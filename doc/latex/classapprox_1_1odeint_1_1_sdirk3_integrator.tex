\doxysubsection{Detailed Description}
Third-\/order SDIRK integrator. 

\doxylink{classapprox_1_1odeint_1_1_sdirk3_integrator}{Sdirk3\+Integrator} implements a third-\/order SDIRK method with three stages for solving ordinary differential equations of the form\+:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + S,
\]

where $M$ is a mass operator, $L$ is a linear operator, and $S$ is a source term. This method is A-\/stable and provides good stability properties for stiff problems. The diagonal elements of the Butcher tableau are identical.

The method uses $\gamma = 0.435866521508459$, which is chosen to optimize stability properties while maintaining third-\/order accuracy. The method requires three implicit solves per time step.
