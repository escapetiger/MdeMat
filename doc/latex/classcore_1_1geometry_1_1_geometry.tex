\doxysubsection{Detailed Description}
Base class for all geometries. 

\doxylink{classcore_1_1geometry_1_1_geometry}{Geometry} defines the common properties and interfaces for all geometric objects in the Mde\+Mat library. This abstract base class establishes the fundamental interface that all geometric entities must implement, including magnitude calculation and point containment testing. Concrete subclasses implement specific geometry types such as polytopes and hyperspherical geometries.

This is an abstract base class that cannot be instantiated directly. All geometric objects inherit from this class and must implement the abstract methods \doxylink{classcore_1_1geometry_1_1_geometry_a3236c7bd738217cc0cdd57944269a065}{magnitude()}, \doxylink{classcore_1_1geometry_1_1_geometry_a245810d2340c87126da6b14ea035548c}{is\+Inside()}, and \doxylink{classcore_1_1geometry_1_1_geometry_a9a403f87832c86f19c2de43902098d11}{is\+On\+Boundary()}.
