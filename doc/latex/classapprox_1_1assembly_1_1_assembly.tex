\doxysubsection{Detailed Description}
Base class for assembly operations. 

\doxylink{classapprox_1_1assembly_1_1_assembly}{Assembly} provides the foundation for assembling discrete operators from finite-\/dimensional function spaces. The assembly process involves iterating over mesh elements, computing local data, and accumulating contributions into global sparse data using appropriate connectivity information from the mesh space.
