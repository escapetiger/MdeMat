\doxysubsection{Detailed Description}
C0 element defined on orthotope domains. 

\doxylink{classapprox_1_1element_1_1_c0_orthotope_element}{C0\+Orthotope\+Element} extends \doxylink{classapprox_1_1element_1_1_c0_element}{C0\+Element} for orthotope geometries with various basis function types and reduction schemes. The element supports 1D (interval), 2D (rectangle), and 3D (cuboid) domains with orthogonal basis functions.
