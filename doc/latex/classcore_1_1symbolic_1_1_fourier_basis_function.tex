\doxysubsection{Detailed Description}
Real-\/valued Fourier basis functions. 

\doxylink{classcore_1_1symbolic_1_1_fourier_basis_function}{Fourier\+Basis\+Function} represents real-\/valued Fourier basis functions on a specified interval. The basis functions include a constant term and sine/cosine harmonics. The functions are scaled from the canonical interval $[0, 2\pi]$ to the given bounding box.

The first five Fourier basis functions with wavelength  $\omega =
\frac{2\pi}{b-a}$ are\+:       \[\phi_0(x) = 1,
\phi_1(x) = \cos(\omega x),
\phi_2(x) = \sin(\omega x),
\phi_3(x) = \cos(2\omega x),
\phi_4(x) = \sin(2\omega x).
\]
