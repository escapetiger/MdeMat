\doxysubsection{Detailed Description}
Interpolation basis using cardinal kernel methods. 

\doxylink{classcore_1_1function_1_1_cardinal_kernel_basis}{Cardinal\+Kernel\+Basis} represents a set of cardinal interpolation basis functions using barycentric coordinates for efficient evaluation. The basis functions are constructed from given node points and provide interpolation properties at those nodes.
