\doxysubsection{Detailed Description}
Abstract class for functions with compiled metadata. 

Abstract base class for general functions from Euclidean.

Abstract class for functions that support.

Base class for compiled differentiable.

from the \doxylink{namespacecore_1_1symbolic}{core.\+symbolic} module.

Compiled\+Function automatically loads precompiled function handles and metadata from the +core/metadata/basis directory. This provides a bridge between symbolic function definitions and efficient numerical evaluation.

The class supports automatic metadata discovery, caching, and efficient function evaluation using precompiled function handles.

This class combines the capabilities of Compiled\+Function and Differentiable\+Function to provide automatic metadata loading and efficient derivative evaluation using precompiled function handles.

The class automatically discovers and loads compiled metadata from the +core/metadata/basis directory, providing both function evaluation and derivative computation capabilities.
