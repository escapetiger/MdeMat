Detailed Description

Base class for all symbolic functions.

SymbolicFunction provides a foundation for creating and manipulating symbolic mathematical expressions with a consistent interface. This class serves as a base for implementing specialized symbolic function types while maintaining uniform evaluation and conversion capabilities.

% Create a symbolic function with default variable
obj = SymbolicFunction();
% Create with custom variables
vars = {sym('x'), sym('y')};
obj = SymbolicFunction(vars);
