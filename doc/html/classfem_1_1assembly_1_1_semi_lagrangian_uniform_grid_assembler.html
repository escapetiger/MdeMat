Detailed Description

Grid-based assembler for semi-Lagrangian methods.

SemiLagrangianUniformGridAssembler provides assembly methods for semi-Lagrangian finite element operators on uniform structured grids. This specialized assembler handles transport operators and boundary conditions for semi-Lagrangian discretizations.

The assembler supports both free transport operators and boundary condition assembly, with particular emphasis on handling characteristic tracing and interpolation required by semi-Lagrangian methods.

% Create semi-Lagrangian assembler with periodic boundaries
assembler = SemiLagrangianUniformGridAssembler(fe, mesh, op, 0);
% Assemble transport operator only
A = assembler.transport();
% Assemble both transport and boundary conditions
[b, A] = assembler.transport(t0, t1, boundaryFunction);
