Detailed Description

Unit tests for MultiIndexer class.

TestMultiIndexer provides test coverage for MultiIndexer functionality including index generation and conversion between multi-indices and linear indices.

% Run all tests
results = runtests(core.linalg.tests.TestMultiIndexer);
