2 % SDIRK2INTEGRATOR Second-order SDIRK integrator.
3 %
4 % Sdirk2Integrator implements a second-order SDIRK method with two
5 % stages for solving ordinary differential equations of the form:
6 %
7 % \f[
8 % \frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + S,
9 % \f]
10 %
11 % where \f$M\f$ is a mass operator, \f$L\f$ is a linear operator, and
12 % \f$S\f$ is a source term. This method is L-stable and A-stable,
13 % making it suitable for stiff problems. The diagonal elements of the
14 % Butcher tableau are identical.
15 %
16 % The method uses the parameter \f$\gamma = 1 - \sqrt{2}/2 \approx
17 % 0.2928932188\f$, which ensures L-stability and optimal damping
18 % properties for stiff systems.
19 %
20 % See also:
21 % approx.odeint.DirkIntegrator, approx.odeint.Sdirk3Integrator,
22 % approx.odeint.Esdirk3Integrator
23
