2 % METRIC Base class for error and distance metrics.

4 % Metric defines the interface for computing distances and errors
5 % between abstract mathematical objects such as functions, solutions,
6 % or data sets. This class serves as the foundation for all specific
7 % metric implementations used in numerical analysis and error
8 % computation.
9 %
10 % All concrete metric classes must inherit from this base class and
11 % implement the abstract evaluate method to define how errors are
12 % computed for their specific use case. The class supports various
