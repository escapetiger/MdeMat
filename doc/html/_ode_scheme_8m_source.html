1classdef OdeScheme < physics.scheme.Scheme
2 % ODESCHEME Base class for ODE integration schemes.
3 %
4 % OdeScheme provides the fundamental framework for ordinary
5 % differential equation integration schemes. It defines the common
6 % interface and workflow for all concrete ODE scheme implementations.
7 %
8 % The class manages temporal discretization through various ODE
9 % integration methods including backward Euler, BDF, SDIRK, forward
10 % Euler, Heun, and SSPRK schemes. It also supports operator splitting
11 % methods for multi-physics problems.
12 %
13 % See also:
14 % physics.scheme.Scheme, approx.odeint.OdeIntegrator
