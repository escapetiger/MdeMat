Detailed Description

Base class for multidimensional structured grids.

Grid provides a foundational framework for representing structured computational grids using memory-efficient tensor-based storage. Unlike unstructured meshes that store explicit connectivity, structured grids leverage their regular topology to achieve O(d×n) memory usage instead of O(n^d) for d-dimensional grids with n elements per dimension.
