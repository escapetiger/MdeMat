Detailed Description

Base class for multidimensional structured grids.

Grid provides a foundational framework for representing structured computational grids using memory-efficient tensor-based storage. Unlike unstructured meshes that store explicit connectivity, structured grids leverage their regular topology to achieve O(d×n) memory usage instead of O(n^d) for d-dimensional grids with n elements per dimension.

The class implements a tensor-product structure where:

  • Grid vertices form a Cartesian product of 1D coordinate arrays
  • Element connectivity follows regular patterns in each dimension
  • Neighbor relationships are computed algorithmically rather than stored
  • Boundary faces are identified by coordinate extrema

Reference coordinate system uses the hypercube [-1/2, 1/2]^d, providing a canonical domain for finite element basis functions and quadrature rules. Coordinate transformations between reference and physical spaces are handled by concrete subclasses (UniformGrid, NonuniformGrid).

The MultiIndexer facilitates efficient conversion between:

  • Linear indices: Single integers identifying grid elements [1, N]
  • Multi-indices: d-tuples specifying position in each dimension
  • Factor indices: Separate indexing within each dimensional factor

InputType IFE )

Find linear indices of boundary elements.

IE = findBoundaryElements(obj, IFE) computes linear indices of elements that share the specified boundary face, essential for applying boundary conditions in numerical methods.

Parameters
obj- The Grid object
IFE- Boundary face index (1 to 2×nDims)
Return values
IE- Linear indices of boundary elements (vector)
Note
Face numbering follows the convention:
- Face 1: Lower boundary in dimension 1 (x_min)
- Face 2: Upper boundary in dimension 1 (x_max)
- Face 3: Lower boundary in dimension 2 (y_min)
- Face 4: Upper boundary in dimension 2 (y_max)
- And so forth for higher dimensions
Boundary elements have one coordinate at the domain extremum
while others vary over the full range.

◆ findInteriorElements()

function approx::mesh::Grid::findInteriorElements ( InputType obj)

Find linear indices of interior elements.

IE = findInteriorElements(obj) computes linear indices of elements that do not touch the domain boundary, useful for applying different numerical schemes to interior and boundary regions.

Parameters
obj- The Grid object
Return values
IE- Linear indices of interior elements (vector)
Note
Interior elements are those with indices [2, n_i-1] in
every dimension i, where n_i is the number of elements in
dimension i. This excludes the first and last layer of
elements which touch the boundary.
For a 2D grid with resolution [nx, ny], interior elements
have multi-indices (i,j) where 2 ≤ i ≤ nx-1 and 2 ≤ j ≤
ny-1.

function approx::mesh::Grid::findNeighborElements ( InputType obj,
InputType IE,
InputType IFE,
InputType BC )

Find neighboring elements across faces.

[JE, JFE] = findNeighborElements(obj, IE, IFE, BC) computes neighbor elements sharing the specified local face of given elements, with appropriate boundary condition treatment.

Parameters
obj- The Grid object
IE- Linear indices of primary elements (vector)
IFE- Local face index (1 to 2×nDims)
BC- Boundary condition ('periodic' or 'dirichlet')
Return values
JE- Linear indices of neighbor elements (vector)
JFE- Local face indices of neighbors (vector)
Note
Local face numbering matches global boundary face
numbering. For structured grids, neighbors are found by
shifting element coordinates by ±1 in the appropriate
dimension.
Boundary condition handling:
- 'periodic': Wrap around at domain boundaries (torus topology)
- 'dirichlet': No neighbors across domain boundaries (JE = 0)
The neighbor's local face index JFE is always opposite to
IFE: if element E has neighbor N across face IFE, then N
has E across face JFE where JFE = 2×ceil(IFE/2) -
mod(IFE-1,2).
