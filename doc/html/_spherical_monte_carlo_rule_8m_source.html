2 % SPHERICALMONTECARLORULE Monte Carlo integration rule on hypersphere.
3 %
4 % SphericalMonteCarloRule implements Monte Carlo integration over
5 % hyperspheres of arbitrary dimension using the normalized Gaussian
6 % method for uniform point generation. This method is particularly
7 % useful for high-dimensional integration problems and integrands
8 % with discontinuities or singularities.
9 %
10 % The implementation uses the normalized Gaussian method:
11 % multivariate normal random vectors are generated and normalized to
12 % unit length, ensuring uniform distribution on the hypersphere
13 % surface.
