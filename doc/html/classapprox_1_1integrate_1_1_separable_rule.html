Detailed Description

Separable multidimensional integration rule.

SeparableRule creates multidimensional integration rules by taking tensor products of one-dimensional rules. This approach is efficient for integrating functions that can be separated into products of univariate functions or for rectangular integration domains.

Examples: % Create a 2D separable rule from two Gauss-Legendre rules rule1D = approx.integrate.GaussLegendreRule(); rule2D = SeparableRule({rule1D, rule1D});

% Generate integration points [X, w] = rule2D.generate({5}, {5});

% Use static methods for common rules gaussRule3D = SeparableRule.gaussLegendre(3);

Note
The separable rule constructs multidimensional quadrature by
taking tensor products of univariate rules. This is most efficient
for functions that exhibit separability or low-rank structure.

VariableInputType varargin )

Generate separable integration rule nodes and weights.

[X, w] = generate(obj, varargin) generates multidimensional integration nodes and weights and takes tensor products of the constituent univariate rules.

Inputs: obj - The SeparableRule object varargin - Cell array of arguments for each factor rule

Outputs: X - Integration nodes (nDims x nPoints or 1 x nDims cell array) w - Integration weights (1 x nPoints or 1 x nDims cell array)
