Detailed Description

Grid-based assembler for auxiliary variables.

AuxiliaryGridAssembler implements Dirichlet boundary treatment for auxiliary variables in mixed finite element systems. This class handles coupling terms between primal and auxiliary variables with both interior and extraction contributions.

The assembler specializes in handling jump terms and boundary conditions specific to auxiliary variable formulations in mixed methods and discontinuous Galerkin schemes.

% Create auxiliary assembler with left flux and Dirichlet BC
assembler = AuxiliaryGridAssembler(fe, mesh, op, 1, 1);
% Assemble outer jump operator
jumpMatrix = assembler.outerJump(1, [1.0, 0.5]);
% Use in divergence computation
divMatrix = assembler.divergence([1.0, 0.5]);

A = outerJump(obj, d, c) creates the outer jump operator matrix for auxiliary variables along the specified dimension. This handles jump discontinuities at element boundaries for mixed formulations.
