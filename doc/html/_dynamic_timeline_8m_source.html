1classdef DynamicTimeline < approx.mesh.Timeline
2 % DYNAMICTIMELINE Adaptive time stepping timeline.
3 %
4 % DynamicTimeline represents a temporal discretization with
5 % dynamically computed time step sizes. This class is particularly
6 % useful for simulations where the time step needs to be adjusted
7 % based on spatial discretization constraints (e.g., CFL conditions)
8 % or solution behavior.
9 %
10 % The time step is computed as \f$\Delta t = C * h^p\f$ where \f$h\f$
11 % is the spatial mesh parameter, \f$C\f$ is a convergence constant
12 % (e.g., CFL number), and \f$p\f$ is an exponent (default 1).
13 %
14 % See also:
15 % approx.mesh.Timeline, approx.mesh.StaticTimeline

69 %

85 end
