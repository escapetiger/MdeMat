1classdef DynamicTimeline < approx.mesh.Timeline
2 % DYNAMICTIMELINE Adaptive time stepping timeline.
3 %
4 % DynamicTimeline represents a temporal discretization with
5 % dynamically computed time step sizes. This class is particularly
6 % useful for simulations where the time step needs to be adjusted
7 % based on spatial discretization constraints (e.g., CFL conditions)
8 % or solution behavior.
9 %
10 % Examples:
11 % % Create dynamic timeline with final time 10
12 % timeline = DynamicTimeline(10);
13 %
14 % % Set time step based on CFL condition
15 % timeline.setTimeStep(0.1, 0.5); % h=0.1, CFL=0.5
16 %
17 % % Advance through time
18 % while ~timeline.isFinished()
19 % timeline.advance();
20 % % Update time step if needed
21 % timeline.setTimeStep(newH, cflNumber);
22 % end
23 %
24 % Notes:
25 % The time step is computed as dt = C * h^p where h is the spatial
26 % mesh parameter, C is a convergence constant (e.g., CFL number),
27 % and p is an exponent (default 1).
28 %
