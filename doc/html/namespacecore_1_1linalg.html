Constructs a block matrix from a 2D cell array of matrices.

S = block(As) infers the block dimensions and returns a block matrix from a cell array of matrices.

S = block(As, Ms, Ns) returns a block matrix from a cell array of matrices with specified row and column dimensions.

Each nonempty cell in As corresponds to a block in S. The function automatically detects whether to create sparse or dense output based on input matrix types. When Ms and Ns are not provided, dimensions are inferred from the first nonempty block in each row and column.

Inverse of unfold.

T = fold(A, n, d) returns a tensor T of shape n obtained by folding a matrix A along the dimension d.

This function reverses the unfold operation by reshaping matrix A back into tensor form with shape n. The folding occurs along dimension d, which determines the reshaping pattern. Matrix A should have dimensions [n(d), prod(n)/n(d)].

function core::linalg::khatrirao ( InputType U,
VariableInputType varargin )

Compute Khatri-Rao product of input matrices.

X = khatrirao(A, B) computes column-wise Kronecker product of matrices A and B. For matrices A (I-by-K) and B (J-by-K), result is (I*J)-by-K matrix where each column k is Kronecker product of k-th columns of A and B.

X = khatrirao(U) computes Khatri-Rao product when U is a cell array of matrices.

The Khatri-Rao product computes column-wise Kronecker products, preserving the number of columns while expanding rows. All input matrices must have the same number of columns. Operation proceeds from right to left through the input matrices.

◆ kronecker()

function core::linalg::kronecker ( VariableInputType varargin)

Kronecker product of multiple matrices.

K = kronecker(A1, A2, ...) computes Kronecker product of all input matrices, with operation carried out from right to left. Extends MATLAB's built-in kron to handle multiple matrices.

K = kronecker(As) computes Kronecker product when input is a cell array As of matrices.

This function extends MATLAB's built-in kron function to handle multiple matrices efficiently. The operation is computed from right to left, so kronecker(A, B, C) equals kron(A, kron(B, C)).

Tensor matricization.

A = unfold(T, n, d) returns a matrix A obtained by unfolding a tensor T of shape n along the dimension d.

This function performs tensor matricization by reshaping tensor T into matrix form. Dimension d becomes the rows, while all other dimensions are flattened into columns. The resulting matrix has dimensions [n(d), prod(n)/n(d)].

Set array entries below threshold to zero.

X = zeroing(X) replaces values in array X smaller than the default tolerance with zeros.

X = zeroing(X, tol) replaces values in array X smaller than the specified tolerance tol with zeros.

This function removes numerical noise by setting values with absolute magnitude below tolerance tol to zero. Uses default tolerance of eps*1e3 when tol is not specified. Operation is applied element-wise to the entire array X.
