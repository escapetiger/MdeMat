2 % RECORD Individual timing measurement with state management.
3 %
4 % Record represents a single named timing operation that tracks
5 % active/inactive state and accumulates elapsed time across multiple
6 % measurement sessions. Each record maintains a name identifier,
7 % cumulative duration, and timing token for active measurements.
8 %
9 % The Record class provides the fundamental timing primitive used by
10 % the Timer class. It maintains state information to distinguish
11 % between active timing (when a measurement is in progress) and
12 % inactive timing (when no measurement is running). Duration values
13 % accumulate across multiple start/stop cycles.
