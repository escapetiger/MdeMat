1classdef FiniteElementAssembly < approx.assembly.Assembly
2 % FINITEELEMENTASSEMBLY Base class for finite element assembly
3 % operations.
4 %
5 % FiniteElementAssembly provides the foundation for assembling
6 % discrete operators from finite element spaces. The assembly process
7 % involves iterating over mesh elements, computing local data, and
8 % accumulating contributions into global sparse data using
9 % appropriate connectivity information from the finite element space.
10 %
11 % The class provides essential methods for creating sparse matrices
12 % and vectors from local element contributions. Local matrices and
13 % vectors computed on individual elements are assembled into global
14 % sparse structures using element connectivity information from the
15 % finite element space.
16 %
17 % Key assembly operations include matrix assembly from element-wise
18 % contributions, vector assembly from local vectors, and batched
19 % vector assembly for multiple right-hand sides. The class handles
20 % the mapping between local element degrees of freedom and global
21 % system indices.
22 %
23 % See also:
24 % approx.assembly.Assembly, approx.space.FiniteElementSpace
