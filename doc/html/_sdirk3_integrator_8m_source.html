2 % SDIRK3INTEGRATOR Third-order SDIRK integrator.
3 %
4 % Sdirk3Integrator implements a third-order SDIRK method with three
5 % stages for solving ordinary differential equations of the form:
6 %
7 % \f[
8 % \frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + S,
9 % \f]
10 %
11 % where \f$M\f$ is a mass operator, \f$L\f$ is a linear operator, and
12 % \f$S\f$ is a source term. This method is A-stable and provides good
13 % stability properties for stiff problems. The diagonal elements of
14 % the Butcher tableau are identical.
15 %
16 % The method uses \f$\gamma = 0.435866521508459\f$, which is chosen
17 % to optimize stability properties while maintaining third-order
18 % accuracy. The method requires three implicit solves per time step.
19 %
20 % See also:
21 % approx.odeint.DirkIntegrator, approx.odeint.Sdirk2Integrator,
22 % approx.odeint.Sdirk4Integrator
23

26 end
