1classdef L2Element < approx.element.Element
2 % L2ELEMENT \f$L^2\f$ element with volume and flux integration.
3 %
4 % L2Element implements a discontinuous finite element based on the
5 % \f$L^2\f$ function space. This class extends the base Element class
6 % by adding volume and flux integration capabilities through
7 % precomputed basis values and derivatives at integration points.
8 %
9 % L2Element assumes discontinuity occurs only at element boundaries,
10 % making them suitable for discontinuous Galerkin (DG) methods and
11 % finite volume schemes. The element supports both modal (orthogonal)
12 % and nodal (interpolation) basis functions.
13 %
14 % See also:
15 % approx.integrate.IntegrationData, approx.element.Element
