Detailed Description

Function representing the composition of two functions.

Composition represents the mathematical composition of two functions:

\[(f \circ g)(x) = f(g(x)) \]

where the output dimension of the inner function rhs must match the input dimension of the outer function lhs. The composition maps from the input space of rhs to the output space of lhs.

For derivatives, the chain rule is applied:

\[\frac{d}{dx}(f \circ g)(x) = f'(g(x)) \cdot g'(x) \]

Higher-order derivatives use Faà di Bruno's formula for the composition of functions.

Constructor for the Composition class.

obj = Composition(f, g) creates a Composition representing the composition \(f(g(x))\) where lhs is the outer function \(f\) and rhs is the inner function \(g\). The output dimension of rhs must match the input dimension of lhs.
