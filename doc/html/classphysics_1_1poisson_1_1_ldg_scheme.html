Detailed Description

Base class for all schemes solving LDG equations.

LdgScheme implements an LDG scheme for solving Poisson equations.

See also

◆ LdgScheme()

function physics::poisson::LdgScheme::LdgScheme ( InputType options)

Construct an instance of LdgScheme.

obj = LdgScheme() creates a LdgScheme with default configuration.

obj = LdgScheme(file=file) creates a LdgScheme and loads configuration from the specified filename.

obj = LdgScheme(config=config) creates a LdgScheme with the specified config configuration.

obj = LdgScheme(file=file, config=config) loads configuration from file and then overrides with struct values.
