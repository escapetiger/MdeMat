Detailed Description

Third-order ESDIRK integrator.

Esdirk3Integrator implements a third-order ESDIRK method with three stages for solving ordinary differential equations of the form:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + S, \]

where \(M\) is a mass operator, \(L\) is a linear operator, and \(S\) is a source term. This method features an explicit first stage ( \(c_1 = 0\)) followed by two implicit stages, providing computational efficiency while maintaining good stability properties.

The parameter \(\gamma = (3 + \sqrt{3})/6 \approx 0.7886751346\) ensures third-order accuracy and A-stability. The explicit first stage reduces computational cost compared to fully implicit methods.
