Detailed Description

Uniform multidimensional structured grid.

UniformGrid represents a structured grid with uniform spacing defined by the number of elements per dimension and domain bounds. This class implements memory-efficient tensor-based storage with constant element sizes throughout the domain.

Uniform grids have constant element spacing within each dimension. The bounding box format is [a1, b1, a2, b2, ..., ad, bd] where [ai, bi] defines the interval for dimension i.
