Detailed Description

Structured grid with uniform element spacing.

UniformGrid represents a structured computational grid where elements have constant spacing within each dimension. This regularity enables highly efficient storage and computation since geometric properties (Jacobians, volumes, outN) are identical for all elements and can be computed once and reused.

The grid is defined by domain bounds and resolution, automatically generating element centers and uniform spacings. All coordinate transformations use simple affine mappings with constant coefficients, making uniform grids ideal for:

  • Finite difference methods requiring regular stencils
  • Spectral methods with tensor-product basis functions
  • Fast Fourier Transform-based solvers
  • Applications where geometric simplicity aids analysis

Storage efficiency: O(d) memory for grid definition vs O(n^d) for explicit storage, where d is spatial dimension and n is resolution per dimension. All geometric computations have O(1) complexity.

% 2D uniform grid: 50×30 elements on unit square
bbox2D = [0, 1, 0, 1]; % [x_min, x_max, y_min, y_max]
resolution2D = [50, 30];
grid2D = UniformGrid(bbox2D, resolution2D);
% 3D uniform grid: 20×20×10 elements on custom domain
bbox3D = [-1, 1, -2, 2, 0, 5]; % [x_min, x_max, y_min, y_max, z_min, z_max]
resolution3D = [20, 20, 10];
grid3D = UniformGrid(bbox3D, resolution3D);
% Query uniform grid properties
h = grid2D.computeMeasure(); % Minimum element spacing
detJ = grid2D.computeElementJacobianDeterminants(); % Constant for all elements
graph = grid2D.graphify(); % SeparableGraph representation
% Coordinate transformations
xRef = [0.2; -0.1]; % Reference coordinates in [-1/2, 1/2]^2
xPhys = grid2D.collocate(xRef, 100); % Map to element 100
% Mesh refinement (preserves uniformity)
fineGrid = grid2D.refine(2); % 2 levels: 200×120 elements
% Access grid structure
spacing = grid2D.spacings; % {h_x, h_y} constant per dimension
centers = grid2D.centroids; % {x_centers, y_centers} vectors
nTotal = grid2D.nElements; % Total elements = 50×30 = 1500
% Boundary and connectivity queries
interior = grid2D.findInteriorElements(); % Interior elements
leftBdry = grid2D.findBoundaryElements(1); % Left boundary (x_min)
rightBdry = grid2D.findBoundaryElements(2); % Right boundary (x_max)
[neighbors, faces] = grid2D.findNeighborElements(interior, 1, 'periodic');

Note
Domain specification uses the format [a_1, b_1, a_2, b_2, ..., a_d,
b_d] where [a_i, b_i] defines the interval for dimension i. The
constructor validates that b_i > a_i for all dimensions.
Element spacing in dimension i is h_i = (b_i - a_i)/n_i where n_i
is the number of elements in that dimension. Element centers are at
a_i + (k+0.5)h_i for k = 0, 1, ..., n_i-1.
All geometric computations exploit uniformity: Jacobian matrices
are diagonal with constant entries, face outN are axis-aligned,
and volume elements are identical throughout the grid.

Constructor for UniformGrid.

obj = UniformGrid(bbox, resolution) creates a uniform grid with constant element spacing determined by the domain bounds and specified resolution in each dimension.

Parameters
bbox- Domain bounding box [a₁, b₁, a₂, b₂, ..., aₐ, bₐ]
resolution- Number of elements per dimension (1 × d vector)
Note
The constructor automatically computes:
1. Element spacing: hᵢ = (bᵢ - aᵢ)/nᵢ for each dimension i
2. Element centers: aᵢ + (k+0.5)hᵢ for k = 0,1,...,nᵢ-1
3. Node coordinates: aᵢ + k·hᵢ for k = 0,1,...,nᵢ
4. Domain and reference element geometries
Input validation ensures bᵢ > aᵢ for proper domain definition.

Note
The uniform grid coordinate transformation is the simple

Compute outward normal vectors for all faces.

outN = computeAllOutwardNormals(obj) computes unit outward normal vectors for each face type. For uniform grids, outN are axis-aligned and constant for faces of the same type.

Parameters
obj- The UniformGrid object
Return values
outN- Outward normal vectors (cell array by face type)
Note
Face normal directions follow the standard convention:
- Face 2k-1: normal = -e_k (negative k-direction, "lower" face)
- Face 2k: normal = +e_k (positive k-direction, "upper" face)
where e_k is the unit vector in dimension k.
For example, in 2D:
- Face 1 (left): normal = [-1, 0]^T
- Face 2 (right): normal = [+1, 0]^T
- Face 3 (bottom): normal = [0, -1]^T
- Face 4 (top): normal = [0, +1]^T

graphObj = graphify(obj) creates a SeparableGraph that efficiently represents the uniform grid's tensor-product connectivity structure using 1D factors.

Parameters
obj- The UniformGrid object
Return values
graphObj- SeparableGraph with tensor-product structure
Note
The separable representation stores d 1D graphs instead of
one d-dimensional graph, reducing memory from O(n^d) to O(d×n).
Each 1D factor contains vertex coordinates and edge connectivity
for one dimension, with the full grid formed by tensor products.

virtual

Create uniformly refined grid with smaller elements.

newObj = refine(obj, nLevels) creates a refined uniform grid by subdividing each element uniformly. The refinement preserves the uniform spacing property while increasing resolution.

Parameters
obj- The UniformGrid object
nLevels- Number of refinement levels (non-negative integer)
Return values
newObj- Refined UniformGrid with 2^(nLevels) times more elements per dimension
- Level 0: Original grid (no refinement)
- Level 1: 2× resolution per dimension (4× elements in 2D)
- Level 2: 4× resolution per dimension (16× elements in 2D)
The refined grid maintains identical domain bounds and
uniform spacing properties as the original.
