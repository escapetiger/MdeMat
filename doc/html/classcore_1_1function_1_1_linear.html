Detailed Description

Function representing linear/affine transformations.

Linear represents linear/affine transformations of the form:

\[f(x) = A*x + b \]

where \(A\) is an \(m\times n\) matrix and \(b\) is an \(m\times 1\) vector. When \(b\) is not provided or is zero, this reduces to a pure linear transformation.
