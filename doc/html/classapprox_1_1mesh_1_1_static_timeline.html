Detailed Description

Predefined time node timeline.

StaticTimeline represents a temporal discretization with predefined time points. It advances through these points sequentially and provides information about the current state and properties of the timeline, including uniformity checks and time step queries.

% Create timeline with uniform time steps
timeline = StaticTimeline(10, 5.0); % 10 steps to time 5.0
% Create timeline with custom time nodes
customNodes = [0, 0.1, 0.5, 1.0, 2.0, 5.0];
timeline = StaticTimeline(customNodes);
% Advance through timeline
while ~timeline.isFinished()
currentTime = timeline.now;
dt = timeline.getTimeStep();
timeline.advance();
end
