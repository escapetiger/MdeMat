Detailed Description

Generate L1-constrained multi-indices.

L1MultiIndexer generates one-based multi-indices such that sum of indices is within specified bounds. Useful for sparse tensor approximation with L1-norm constraints.

Generate and cache L1-constrained multi-indices.

obj = setCache(obj, nDims=nDims, maxSum=maxSum) generates all multi-indices with nDims dimensions and sum <= sMax.

obj = setCache(obj, nDims=nDims, maxSum=maxSum, minSum=minSum) generates multi-indices with nDims dimensions and sum between minSum and maxSum.
