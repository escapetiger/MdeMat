Detailed Description

Function representing Hadamard product of two functions.

Product represents the element-wise (Hadamard) product of two functions with broadcasting support:

[ (f * g)(x) = f(x) .* g(x) ]

The class supports broadcasting following MATLAB's element-wise operation rules. Input dimensions must be identical, while output dimensions follow broadcasting compatibility rules. The class implements the product rule for derivatives:

[ (f * g)' = f' * g + f * g' ]

Implementation of product function derivative.

dY = diffImpl(obj, X, order) computes the derivative of the product function using the product rule: (f * g)' = f' * g + f * g'

For higher-order derivatives, this uses the generalized Leibniz rule (binomial expansion).
