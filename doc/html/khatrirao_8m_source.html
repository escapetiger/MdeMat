2% KHATRIRAO Compute Khatri-Rao product of input matrices.
3%
4% X = khatrirao(A, B) computes column-wise Kronecker product of matrices
5% @a A and @a B. For matrices A (I-by-K) and B (J-by-K), result is
6% (I*J)-by-K matrix where each column k is Kronecker product of k-th
7% columns of A and B.
8%
9% Inputs:
10% U - Cell array of matrices or head input matrix
11% varargin - Tailed input matrices
12%
13% Outputs:
14% X - Khatri-Rao product matrix
15%
16% Examples:
17% % Two-matrix Khatri-Rao product
18% A = [1 2; 3 4]; % 2-by-2 matrix
19% B = [5 6; 7 8]; % 2-by-2 matrix
20% X = khatrirao(A, B);
21%
22% % Sparse matrix Khatri-Rao product
23% As = sparse([1 0; 3 4]);
24% Bs = sparse([5 0; 0 8]);
25% X = khatrirao(As, Bs);
26%
27% See Also:
28% core.linalg.kronecker

30if ~iscell(U), U = [{U}, varargin]; end
