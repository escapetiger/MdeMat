4 % Hypersphere represents a generalized geometric surface that extends

6 % dimensions. It represents the set of points at a constant distance

54 % MAGNITUDE Returns the surface area of the hypersphere.
55 %
56 % m = magnitude(obj) computes the (n-1)-dimensional surface
57 % area of the hypersphere using the general formula for
58 % hyperspheres.
59
60 arguments
61 obj core.geometry.Hypersphere
62 end
63
64 nsd = obj.NSphDims;
65
66 r = obj.Radius;
67 switch nsd
68 case 0
69 tol = sqrt(eps);
