Detailed Description

Configuration file parser for KEY=VALUE format.

OptionParser provides a robust interface for reading and processing configuration files that use KEY=VALUE syntax. Supports extracting options as MATLAB variables, dynamically adding directories to the MATLAB path, and handling various configuration settings.

The parser supports three main configuration directives:

  • OPTION=name=value: Defines configuration options with automatic type conversion
  • MATLABPATH=path: Adds directories to MATLAB's search path
  • SUBDIRS=path: Recursively adds all subdirectories to MATLAB's search path

Type conversion is performed automatically for numeric values, logical values (true/false), and MATLAB expressions. String values are preserved as-is.

Configuration files use KEY=VALUE format with # for comments. Empty lines and comment lines are ignored during parsing. All added paths are tracked and can be removed using the reset() method.
