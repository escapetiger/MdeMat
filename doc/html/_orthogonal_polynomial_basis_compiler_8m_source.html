1classdef OrthogonalPolynomialBasisCompiler < core.symbolic.Compiler
2 % ORTHOGONALPOLYNOMIALBASISCOMPILER Compiler for orthogonal polynomial basis functions.
3 %
4 % OrthogonalPolynomialBasisCompiler specializes in compiling basis
5 % matrices for orthogonal polynomial families such as Legendre and
6 % Chebyshev polynomials. It creates and manages arrays of orthogonal
7 % polynomial basis functions with optional monic normalization.
8 %
9 % Supported orthogonal polynomial families:
10 % - Legendre: orthogonal on [-1,1] with weight w(x) = 1
11 % - Chebyshev: orthogonal on [-1,1] with weight w(x) = 1/√(1-x²)
12 % Both families support standard and monic forms.
13 %
14 % Examples:
15 % % Create compiler and set Legendre functions
16 % compiler = core.symbolic.OrthogonalPolynomialBasisCompiler();
17 % compiler.setFunctions(3, [0, 1], 'legendre');
18 %
19 % % Compile and load basis matrix
20 % compiler.compile('legendre_basis', 'Legendre', 2);
21 % metadata = compiler.load('legendre_basis');
22 %
23 % % Chebyshev polynomials in monic form
24 % compiler.setFunctions(4, [-1, 1], 'monic_chebyshev');
25 % compiler.compile('chebyshev_monic', 'Chebyshev_Monic', 1);
26 %
27 % See Also:
28 % core.symbolic.Compiler, core.symbolic.LegendreBasisFunction,
29 % core.symbolic.ChebyshevBasisFunction
