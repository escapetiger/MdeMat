2 % C0SEMILAGRANGIANFINITEELEMENTOPERATOR Semi-Lagrangian operator for
3 % continuous finite elements.
4 %
5 % C0SemiLagrangianFiniteElementOperator implements semi-Lagrangian
6 % operators for C0 finite elements. It manages piece-wise bilinear
7 % form data for volume integrals that arise from the intersection
8 % of Eulerian elements with upstream footprints in semi-Lagrangian
9 % transport schemes.
10 %
11 % The operator handles the complex geometry resulting from tracking
12 % fluid parcels backward along characteristic curves. Each Eulerian
13 % element may intersect with multiple upstream elements, creating
14 % a piecewise structure that requires specialized integration
15 % and assembly procedures.
16 %
17 % This approach is particularly effective for advection-dominated
18 % problems where traditional Eulerian methods suffer from numerical
19 % diffusion or require prohibitively small time steps for stability.
20 %
21 % Examples:
22 % % Create semi-Lagrangian operator for C0 element
23 % element = fem.element.C0FiniteElement(geometry, projector, integrator);
24 % clipper = SomeClipperImplementation();
25 % operator = C0SemiLagrangianFiniteElementOperator(element, clipper);
26 %
27 % % Set up piece data and access operators
28 % operator.setVolumePieceData();
29 % massOp = operator.mass;
30 % gradOp = operator.gradient;
31 %
32 % See also:
33 % fem.element.SemiLagrangianFiniteElementOperator,
34 % fem.element.C0FiniteElement
