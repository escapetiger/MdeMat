Detailed Description

Base class for all interpolation polynomial basis functions.

InterpolationPolynomialBasisFunction provides common functionality for interpolation-based polynomial basis functions such as Lagrange and Hermite polynomials. It handles node management and automatically calculates the polynomial degree based on the number of nodes.

% nodes = [0, 1, 2];
% basis = LagrangeBasisFunction(nodes, 1);
