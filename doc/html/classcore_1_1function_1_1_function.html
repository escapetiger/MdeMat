Detailed Description

Base class for all functions from Euclidean space to Euclidean space.

Function represents a mathematical mapping from \(R^n\) to \(R^m\), which can be evaluated at specified points. This class defines the interface for all function types in the system.

function core::function::Function::Function ( InputType options)

Constructor for the abstract Function class.

obj = Function() creates a Function with default dimensions (both nDims and nCodims are 0).

obj = Function(nDims=nDims, nCodims=nCodims) creates a Function with specified input dimension nDims and output dimension nCodims.

Compute the Jacobian matrix at specified points.

J = jacobian(obj, X) computes the Jacobian matrix of the function at the specified points. For a function from \(R^n\) to \(R^m\), the Jacobian is an \(m\times n\) matrix of first partial derivatives.
