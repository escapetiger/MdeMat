Detailed Description

Data container for visualization datasets.

Dataset provides a simple container for visualization data with type information. This class encapsulates the data structure and type classification used throughout the visualization system.

The Type property determines how the data is rendered:

  • Type 0 (FIXED): Fixed or reference data
  • Type 1 (EXACT): Exact analytical solution data
  • Type 2 (NUMERICAL): Numerical solution data
