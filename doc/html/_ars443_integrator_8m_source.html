2 % ARS443INTEGRATOR Third-order ARS(4,4,3) IMEX Runge-Kutta integrator.
3 %
4 % Ars443Integrator implements the ARS(4,4,3) method, a third-order
5 % IMEX scheme for solving ordinary differential equations of the
6 % form:
7 %
8 % \f[
9 % \frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + F(u) + S(t),
10 % \f]
11 %
12 % where \f$M\f$ is a mass operator, \f$L\f$ is a linear operator
13 % (treated implicitly), \f$F(u)\f$ is a nonlinear operator (treated
14 % explicitly), and \f$S(t)\f$ is a source term (treated explicitly).
15 % This method provides high accuracy with good stability properties,
16 % making it suitable for problems requiring precise solutions with
17 % moderate computational cost.
18 %
19 % This method uses 5 stages to achieve third-order accuracy. The
20 % method maintains A-stability for the implicit part and provides
21 % excellent accuracy for smooth solutions. The explicit part is
22 % designed to minimize storage requirements and computational
23 % overhead.
24 %
25 % See also:
26 % approx.odeint.ImexrkIntegrator, approx.odeint.Ars111Integrator,
27 % approx.odeint.Ars222Integrator
28

31 end
