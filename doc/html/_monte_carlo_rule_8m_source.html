2 % MONTECARLORULE Monte Carlo numerical integration rule.
3 %
4 % MonteCarloRule provides a foundation for Monte Carlo integration
5 % methods. This class manages random number generation with
6 % reproducible seeding and defines the interface for Monte Carlo
7 % quadrature implementations.
8 %
9 % Examples:
10 % % Create a 2D Monte Carlo rule with specific seed
11 % rule = MonteCarloRule(2, 12345);
12 %
13 % % Generate 1000 random integration points
14 % [X, w] = rule.generate(1000);
15 %
