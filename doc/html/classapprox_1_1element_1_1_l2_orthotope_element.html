Detailed Description

\(L^2\) element over the orthotope.

L2OrthotopeElement implements an \(L^2\) finite element over the orthotope domain. The element supports both modal and nodal basis functions with various polynomial orders and ordering patterns.

Create an \(L^2\) element on the unit orthotope.

obj = L2OrthotopeElement(nDims, basisOrder, basisType, basisPattern) creates an \(L^2\) element on the unit orthotope with specified basis configuration.

Basis types: 'monic_unit_legendre': Monic Legendre basis 'unit_gauss_legendre_lagrange': Lagrange-Gauss-Legendre basis 'unit_gauss_lobatto_lagrange': Lagrange-Gauss-Lobatto basis

Basis patterns: 'Q': \(L_\infty\) norm ordering (tensor product) 'P': \(L_1\) norm ordering (total degree)
