1classdef SeparableOdeIntegrator < core.linalg.Separable
2 % SEPARABLEODEINTEGRATOR Base class for separable ODE integrators.
3 %
4 % SeparableOdeIntegrator extends the Separable class to provide
5 % specialized functionality for ODE integration methods that
6 % decompose the evolution operator into separable factors. Each
7 % factor corresponds to a sub-integrator that handles one part
8 % of the split equation.
9 %
10 % The mathematical foundation is based on decomposing:
11 %
12 % \f[
13 % \frac{\mathrm{d}(Mu)}{\mathrm{d}t} = \sum_{i=1}^{n} (L_i u +
14 % F_i(u) + S_i)
15 % \f]
16 %
17 % into n separable sub-problems, each solved by an appropriate
18 % factor integrator stored in the separable representation.
19 %
20 % See also:
21 % core.linalg.Separable, approx.odeint.LieTrotterIntegrator,
22 % approx.odeint.StrangIntegrator
23
