Detailed Description

Unit tests for LxMultiIndexer class.

TestLxMultiIndexer provides test coverage for LxMultiIndexer functionality including index generation, caching, and conversion between multi-indices and linear indices.

% Run all tests
results = runtests(core.linalg.tests.TestLxMultiIndexer);
