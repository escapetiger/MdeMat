2 % STRATEGY1D One-dimensional line plot rendering strategy.
3 %
4 % Strategy1d extends the base Strategy class to provide specialized
5 % rendering for 1D data using line and scatter plots. The strategy
6 % automatically selects appropriate styling based on dataset types,
7 % using lines for analytical/exact data and markers for numerical
8 % data points.
