Detailed Description

Grid-based assembler for mixed finite element systems.

MixedGridAssembler extends the Eulerian grid assembler with support for different flux types (left-biased, right-biased, central) used in mixed finite element methods and discontinuous Galerkin schemes.

This class provides the foundation for assembling operators in mixed formulations where different variables may require different flux treatments. It supports various numerical flux choices commonly used in discontinuous methods.

% Create mixed assembler with central flux and Dirichlet BC
assembler = MixedGridAssembler(fe, mesh, op, 1, 3);
% Assemble divergence operator with dimension-specific coefficients
coeffs = [1.0, 0.5]; % coefficients for each dimension
divMatrix = assembler.divergence(coeffs);
% Assemble partial derivative in specific dimension
partialMatrix = assembler.partial(1, 2.0);

Constructor for MixedGridAssembler.

obj = MixedGridAssembler(fe, mesh, op, bcType, fluxType) creates an assembler for mixed finite element systems with specified flux type for discontinuous Galerkin methods.

Parameters
fe- Finite element object
mesh- Grid mesh object (must be approx.mesh.Grid)
op- Finite element operator object
bcType- Boundary condition type (0=periodic, 1=Dirichlet)
fluxType- Flux type (1=left-biased, 2=right-biased, 3=central)
