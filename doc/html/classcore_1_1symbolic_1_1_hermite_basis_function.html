Detailed Description

Hermite interpolation basis functions.

HermiteBasisFunction generates Hermite interpolation basis functions that interpolate both function values and derivatives at specified nodes. Each basis function satisfies specific conditions at the interpolation nodes for both the function and its derivatives.

For \(n\) nodes, there are \(2n\) Hermite basis functions: Index \(1\) to \(n\): function value interpolation Index \(n+1\) to \(2n\): derivative interpolation

% Function value basis at first node
nodes = [0, 1];
basis = core.symbolic.HermiteBasisFunction(nodes, 1);
% Derivative basis in monic form
basis = core.symbolic.HermiteBasisFunction(nodes, 3, sym('t'), true);
