1classdef Composition < core.function.Function
2 % COMPOSITION Function representing the composition of two functions.
3 %
4 % Composition represents the mathematical composition of two
5 % functions:
6 %
7 % \f[
8 % (f \circ g)(x) = f(g(x))
9 % \f]
10 %
11 % where the output dimension of the inner function @a rhs must match
12 % the input dimension of the outer function @a lhs. The composition
13 % maps from the input space of @a rhs to the output space of @a lhs.
14 %
15 % For derivatives, the chain rule is applied:
16 % \f[
17 % \frac{d}{dx}(f \circ g)(x) = f'(g(x)) \cdot g'(x)
18 % \f]
19 %
20 % Higher-order derivatives use Faà di Bruno's formula for the
21 % composition of functions.
22 %
23 % See also:
24 % core.function.Function, core.function.ProductFunction
