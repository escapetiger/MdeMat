3 %
4 % ChebyshevBasis generates Chebyshev polynomial basis functions of

78 function normalizer = computeNormalizer(obj, n)
79 % COMPUTENORMALIZER Compute Chebyshev normalizer.
80
81 l = obj.Upper - obj.Lower;
82 if n == 0
