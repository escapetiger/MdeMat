1classdef IntegrationData < handle
2 % INTEGRATIONDATA Data collection for integration.
3 %
4 % IntegrationData stores function values and derivatives evaluated at
5 % integration nodes, along with the associated integration weights.
6 %
7 % The class manages function evaluations at integration points and
8 % supports efficient computation of integrals involving functions
9 % and their derivatives. It serves as a bridge between continuous
10 % function representations and discrete numerical computations.
11 %
12 % Function derivatives are computed using multi-index notation to
13 % handle arbitrary spatial dimensions and derivative orders
14 % efficiently.
15 %
