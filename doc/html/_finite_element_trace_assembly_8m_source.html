2 % FINITEELEMENTTRACEASSEMBLY Assembly for finite element trace operations.
3 %
4 % FiniteElementTraceAssembly provides specialized assembly methods for
5 % trace operations in finite element computations. These operations are
6 % particularly important for handling boundary conditions and interface
7 % problems where contributions must be accumulated from traces of elements
8 % on boundaries.
9 %
10 % The class handles vectorized assembly operations (batch processing) for
11 % efficiency when multiple components need to be assembled simultaneously.
12 % All assembly operations respect periodic boundary conditions by skipping
13 % assembly when such conditions are specified.
14 %
