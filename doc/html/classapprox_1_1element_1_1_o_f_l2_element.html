Detailed Description

Oscillation-free \(L^2\) element.

OFL2Element extends the standard L2Element by adding flux derivative evaluation capabilities for oscillation-free treatment in Galerkin methods. This element type is particularly useful for problems where standard Galerkin methods may produce spurious oscillations, such as advection-dominated transport problems.
