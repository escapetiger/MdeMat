1classdef ScalingFunction < core.function.Function
2 % SCALING Function representing scaled coordinate transformations.
3 %
4 % Scaling represents coordinate scaling transformations of the form:
5 %
6 % \f[
7 % f(x) = g(x/\lambda)
8 % \f]
9 %
10 % where \f$g\f$ is a core.function.Function and \f$\lambda\f$ is a
11 % positive scaling parameter. This transformation scales the input
12 % coordinates by \f$1/\lambda\f$ before evaluating the base function.
13 %
14 % For derivatives, the chain rule gives:
15 % \f[
16 % \frac{\partial^k f}{\partial x^k}(x) = \frac{1}{\lambda^k}
17 % \frac{\partial^k g}{\partial u^k}(x/\lambda)
18 % \f]
19 %
20 % See also:
