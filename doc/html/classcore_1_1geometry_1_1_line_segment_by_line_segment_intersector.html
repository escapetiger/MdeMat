Detailed Description

Computes intersections between line segments.

LineSegmentByLineSegmentIntersector computes intersection points between pairs of line segments in n-dimensional space (n >= 2). The line segments are defined by their endpoints, and intersections are computed using a least-squares approach.

The line segments are parameterized as:

\[L1(s) = X1 + s*(X2 - X1) L2(t) = X3 + t*(X4 - X3) \]

An intersection is considered valid only when:

  1. Two non-collinear line segments intersect at exactly one point
  2. Two collinear line segments intersect at exactly one point

If line segments would have more than one intersection point (e.g., they overlap), an error is thrown.
