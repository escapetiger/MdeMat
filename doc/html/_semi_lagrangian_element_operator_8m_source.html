2 % SEMILAGRANGIANELEMENTOPERATOR Base class for semi-Lagrangian element
3 % operators.
4 %
5 % SemiLagrangianElementOperator provides the foundation for
6 % operators used in semi-Lagrangian finite element methods. These
7 % methods track fluid parcels backward in time along characteristic
8 % curves, requiring specialized operators that handle the coupling
9 % between Eulerian and upstream (Lagrangian) data.
10 %
11 % The class maintains a reference to a clipper object that manages
12 % the geometric intersection and integration over the overlap
13 % regions between Eulerian elements and upstream footprints.
14 % This is essential for accurate transport calculations in
15 % convection-dominated problems.
16 %
17 % Semi-Lagrangian methods are particularly effective for problems
18 % with high Péclet numbers where traditional Eulerian methods
19 % suffer from numerical diffusion or instability. By following
20 % characteristics backward, these methods naturally handle
21 % advection without the CFL time step restriction.
22 %
23 % See also:
