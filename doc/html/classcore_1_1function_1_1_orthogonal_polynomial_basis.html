Detailed Description

Abstract base class for orthogonal polynomial basis functions.

OrthogonalPolynomialBasis provides a unified framework for generating orthogonal polynomial basis functions using three-term recurrence relations. Concrete subclasses implement specific polynomial families such as Legendre, Chebyshev, and Hermite polynomials.

The three-term recurrence relation has the general form:

\[P_{n+1}(x) = (A_n \cdot x + B_n) \cdot P_n(x) + C_n \cdot P_{n-1}(x) \]

Compute coefficients for three-term recurrence relation.

[a, b, c] = computeCoefficients(n) returns the coefficients a, b, and c for the three-term recurrence relation at degree n. The recurrence relation is: \( P_{n+1}(x) = (a*x + b)*P_n(x) + c*P_{n-1}(x) \)
