Detailed Description

Visualization class for Graph objects.

GraphPlotter provides comprehensive visualization functionality for approx.mesh.Graph objects, enabling customizable plots of vertices and edges in 1D, 2D, and 3D spaces. The class supports various styling options for different visualization needs.
