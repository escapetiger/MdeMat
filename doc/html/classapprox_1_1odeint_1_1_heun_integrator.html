Detailed Description

Heun's integrator.

HeunIntegrator implements Heun's method, a second-order explicit Runge-Kutta scheme for solving ordinary differential equations of the form:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + F(u) + S(t), \]

where \(M\) is a mass operator, \(L\) is a linear operator, \(F(u)\) is a nonlinear operator, and \(S(t)\) is a source term. This method provides second-order accuracy with good stability properties. It's also known as the improved Euler method or RK2.

Heun's method evaluates the derivative at \(t\) and at \(t + (2/3)\Delta t\), then takes a weighted average. The weights [1/4, 3/4] give optimal second-order accuracy with this intermediate evaluation point.
