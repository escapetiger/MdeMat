Detailed Description

Linear approximator based on nodal information.

NodalApproximator implements a linear approximation method that uses interpolation basis functions, such as Lagrange polynomials.

Let \(x_j\) denote the nodal points, \(p_i\) basis functions, and \(c_i\) the coefficients to be determined. The projection system is defined as:

\[\sum_i\sum_kw_kc_ip_i(x_k)p_j(x_k) = f_j(x_k), \forall j. \]

This implies that the mass matrix is \(M=diag(w_k)\). The fitting system is defined as:

\[u(x_j) = \sum_i c_i p_i(x_j), \forall j. \]

The design matrix \(D_{ji} = p_i(x_j)\) represents the evaluation of basis functions at nodal points. For Lagrangian polynomial, \(D\) reduces to the identity matrix.

Embed function values at nodal points into the latent space.

F = embed(obj, U) embeds function values at nodal points into the latent space. For nodal embedding, this operation is essentially the identity transformation since the latent space directly corresponds to function values at nodes.

◆ setDesign()

function approx::linear::NodalApproximator::setDesign ( InputType obj,
InputType X )

Set up the design operator using nodal points.

obj = setDesign(obj, X) constructs the design matrix as the evaluation of basis functions at the nodal points. The design matrix \(D_{ji} = p_i(x_j)\) where \(x_j\) are nodal points and \(p_i\) are basis functions.
