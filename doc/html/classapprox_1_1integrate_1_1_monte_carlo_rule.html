Detailed Description

Monte Carlo numerical integration rule.

MonteCarloRule provides a foundation for Monte Carlo integration methods. This class manages random number generation with reproducible seeding and defines the interface for Monte Carlo quadrature implementations.

% Create a 2D Monte Carlo rule with specific seed
rule = MonteCarloRule(2, 12345);
% Generate 1000 random integration points
[X, w] = rule.generate(1000);
