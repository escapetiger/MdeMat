Detailed Description

Finite element representation.

Provides the foundation for finite element methods with domain, function space, and integration capabilities. This abstract base class defines the interface for all finite element implementations.

% Create a concrete finite element (C0 or L2)
element = C0FiniteElement(geometry, projector, integrator);
% Evaluate function at points
values = element.evaluate(evaluationPoints, coefficients);
