1classdef Timer < handle
2 % TIMER High-precision timing framework for performance measurement.
3 %
4 % Timer manages a collection of named timing records with mutually
5 % exclusive operation (only one record can be active at any time).
6 % It provides comprehensive timing functionality including start/stop
7 % operations, duration accumulation, and formatted reporting.
8 %
9 % The Timer class maintains an array of Record objects, each tracking
10 % a specific operation or phase. When a record is started, all other
11 % records must be stopped to ensure accurate measurements. Timing
12 % data accumulates across multiple start/stop cycles for the same
13 % record, allowing measurement of iterative or multi-phase
14 % operations.
15 %
