Detailed Description

\(H^1\) Sobolev space element.

H1Element implements an \(H^1\) element function suitable for problems requiring both function values and first derivatives. This class extends the base Element class by adding volume integration capabilities through precomputed basis function values and first-order derivatives at integration points.
