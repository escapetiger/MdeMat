Detailed Description

Multi-level integrator with Richardson extrapolation.

MultiLevelIntegrator implements multi-level numerical integration using an array of Integrator objects at different refinement levels. It supports Richardson extrapolation to achieve higher accuracy by combining results from multiple levels with known convergence rates.

The class manages a collection of Integrator objects, each operating at different resolutions, and provides methods for setting up multi-level integration points, evaluating functions at all levels, and computing extrapolated results.
