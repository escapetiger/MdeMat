2 % SSPRK2INTEGRATOR SSPRK2 integrator.
3 %
4 % Ssprk2Integrator implements SSPRK2 method, a second-order explicit
5 % Runge-Kutta scheme for solving ordinary differential equations of
6 % the form:
7 %
8 % \f[
9 % \frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + F(u) + S(t),
10 % \f]
11 %
12 % where \f$M\f$ is a mass operator, \f$L\f$ is a linear operator,
13 % \f$F(u)\f$ is a nonlinear operator, and \f$S(t)\f$ is a source
14 % term. This method provides second-order accuracy with good
15 % stability properties. It's also known as the improved Euler method
16 % or RK2.
17 %
18 % SSPRK2 method evaluates the derivative at \f$t\f$ and at \f$t +
19 % (2/3)\Delta t\f$, then takes a weighted average. The weights [1/4,
20 % 3/4] give optimal second-order accuracy with this intermediate
21 % evaluation point.
22 %
23 % See also:
24 % approx.odeint.ExrkIntegrator, approx.odeint.Exrk4Integrator,
25 % approx.odeint.FeIntegrator
26
27 properties (Constant)
28 Order = 2 % Accuracy order of SSPRK2 method
29 end
