2 % ESDIRK3INTEGRATOR Third-order ESDIRK integrator.
3 %
4 % Esdirk3Integrator implements a third-order ESDIRK method with three
5 % stages for solving ordinary differential equations of the form:
6 %
7 % \f[
8 % \frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + S,
9 % \f]
10 %
11 % where \f$M\f$ is a mass operator, \f$L\f$ is a linear operator, and
12 % \f$S\f$ is a source term. This method features an explicit first
13 % stage (\f$c_1 = 0\f$) followed by two implicit stages, providing
14 % computational efficiency while maintaining good stability
15 % properties.
16 %
17 % The parameter \f$\gamma = (3 + \sqrt{3})/6 \approx 0.7886751346\f$
18 % ensures third-order accuracy and A-stability. The explicit first
19 % stage reduces computational cost compared to fully implicit
20 % methods.
21 %
22 % See also:
23 % approx.odeint.DirkIntegrator, approx.odeint.Sdirk2Integrator,
24 % approx.odeint.Sdirk3Integrator
25

43 %< ESDIRK3 coefficients for third-order accuracy
44 c3 = 1;
45 gamma = (3 + sqrt(3)) / 6;
46 a32 = c3 * (c3 - 2 * gamma) / (4 * gamma);
47 b2 = (-2 + 3 * c3) / (12 * (c3 - 2 * gamma) * gamma);
48 b3 = (1 - 3 * gamma) / (3 * c3 * (c3 - 2 * gamma));
