Detailed Description

Key-value map that preserves insertion order.

OrderedMap provides containers.Map-like interface but preserves insertion order of elements. Supports basic operations (get, set, remove, isKey) and adds methods for order manipulation.

% Create and populate ordered map
map = core.data.OrderedMap();
map('first') = 1;
map('second') = 2;
map('third') = 3;
% Iterate through keys in insertion order
keys = map.keys();
% keys will be {'first', 'second', 'third'} in that order
% Check if key exists
exists = map.isKey('third'); % exists = true
