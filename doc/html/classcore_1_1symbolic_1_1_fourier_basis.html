Detailed Description

Fourier orthogonal basis functions.

FourierBasis generates trigonometric Fourier basis functions up to a specified maximum degree. The basis functions include constant, sine, and cosine terms, orthogonal on the interval \([0, 2\pi]\).

Construct Fourier basis functions.

obj = FourierBasis(variables, maxDegree) creates Fourier basis functions using the specified variables up to maxDegree.

obj = FourierBasis(variables, maxDegree, isNormalized=true) creates orthonormal Fourier basis functions.
