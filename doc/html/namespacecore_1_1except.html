◆ hasFields()

function core::except::hasFields ( InputType s,
InputType f )

Check if a struct s has all specified fields f and return first missing one.

tf = hasFields(s, f) returns only the logical result without missing field.

[tf, missingField] = hasFields(s, f) returns true if struct s contains all fields specified in f, and also returns the first missing field name.
