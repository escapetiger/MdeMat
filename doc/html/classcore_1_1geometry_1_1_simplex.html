Detailed Description

Geometry for n-dimensional simplex domains.

Simplex represents a generalized geometric domain that extends the concept of triangles and tetrahedra to arbitrary dimensions. It is the simplest possible convex polytope in any given dimensional space.

Dimensional Representations:

  • In 1D: A line segment (2 vertices)
  • In 2D: A triangle (3 vertices)
  • In 3D: A tetrahedron (4 vertices)
  • In nD: An n-simplex (n+1 vertices)

◆ Simplex()

function core::geometry::Simplex::Simplex ( InputType V)

Construct an instance of Simplex.

obj = Simplex(V) creates a simplex from the given vertices, with strict validation of vertex configuration. The vertices must be affinely independent and form a valid simplex. A nd-dimensional simplex requires exactly nd+1 vertices.

The V parameter must be a matrix of size nd×(nd+1) where each column represents a vertex. Vertices must be affinely independent to ensure the simplex is non-degenerate.

Converts barycentric to Cartesian coordinates.

C = barycentricToCartesian(obj, B) transforms points from barycentric coordinates back to Cartesian coordinates. The barycentric coordinates must sum to 1 and be non-negative for valid points within or on the simplex.

◆ cartesianToBarycentric()

function core::geometry::Simplex::cartesianToBarycentric ( InputType obj,
InputType C )

Converts Cartesian to barycentric coordinates.

B = cartesianToBarycentric(obj, C) transforms points from Cartesian coordinates to barycentric coordinates with respect to the simplex vertices. Barycentric coordinates sum to 1 and are non-negative for interior points. Each coordinate represents the weight of the corresponding vertex.

◆ isInside()

function core::geometry::Simplex::isInside ( InputType obj,
InputType X )

Tests if points are inside the simplex.

TF = isInside(obj, X) uses barycentric coordinates to determine if points lie strictly within the interior of the simplex. Points are inside if all barycentric coordinates are positive (greater than tolerance).

◆ isOnBoundary()

function core::geometry::Simplex::isOnBoundary ( InputType obj,
InputType X )

Tests if points are on the simplex boundary.

TF = isOnBoundary(obj, X) uses barycentric coordinates to determine if points lie exactly on the boundary faces of the simplex. Points are on the boundary if at least one barycentric coordinate is zero (within tolerance).

◆ magnitude()

function core::geometry::Simplex::magnitude ( InputType obj)

Returns the volume of the simplex.

m = magnitude(obj) computes the n-dimensional volume of the simplex using the determinant formula. The volume is calculated as \(|det(E)|/nd!\) where \(E\) is the matrix of edge vectors from one vertex to all others.
