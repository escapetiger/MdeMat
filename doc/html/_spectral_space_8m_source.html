2 % SPECTRALSPACE Function space based on a single element.
3 %
4 % SpectralSpace represents a finite-dimensional function space
5 % defined by a single element. It serves as a building block for
6 % more complex function space constructions through direct sum
7 % operations.
8 %
9 % Functions in this space have the form:

11 % u_h(x) = \sum_{i=1}^n c_i \phi_i(x)
12 % \f]
13 % where \f$\phi_i\f$ are basis functions from the element and
