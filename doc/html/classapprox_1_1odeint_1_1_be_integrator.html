Detailed Description

Backward Euler integrator.

BeIntegrator implements the Backward Euler method, a first-order implicit time integration scheme for solving ordinary differential equations of the form:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + S, \]

where \(M\) is a mass operator, \(L\) is a linear operator, and \(S\) is a source term. Any of these terms can be empty. For mass operator, it means it reduces to an identity. For linear and source term, it means they vanish from the equation. The method is A-stable and suitable for stiff problems.

The Backward Euler method is the simplest implicit method, requiring only one function evaluation per time step but involving the solution of a linear system at each step.

Set the augmented left-hand side matrix for Backward Euler.

obj = setLhsA(obj, L, M, P, A, B) constructs the augmented left-hand side block matrix for the Backward Euler system with constraints:

\[\begin{bmatrix} M - \Delta t L & -\Delta t P \\ -A & -B \end{bmatrix} \]

where the constraint system couples the differential variables through A and algebraic variables through B. The coupling operator P connects the algebraic variables to the differential equation, and all operators are evaluated at the current time level.

Set the augmented right-hand side vector for Backward Euler.

obj = setRhsA(obj, S, M, C) constructs the augmented right-hand side block vector for the Backward Euler system with constraints:

\[\begin{bmatrix} M u^{(n)} + \Delta t S \\ C \end{bmatrix} \]

where \(u^{(n)}\) is the solution at the previous time step, S is the source term for the differential equation, and C is the constraint source term for the algebraic equation. Since Backward Euler is a single-stage method, no stage accumulation is required.

Compute the single stage of the augmented Backward Euler method.

U = stageA(obj, L, S, M, P, A, B, C) computes the solution for the constrained system by solving the augmented implicit Backward Euler system:

\[\begin{bmatrix} M - \Delta t L & -\Delta t P \\ -A & -B \end{bmatrix} \begin{bmatrix} u^{(n+1)} \\ v^{(n+1)} \end{bmatrix} = \begin{bmatrix} M u^{(n)} + \Delta t S \\ C \end{bmatrix} \]

where \(u^{(n+1)}\) are the differential variables, \(v^{(n+1)}\) are the algebraic variables at the new time level. For Backward Euler, this single stage computation is equivalent to a complete time step.

Advance one time step using the augmented Backward Euler method.

U = stepA(obj, L, S, M, P, A, B, C) performs a complete time step for the constrained system. For Backward Euler, this is equivalent to computing a single stage since it is a single-stage method. The method solves the differential-algebraic equation system:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + Pv + S, \quad 0 = Au + Bv + C \]

where u represents the differential variables, v represents the algebraic variables, and the constraint equation couples them through operators A and B.
