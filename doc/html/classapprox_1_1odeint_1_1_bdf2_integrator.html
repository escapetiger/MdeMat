Detailed Description

Second-order BDF integrator.

Bdf2Integrator implements two-step Backward Differentiation Formula (BDF) methods for solving ordinary differential equations of the form:

\[\frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + S, \]

where \(M\) is a mass operator, \(L\) is a linear operator, and \(S\) is a source term.

Bdf2Integrator uses the Backward Euler method for the first step. It acheives second-order accuracy and A-stability.

integrator = approx.odeint.Bdf2Integrator(1.0);
U_new = integrator.step(L, N);
integrator.update(U_new);
