2 % SPHERICALGAUSSTRAPEZOIDALRULE Gauss-Trapezoidal integration over hypersphere.
3 %
4 % SphericalGaussTrapezoidalRule implements numerical integration over
5 % hyperspheres using a product of Gauss-Lobatto rules for zenith angles
6 % and a periodic trapezoidal rule for the azimuthal angle. This method
7 % provides efficient integration for functions on spherical domains.
8 %
9 % Hyperspherical coordinates map Cartesian coordinates
10 % \f$(y_1,...,y_d)\f$ as:
11 % \f[
12 % y_1 = r*\cos(x_1)
13 % y_i = r*\sin(x_1)*...*\sin(x_{i-1})*\cos(x_i), i = 2,...,d-1
14 % y_d = r*\sin(x_1)*...*\sin(x_{d-1})
15 % \f]
16 % where:
17 % \f[
18 % x_i \in [0, \pi] for i = 1,...,d-2 (zenith angles)
19 % x_{d-1} \in [0, 2\pi] (azimuthal angle)
20 % \f]
21 %
22 % Examples:
23 % % Create rule for 3D sphere integration
24 % rule = SphericalGaussTrapezoidalRule(3);
25 %
26 % % Generate integration points
27 % [X, w] = rule.generate([5, 8]);
28 %
29 % % Custom sphere with different center and radius
30 % [X, w] = rule.generate([3, 6], false, [1, 2, 0], 1.5);
31 %
32 % Notes:
33 % For d-dimensional hypersphere, requires d-1 parameters in n:
34 % first d-2 for zenith angles, last one for azimuthal angle.
35 %
36 % See also:
37 % approx.integrate.IntegrationRule, approx.integrate.LebedevRule,
38 % approx.integrate.SphericalMonteCarloRule
