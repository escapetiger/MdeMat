3 % hypersphere.
4 %
5 % SphericalGaussTrapezoidalRule implements numerical integration over
6 % hyperspheres using a product of Gauss-Lobatto rules for zenith
7 % angles and a periodic trapezoidal rule for the azimuthal angle.
8 % This method provides efficient integration for functions on
9 % spherical domains.
10 %
11 % Hyperspherical coordinates map Cartesian coordinates
12 % \f$(y_1,...,y_d)\f$ as:
13 % \f[
14 % y_1 = r*\cos(x_1)
15 % y_i = r*\sin(x_1)*...*\sin(x_{i-1})*\cos(x_i), i = 2,...,d-1
16 % y_d = r*\sin(x_1)*...*\sin(x_{d-1})
17 % \f]
18 % where:
19 % \f[
20 % x_i \in [0, \pi] for i = 1,...,d-2 (zenith angles)
21 % x_{d-1} \in [0, 2\pi] (azimuthal angle)
22 % \f]
23 %
