5 % LineSegmentByPlaneIntersector computes intersection points between
6 % line segments and planes in n-dimensional space (n >= 2).
7 % Line segments are defined by their endpoints, and planes are
8 % defined by normal vectors and offset constants.
9 %
10 % The line segment is parameterized as:
11 %
12 % \f[
13 % L(t) = X1 + t*(X2 - X1), t \in [0,1]
14 % \f]
15 %
16 % The plane is defined by the equation:
17 %
18 % \f[
19 % a^T * x + b = 0,
20 % \f]
21 %
22 % where \f$a\f$ is the normal vector to the plane and \f$b\f$ is
23 % the offset constant. The method handles parallel and coincident
24 % cases appropriately. If a line segment lies entirely on a plane,
25 % all points are considered intersection points.
26 %
27 % See also:
