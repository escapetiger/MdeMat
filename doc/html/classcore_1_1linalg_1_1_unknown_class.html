Detailed Description

Abstract base class for indexers with cached.

indices.

Provides a foundation for index generation strategies that benefit from caching generated indices. This abstract class implements caching mechanisms and methods for index conversion using the cache. Subclasses implement specific index generation strategies while inheriting common caching functionality.
