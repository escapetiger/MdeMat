2 % SDIRK4INTEGRATOR Fourth-order SDIRK integrator.
3 %
4 % Sdirk4Integrator implements a fourth-order SDIRK method with five
5 % stages for solving ordinary differential equations of the form:
6 %
7 % \f[
8 % \frac{\mathrm{d}(Mu)}{\mathrm{d}t} = Lu + S,
9 % \f]
10 %
11 % where \f$M\f$ is a mass operator, \f$L\f$ is a linear operator, and
12 % \f$S\f$ is a source term. This method provides high-order accuracy
13 % with good stability properties for stiff problems. The diagonal
14 % elements of the Butcher tableau are identical.
15 %
16 % The method uses \f$\gamma = 1/4\f$, which provides A-stability and
17 % good damping properties. The method requires five implicit solves
18 % per time step but achieves fourth-order accuracy, making it
19 % suitable for problems requiring high precision.
20 %
21 % See also:
22 % approx.odeint.DirkIntegrator, approx.odeint.Sdirk2Integrator,
23 % approx.odeint.Sdirk3Integrator
