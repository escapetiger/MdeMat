Detailed Description

Nonuniform multidimensional structured grid.

NonuniformGrid represents a structured grid with non-uniform spacing defined by coordinate vectors along each dimension. This class implements memory-efficient tensor-based storage while allowing arbitrary element sizes and distributions.

% 1D nonuniform grid with refined regions
x = [0, 0.1, 0.15, 0.2, 0.5, 0.8, 0.9, 1.0];
grid1D = NonuniformGrid({x});
% 2D nonuniform grid with different spacing in each direction
x = 0:0.1:1;
y = [0, 0.05, 0.2, 0.5, 1.0];
grid2D = NonuniformGrid({x, y});
