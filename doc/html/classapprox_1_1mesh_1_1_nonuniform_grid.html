Detailed Description

Structured grid with variable element spacing.

NonuniformGrid represents a structured computational grid where elements can have different sizes within each dimension while maintaining the regular tensor-product topology. This flexibility enables adaptive mesh refinement in specific regions while preserving the computational advantages of structured grids.

The grid is defined by coordinate vectors along each dimension, allowing arbitrary spacing distributions such as geometric progressions, hyperbolic tangent clustering, or user-defined refinement patterns. Despite varying element sizes, the tensor-product structure enables efficient storage O(∑nᵢ) and algorithmic operations compared to unstructured meshes.

Key advantages over uniform grids:

  • Adaptive resolution: Fine elements where needed, coarse elsewhere
  • Boundary layer capture: Geometric clustering near walls/interfaces
  • Smooth transitions: Gradual spacing changes avoid numerical artifacts
  • Domain conformity: Better approximation of curved boundaries

Key advantages over unstructured meshes:

  • Tensor-product structure: Efficient matrix operations and solvers
  • Separable algorithms: Fast Fourier transforms and direct methods
  • Memory efficiency: O(d×n) storage vs O(n^d) for explicit connectivity
  • Neighbor queries: O(1) algorithmic connectivity vs stored tables
% 1D grid with boundary layer refinement
x_fine = linspace(0, 0.1, 21); % Fine near x=0
x_coarse = linspace(0.1, 1, 11); % Coarse in interior
x = [x_fine, x_coarse(2:end)]; % Remove duplicate
grid1D = NonuniformGrid({x});
% 2D grid with geometric stretching
x_uniform = linspace(0, 1, 51); % Uniform in x
y_stretched = [0, cumsum(1.05.^(0:29))]; % Geometric in y
y_stretched = y_stretched / y_stretched(end); % Normalize to [0,1]
grid2D = NonuniformGrid({x_uniform, y_stretched});
% 3D grid with mixed spacing patterns
x = linspace(-1, 1, 21); % Uniform x-direction
y = tanh(linspace(-2, 2, 31)) / tanh(2); % Hyperbolic clustering in y
z = [0, 0.01, 0.05, 0.1:0.1:0.9, 0.95, 0.99, 1]; % Manual refinement in z
grid3D = NonuniformGrid({x, y, z});
% Query nonuniform grid properties
h = grid2D.computeMeasure(); % Minimum element spacing
detJ = grid2D.computeAllElementJacobianDeterminants(); % Variable per element
spacing_x = grid2D.spacings{1}; % Variable spacing in x
spacing_y = grid2D.spacings{2}; % Variable spacing in y
% Coordinate transformations (element-dependent)
xRef = [0.3; -0.2]; % Reference coordinates
xPhys = grid2D.collocate(xRef, [100, 200]); % Map to elements 100, 200
% Mesh refinement (preserves spacing patterns)
fineGrid = grid2D.refine(1); % Each element subdivides uniformly
% Access variable grid structure
centers_x = grid2D.centroids{1}; % Variable element centers in x
centers_y = grid2D.centroids{2}; % Variable element centers in y
nElements = grid2D.nElements; % Total elements = nx × ny

function NonuniformGrid(InputType nodes)
Constructor for NonuniformGrid.
Note
Node coordinates must be strictly increasing within each dimension
to ensure proper element ordering and positive Jacobian
determinants. The constructor automatically computes element
centers and spacings from the provided node coordinates.
Refinement preserves the relative spacing ratios within each
original element while subdividing uniformly. This maintains the
adaptive character of the original grid at finer scales.
Despite variable spacing, face normals remain axis-aligned and the
coordinate transformation retains its separable structure, enabling
efficient tensor-product algorithms.

invJ = computeAllElementInverseJacobians(obj) computes the inverse Jacobian matrix for coordinate transformation for each element. For nonuniform grids, inverse Jacobians vary by element.

Return values

Note

h = [h₁(i₁), h₂(i₂), ..., hₐ(iₐ)]:

outN = computeAllOutwardNormals(obj) computes unit outward normal vectors for each face type. For nonuniform grids, normals remain axis-aligned and constant for faces of the same type.

Parameters
obj- The NonuniformGrid object
Return values
outN- Outward normal vectors (cell array by face type)
Note
Despite variable element spacing, outward normals remain
axis-aligned and independent of element size:
- Face 2k-1: normal = -eₖ (negative k-direction, "lower" face)
- Face 2k: normal = +eₖ (positive k-direction, "upper" face)
where eₖ is the unit vector in dimension k.
All boundary elements sharing the same face type have identical
outward normals, regardless of their individual element sizes.

Compute minimum element spacing across the grid.

h = computeMeasure(obj) returns the minimum element spacing among all elements in all dimensions, providing a characteristic length scale for the nonuniform grid.

Parameters
obj- The NonuniformGrid object
Return values
h- Minimum element spacing (positive scalar)
Note
For nonuniform grids, the measure is min(min(h₁), min(h₂), ..., min(hₐ))
where hᵢ is the spacing array in dimension i. This provides the
finest resolution anywhere in the grid, important for:
- CFL stability conditions (determined by smallest element)
- Error estimates (dominated by finest resolution)
- Solver convergence (limited by most refined regions)

function approx::mesh::NonuniformGrid::refine ( InputType obj,
InputType nLevels )
virtual

Create refined nonuniform grid preserving spacing patterns.

newObj = refine(obj, nLevels) creates a refined nonuniform grid by uniformly subdividing each element while preserving the relative spacing characteristics of the original grid.

Parameters
obj- The NonuniformGrid object
nLevels- Number of refinement levels (non-negative integer)
Return values
newObj- Refined NonuniformGrid with preserved spacing patterns
Note
Refinement subdivides each original element into 2^nLevels
sub-elements with uniform spacing within the original element.
This preserves the adaptive character: regions that were fine
remain proportionally fine, and coarse regions remain coarse.
The total number of elements increases by 2^(nLevels×d), but
the relative spacing ratios between different grid regions
are maintained at the refined scale.
