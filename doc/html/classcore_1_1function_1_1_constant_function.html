Detailed Description

Function that returns constant values.

ConstantFunction represents a mathematical mapping that returns the same constant value for all input points:

\[f(x) = c \]

where \(c\) is a constant vector in \(R^m\).

% Scalar constant function
f = ConstantFunction(3, 5); % R^3 -> R^1, returns 5
% Vector constant function
f = ConstantFunction(2, [1; 2; 3]); % R^2 -> R^3, returns [1;2;3]
% Evaluate
X = rand(3, 100);
Y = f.evaluate(X); % Y will be 5 for all points
