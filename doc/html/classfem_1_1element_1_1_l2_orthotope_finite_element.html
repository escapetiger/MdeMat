function fem::element::L2OrthotopeFiniteElement::L2OrthotopeFiniteElement ( VariableInputType varargin)

Create standard L2 finite element on unit orthotope.

obj = L2OrthotopeFiniteElement(...) creates a discontinuous finite element on the unit orthotope with specified polynomial order and basis configuration.

Parameters
varargin- Input arguments
Note
id = 1: Orthogonal (Legendre) basis
id = 2: Lagrange-Gauss-Legendre basis
id = 3: Lagrange-Gauss-Lobatto basis
pattern = 1: \(L_\infty\) norm ordering
pattern = 2: \(L_1\) norm ordering
