Detailed Description

Galerkin projector based on modal embedding.

ModalProjector implements a Galerkin projection method that uses inner products between basis functions to construct the mass operator. This approach is particularly suitable for orthogonal and well-conditioned basis functions.

The Galerkin system is defined as:

\[\langle u(x), p_j(x)\rangle = \sum_{i=1}^{n} c_i \langle p_i(x), p_j(x)\rangle, \forall j = 1, ..., m \]

where \(\langle\cdot,\cdot\rangle\) denotes the inner product defined by integration weights, \(p_i\) are basis functions, and \(c_i\) are the coefficients to be determined.

The mass matrix \(M_{ij} = \langle p_i, p_j\rangle\) is constructed using numerical integration with specified quadrature points and weights.

% Create modal projector with Legendre basis
basis = OrthogonalBasisFunction(5, 'legendre', 'unit');
basis = basis.autoLoad();
projector = ModalProjector(basis);
% Set up mass operator with Gauss-Legendre quadrature
[X, w] = gauss_legendre_quadrature(10); % 10 quadrature points
projector.setMass(X, w);
% Project function data
U = sin(pi * X); % Function values at quadrature points
B = basis.evaluate(X); % Basis values at quadrature points
F = projector.embed(U, B, w);
coeffs = projector.project(F);

Embed data into the latent space using modal approach.

F = embed(obj, U, B, w) embeds function values into the latent space using the modal approach. Computes the weighted inner product between basis functions and function values at integration points: \(F_i = \langle U, p_i\rangle = \sum_k w_k U_k p_i(x_k)\).

Parameters
obj- The ModalProjector object
U- Function values at integration points (q x p)
B- Basis function values at integration points (m x q)
w- Integration weights (1 x q)
Return values
F- Latent space representation (m x p)

Set up the mass operator using numerical integration.

obj = setMass(obj, X, w) constructs the mass matrix using integration points and weights. The (i,j) entry of the mass matrix is \(\langle p_i, p_j\rangle\) where the inner product is defined by the weighted integration: \(\langle f,g\rangle = \sum_k w_k f(x_k) g(x_k)\).

Parameters
obj- The ModalProjector object
X- Integration points (n x q)
w- Integration weights (1 x q)
Return values
obj- The ModalProjector object
