Detailed Description

Base class for all solution states.

State encapsulates the fundamental solution state components including degrees of freedom and coefficients. It provides a unified container and interface for state management operations including reporting, saving, and loading.

The handle-based design allows for efficient passing of state objects between methods without copying large arrays.
